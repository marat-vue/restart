<div class="callout-title">Коротко</div>
<div class="callout-body"><p><strong>Условное оформление</strong> меняет вид (цвет, шрифт, текст) при выполнении условия; данные не меняются. Правило = <strong>оформление</strong> + <strong>условие</strong> + <strong>оформляемые поля</strong>. У динамического списка — в «Настройке списка», у формы — свойство <code>УсловноеОформление</code> (редактор или код). В условии — путь к <strong>данным</strong>, в оформляемых полях — <strong>элементы</strong> формы.</p></div>
</div>
<h2 id="что-такое-условное-оформление">Что такое условное оформление</h2>
<p><strong>Условное оформление</strong> — правило «если выполняется условие, покрась вот эти поля вот так». Например: «если накладная не проведена — жёлтый фон у номера и даты». Пользователь сразу видит, на что обратить внимание.</p>
<p>Каждое правило состоит из трёх частей:</p>

























<div class="table-wrap"><table><thead><tr><th>Часть</th><th>Вопрос</th><th>Пример</th></tr></thead><tbody><tr><td><strong>Оформление</strong></td><td>Как выделить?</td><td>Жёлтый фон</td></tr><tr><td><strong>Условие</strong></td><td>Когда?</td><td><code>Проведен = Ложь</code></td></tr><tr><td><strong>Оформляемые поля</strong></td><td>Что выделить?</td><td>Колонки «Номер» и «Дата»</td></tr></tbody></table></div>
<p>Оформление меняет только <strong>вид</strong> — данные остаются прежними. Платформа применяет правило сама к каждой строке при выводе: не нужно писать код, который перебирает строки и красит их.</p>
<h2 id="непроведённые-накладные-в-списке">Непроведённые накладные в списке</h2>
<p><code>ФормаСпискаУчебная</code> → реквизит <code>Список</code> → <strong>Настройка списка</strong> → <strong>Условное оформление</strong> → <strong>Добавить</strong>:</p>
<ol>
<li><strong>Оформление</strong> — светло-жёлтый фон.</li>
<li><strong>Условие</strong> — <code>Проведен</code> <strong>Равно</strong> <code>Ложь</code> (булево, не строка).</li>
<li><strong>Оформляемые поля</strong> — <code>Номер</code>, <code>Дата</code> (не вся строка — иначе список станет «цветным пятном»).</li>
</ol>
<p>Проверка: у непроведённой накладной выделены номер и дата; провели документ, обновили список — выделение исчезло. Пример — в <a href="https://1c-dn.com/library/tutorials/practical_developer_guide_lesson27_designer2/" target="_blank" rel="noopener noreferrer">пособии 1С</a>.</p>
<div class="callout callout-tip" data-callout="tip">
<div class="callout-title">Цвет — не единственный сигнал</div>
<div class="callout-body"><p>Важные состояния дублируем колонкой или значком: цвет воспринимается по-разному.</p></div>
</div>
<h2 id="нулевая-цена-в-таблице-документа">Нулевая цена в таблице документа</h2>
<p><code>ФормаДокумента</code> → корень «Форма» → свойство <strong>УсловноеОформление</strong>:</p>
<ol>
<li>Оформление — светло-красный фон.</li>
<li>Условия (по <strong>И</strong>): <code>Объект.Товары.Цена</code> ≤ 0 и <code>Объект.Товары.Количество</code> > 0.</li>
<li>Оформляемое поле — элемент <code>ТоварыЦена</code>.</li>
</ol>
<p>Условие табличной части применяется к <strong>каждой строке</strong> отдельно.</p>

<div class="callout callout-info" data-callout="info">
<div class="callout-title">Почему не красим строки кодом</div>
<div class="callout-body"><p>Правило условного оформления платформа применяет сама при выводе каждой строки. Не нужен код на каждое изменение данных, и приём работает в динамическом списке, строки которого форма не перебирает.</p></div>

<h2 id="проверка">Проверка</h2>
<p>Три строки: (1 шт., 0 ₽), (1 шт., 100 ₽), (0 шт., 0 ₽) — выделена только цена первой. Меняем на 50 — выделение исчезло, обратно 0 — появилось.</p>

<p>Оформление <strong>предупреждает</strong>, но не запрещает запись нулевой цены — для запрета нужна проверка с <code>Отказ = Истина</code>.</p>
