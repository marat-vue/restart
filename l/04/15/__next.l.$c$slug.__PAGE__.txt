<h2 id="открыть-форму-из-кода">Открыть форму из кода</h2>
<p>До сих пор формы открывал пользователь — через раздел или двойным щелчком. Но часто окно нужно открыть <strong>программно</strong>: по кнопке «Открыть покупателя», «Создать накладную для этого клиента», «Подобрать товар». Для этого есть метод <code>ОткрытьФорму</code> — он работает на <strong>клиенте</strong>.</p>

<p>Параметры — это способ <strong>передать данные</strong> в открываемое окно: какой документ показать, какими значениями заполнить новый, какой товар подставить.</p>

<p>Разберём:</p>
<ul>
<li><code>ЗначениеЗаполнено(Объект.Ссылка)</code> — у <strong>нового</strong>, ещё не записанного документа ссылки нет (она пустая). Открыть «сохранённую версию» несохранённого документа нельзя, поэтому сначала проверяем.</li>
<li><code>Новый Структура("Ключ", Объект.Ссылка)</code> — структура с одним параметром: имя <code>Ключ</code>, значение — ссылка на документ.</li>
<li><code>Ключ</code> — <strong>стандартный</strong> параметр формы объекта: «открой вот этот существующий объект».</li>
</ul>
<p>В <code>Ключ</code> передаём <strong>ссылку</strong>, а не номер или <code>ДокументОбъект</code>. Если форма этого документа уже открыта, платформа её активирует — второе окно не создаётся.</p>

<li>Записанная → открывается (или активируется) по ссылке.</li>
<li>«Покупатель» → карточка выбранного контрагента.</li>
