<h2 id="удаление-строки">Удаление строки</h2>
<p>Удалили строку — её сумма больше не должна входить в итог. Для этого у <strong>самой таблицы</strong> есть событие <strong>ПослеУдаления</strong>:</p>
<ol>
<li>В дереве элементов выделяем таблицу <code>Товары</code> (не колонку!).</li>
<li>События → <strong>ПослеУдаления</strong> → лупа → «Создать на клиенте».</li>
</ol>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bsl" data-theme="mono"><code data-language="bsl" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-token-keyword)">&#x26;НаКлиенте</span></span>
<span data-line=""><span style="color:var(--shiki-token-keyword)">Процедура</span><span style="color:var(--shiki-token-function)"> ТоварыПослеУдаления</span><span style="color:var(--shiki-foreground)">(Элемент)</span></span>
<span data-line=""><span style="color:var(--shiki-foreground)">	ПересчитатьИтогТоваров()</span><span style="color:var(--shiki-token-keyword)">;</span></span>
<span data-line=""><span style="color:var(--shiki-token-keyword)">КонецПроцедуры</span></span></code></pre></figure>
<p>Именно <strong>После</strong>удаления: в событии <code>ПередУдалением</code> строка ещё в коллекции, и итог посчитался бы вместе с ней. Для собственной кнопки удаления из урока 09 вызываем <code>ПересчитатьИтогТоваров()</code> сразу после <code>Удалить</code>.</p>
<h2 id="открытие-формы">Открытие формы</h2>
<p>В <code>ПриСозданииНаСервере</code> (урок 07) итог уже считается: <code>ИтогТоваров = Объект.Товары.Итог("Сумма");</code>. Клиентскую процедуру <code>ПересчитатьИтогТоваров()</code> оттуда вызвать нельзя — она <code>&#x26;НаКлиенте</code>, а событие серверное. Поэтому оставляем серверную строку как есть.</p>
<p>Важное правило: при открытии <strong>складываем</strong> существующие суммы, но <strong>не пересчитываем</strong> строки. Если открыть накладную годичной давности и пересчитать строки по формуле, можно незаметно изменить исторический документ — например, если раньше суммы округлялись иначе.</p>
<h2 id="команда-пересчитать-товары">Команда «Пересчитать товары»</h2>
<p>Иногда пользователю нужно пересчитать всё разом (например, после массовой правки цен). Создаём команду <code>ПересчитатьВсеТовары</code> с кнопкой:</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bsl" data-theme="mono"><code data-language="bsl" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-token-keyword)">&#x26;НаКлиенте</span></span>
<span data-line=""><span style="color:var(--shiki-token-keyword)">Процедура</span><span style="color:var(--shiki-token-function)"> ПересчитатьВсеТовары</span><span style="color:var(--shiki-foreground)">(Команда)</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:var(--shiki-token-keyword)">	Для Каждого</span><span style="color:var(--shiki-foreground)"> СтрокаТовара </span><span style="color:var(--shiki-token-keyword)">Из</span><span style="color:var(--shiki-foreground)"> Объект.Товары </span><span style="color:var(--shiki-token-keyword)">Цикл</span></span>
<span data-line=""><span style="color:var(--shiki-foreground)">		ПересчитатьСтрокуТоваров(СтрокаТовара)</span><span style="color:var(--shiki-token-keyword)">;</span></span>
<span data-line=""><span style="color:var(--shiki-token-keyword)">	КонецЦикла;</span></span>
<span data-line=""><span style="color:var(--shiki-foreground)">	ПересчитатьИтогТоваров()</span><span style="color:var(--shiki-token-keyword)">;</span><span style="color:var(--shiki-token-comment)">     // один раз после цикла, а не в каждой итерации</span></span>
<span data-line=""><span style="color:var(--shiki-foreground)">	Модифицированность </span><span style="color:var(--shiki-token-keyword)">=</span><span style="color:var(--shiki-token-constant)"> Истина</span><span style="color:var(--shiki-token-keyword)">;</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:var(--shiki-token-keyword)">КонецПроцедуры</span></span></code></pre></figure>
<p>Итог считаем <strong>один раз после</strong> цикла: считать его на каждой строке бессмысленно — промежуточные значения никто не увидит.</p>
<p>Обязательный пересчёт при записи (чтобы суммы были верными, даже если документ записала обработка) добавим на сервере в <a href="/restart/l/04/13/" data-internal="true">13. Запись из формы и события записи</a>. Когда формула устоится, её можно вынести в общий модуль «Клиент + Сервер», чтобы использовать и в форме, и в модуле объекта (<a href="/restart/l/02/26/" data-internal="true">26. Общие модули</a>).</p>
