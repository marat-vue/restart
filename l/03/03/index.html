Выбор полей, псевдонимы и сортировка

Коротко

ВЫБРАТЬ поля ИЗ источник КАК Псевдоним УПОРЯДОЧИТЬ ПО …. КАК задаёт имена колонок и таблиц. Без УПОРЯДОЧИТЬ ПО порядок строк не гарантирован. ПЕРВЫЕ N — ограничить количество строк, РАЗЛИЧНЫЕ — убрать полные дубли выбранных полей.

Из чего состоит простейший запрос

Любой запрос начинается с двух обязательных частей: что выбрать и откуда.

Прочитаем запрос как обычное предложение: «Выбрать ссылку (назовём её Товар) и наименование (назовём Название) из справочника Номенклатура (коротко — Н), упорядочить по названию».

ЧастьОбязательна?Что задаёт
ВЫБРАТЬ …ДаСписок колонок результата через запятую
ИЗ …ДаТаблицу-источник
УПОРЯДОЧИТЬ ПО …НетПорядок строк

Ключевые слова пишут заглавными буквами — так принято, чтобы отличать их от имён. Для платформы регистр не важен: выбрать тоже сработает. Переносы строк и отступы — только для удобства чтения.

Псевдонимы: слово КАК

Псевдоним — это короткое или более понятное имя, которое мы даём таблице или колонке внутри запроса.

Псевдоним таблицы — Справочник.Номенклатура КАК Н. Дальше вместо длинного Справочник.Номенклатура.Наименование пишем Н.Наименование. Буква Н — наш выбор: можно написать КАК Номенклатура или КАК Товары. Короткие псевдонимы удобны, длинные — понятнее; главное — единообразие.

Если псевдоним поля не указать, платформа придумает имя сама (обычно совпадающее с именем поля). Но лучше задавать псевдонимы явно — так понятнее, какие колонки получит код.

Псевдоним ничего не переименовывает в базе

КАК Название меняет только имя колонки в этом результате. Реквизит справочника по-прежнему называется Наименование, и после Н. мы пишем именно его настоящее имя.

Где можно использовать псевдоним поля:

  • в УПОРЯДОЧИТЬ ПО — можно (УПОРЯДОЧИТЬ ПО Название);
  • в ГДЕ — нельзя: там пишем исходное поле (ГДЕ Н.Наименование = …). Условие проверяется до того, как колонки получили новые имена.

Порядок строк: УПОРЯДОЧИТЬ ПО

  • ВОЗР — по возрастанию: А→Я, 1→9, раньше→позже. Это направление по умолчанию, слово можно не писать.
  • УБЫВ — по убыванию.
  • Несколько полей через запятую: сначала сортируем по первому; строки с одинаковым первым значением — по второму, и так далее.

Пример результата для товаров «Чайник» (код 2), «Блендер» (код 3), «Чайник» (код 5):

НазваниеКод
Блендер000000003
Чайник000000005
Чайник000000002

Два «Чайника» стоят рядом, и между ними порядок решает код — по убыванию.

Без

УПОРЯДОЧИТЬ ПО порядок не гарантирован Если сортировку не указать, строки придут «как удобнее базе». Сегодня это может быть порядок создания, завтра — другой. Даже если при нескольких запусках порядок совпал, рассчитывать на него нельзя. Нужен порядок — всегда пишем УПОРЯДОЧИТЬ ПО.

Только первые N строк: ПЕРВЫЕ

ПЕРВЫЕ 5 оставляет пять строк после сортировки. Без сортировки «первые пять» — это случайные пять. Чтобы при одинаковых названиях выбор был стабильным, добавляем в сортировку ещё одно поле, например код.

Типичное применение — «топ-10 товаров по выручке» или «проверить, есть ли хоть одна запись» (ПЕРВЫЕ 1).

Без повторов: РАЗЛИЧНЫЕ

ВЫБРАТЬ РАЗЛИЧНЫЕ убирает строки, у которых совпали все выбранные колонки.

Допустим, в справочнике два разных товара с одинаковым названием «Чайник» (разные поставщики) и один «Блендер»:

ЗапросРезультат
ВЫБРАТЬ РАЗЛИЧНЫЕ Н.Наименование …Блендер, Чайник — 2 строки: два чайника слились в один
ВЫБРАТЬ РАЗЛИЧНЫЕ Н.Ссылка, Н.Наименование …3 строки: ссылки у чайников разные, строки не одинаковые

Отсюда опасность: если выбрать только название, разные товары «склеятся», и вы потеряете один из них.

Внимание

РАЗЛИЧНЫЕ — не лекарство от дублей Если в результате неожиданно появились повторы, почти всегда виновато неправильное соединение таблиц (08. Соединения таблиц). РАЗЛИЧНЫЕ спрячет симптом, но суммы при этом останутся неверными. Сначала выясняем, откуда взялись повторы.

Вкладка «Дополнительно» конструктора: «Первые 5» (ПЕРВЫЕ 5) и «Без повторяющихся» (РАЗЛИЧНЫЕ). Флажок «Разрешенные» добавляет РАЗРЕШЕННЫЕ — о нём в 18. Проверка и ускорение запросов.

Проверка

  1. Выполните запрос с ВЫБРАТЬ РАЗЛИЧНЫЕ Н.Наименование. Посчитайте строки.
  2. Добавьте в выбор Н.Ссылка. Если строк стало больше — значит, в справочнике есть товары с одинаковыми названиями.
  3. Уберите УПОРЯДОЧИТЬ ПО и добавьте ПЕРВЫЕ 2 — убедитесь, что «первые» без сортировки не несут смысла.
Проверь себя

  1. Гарантирован ли порядок строк без УПОРЯДОЧИТЬ ПО?

  2. Чем опасен РАЗЛИЧНЫЕ при выборе только наименования?

  3. Исправляет ли РАЗЛИЧНЫЕ ошибку соединения?

Ответы
  1. Нет, даже если при тестах он совпадал.
  2. Разные товары с одинаковым названием сольются в одну строку.
  3. Нет, только маскирует. Нужно найти причину размножения строк.
