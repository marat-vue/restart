Выражения и функции языка запросов

Коротко

В запросе можно вычислять поля (Т.Количество * Т.Цена), использовать ВЫБОР КОГДА … ТОГДА … ИНАЧЕ … КОНЕЦ, функции дат (НАЧАЛОПЕРИОДА, КОНЕЦПЕРИОДА, ДОБАВИТЬКДАТЕ), строк (ПОДСТРОКА) и приведения (ВЫРАЗИТЬ). Функции языка запросов, встроенного языка и выражений СКД — разные наборы.

Вычисляемая колонка

В ВЫБРАТЬ можно писать не только поля, но и выражения — формулы над полями. Каждая строка результата получит своё вычисленное значение, как формула в ячейке Excel, протянутая вниз.

ТоварКоличествоЦенаРасчётнаяСумма
Чайник2150300
Кружка350150

Доступны обычные арифметические операции: + - * /. Псевдоним (КАК РасчётнаяСумма) для выражения обязателен по смыслу: иначе колонка получит безликое имя вроде Поле1.

Вычисление происходит только в результате запроса. Записанное поле Т.Сумма в базе не меняется — запрос ничего не изменяет.

Условие внутри колонки: ВЫБОР

Иногда значение колонки зависит от условия. Для этого есть конструкция ВЫБОР — аналог Если встроенного языка и тернарного ?():

Читаем: «когда количество равно нулю — тогда 0, иначе сумма, делённая на количество».

Деление на ноль

Если в какой-то строке количество равно 0, выражение Т.Сумма / Т.Количество вызовет ошибку деления на ноль, и весь запрос не выполнится. Поэтому деление почти всегда оборачиваем в ВЫБОР, как в примере выше.

Три похожих, но разных языка

В 1С функции с похожими названиями есть в трёх местах, и они не взаимозаменяемы:

ГдеКонец дняКак пишется период
Встроенный язык (код модуля)КонецДня(Дата)Отдельная функция для каждого периода
Язык запросов (текст запроса)КОНЕЦПЕРИОДА(Дата, ДЕНЬ)Ключевое слово без кавычек
Выражения СКД (настройки отчёта)КонецПериода(&Дата, "День")Строка в кавычках

Написать в тексте запроса КонецДня(Н.Дата) нельзя — такой функции в языке запросов нет. Либо используем КОНЕЦПЕРИОДА в запросе, либо считаем значение в коде и передаём параметром.

Даты и другие меняющиеся значения лучше передавать параметрами — так запрос не придётся переписывать.

Проверка

  1. Выведите дату документов и НАЧАЛОПЕРИОДА(Н.Дата, МЕСЯЦ) — все октябрьские получат 01.10.2026 00:00:00.
  2. Добавьте колонку с ВЫБОР и категорией продажи — проверьте накладную ровно на 1000 ₽: она должна попасть в «Средняя».
  3. Создайте строку товара с количеством 0 и выведите Т.Сумма / Т.Количество без ВЫБОР — увидите ошибку деления на ноль.

  1. Как защититься от деления на ноль в запросе?

Ответы
  1. ВЫБОР КОГДА Количество = 0 ТОГДА 0 ИНАЧЕ Сумма / Количество КОНЕЦ.
  2. Нет; в запросе — КОНЕЦПЕРИОДА(Дата, ДЕНЬ), либо считаем границу в коде и передаём параметром.
  3. ""Продажа"" — удвоенные кавычки.
