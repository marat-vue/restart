<div class="callout-title">Коротко</div>
<div class="callout-body"><p>Кроме списка, СКД строит <strong>таблицы</strong> (группировки по строкам и колонкам) и <strong>диаграммы</strong> (точки и серии). <strong>Вариант</strong> — сохранённые настройки на той же схеме: один запрос — несколько представлений. Пользовательские настройки могут перекрывать настройки разработчика.</p></div>

<h2 id="одна-схема--много-видов-отчёта">Одна схема — много видов отчёта</h2>
<p>До сих пор наш отчёт был <strong>списком</strong>: строки вниз, колонки — поля. Но те же данные часто удобнее показать иначе:</p>

























<div class="table-wrap"><table><thead><tr><th>Вид</th><th>Как выглядит</th><th>Когда удобен</th></tr></thead><tbody><tr><td><strong>Список</strong></td><td>Строки с группировками вниз</td><td>Подробный разбор, детальные записи</td></tr><tr><td><strong>Таблица</strong></td><td>Значения и в строках, и в колонках — как сводная таблица Excel</td><td>Сравнить товары по покупателям или по месяцам</td></tr><tr><td><strong>Диаграмма</strong></td><td>Столбики, линии, круги</td><td>Быстро увидеть, кто лидер</td></tr></tbody></table></div>
<p>Всё это строится на <strong>той же схеме</strong> — с тем же запросом и ресурсами. Меняются только <strong>настройки</strong>.</p>
<h2 id="таблица-товары-по-строкам-покупатели-по-колонкам">Таблица: товары по строкам, покупатели по колонкам</h2>
<p>Хотим получить:</p>





























<div class="table-wrap"><table><thead><tr><th>Номенклатура</th><th>Ромашка</th><th>Петров</th><th>Итого</th></tr></thead><tbody><tr><td>Чайник</td><td>300</td><td>200</td><td>500</td></tr><tr><td>Блендер</td><td>—</td><td>300</td><td>300</td></tr><tr><td><strong>Итого</strong></td><td><strong>300</strong></td><td><strong>500</strong></td><td><strong>800</strong></td></tr></tbody></table></div>
<p>Чтобы не испортить основной вид отчёта, сделаем это <strong>отдельным вариантом</strong>.</p>
<ol>
<li>На вкладке <strong>Настройки</strong> слева вверху — список <strong>вариантов</strong>. Кнопкой <strong>Добавить</strong> создаём вариант: имя <code>ПоПокупателям</code>, представление «Продажи по покупателям».</li>
<li>Выделяем новый вариант. В его дереве структуры выделяем корень <strong>Отчёт</strong> → <strong>ПКМ → Новая таблица</strong>.</li>
<li>У таблицы появятся два узла: <strong>Строки</strong> и <strong>Колонки</strong>.</li>
<li>Выделяем <strong>Строки</strong> → <strong>ПКМ → Новая группировка</strong> → поле <code>Номенклатура</code>.</li>
<li>Выделяем <strong>Колонки</strong> → <strong>ПКМ → Новая группировка</strong> → поле <code>Контрагент</code>.</li>
<li>Выделяем саму <strong>таблицу</strong> → внизу <strong>Выбранные поля</strong> → добавляем ресурс <code>Выручка</code>.</li>
</ol>

Под деревом переключатель «Настройки: Отчёт / Таблица» — чьи настройки показаны в закладках.</em></p>
<p>В пересечении строки товара и колонки покупателя СКД покажет выручку этого покупателя по этому товару. Итоги по строкам и колонкам посчитаются сами — благодаря ресурсу.</p>
<h2 id="диаграмма">Диаграмма</h2>
<p>Создаём ещё один вариант — <code>ДиаграммаПродаж</code>.</p>
<ol>
<li>В структуре: <strong>Отчёт → ПКМ → Новая диаграмма</strong>.</li>
<li>У диаграммы два узла: <strong>Точки</strong> и <strong>Серии</strong>.</li>
<li>В <strong>Точки</strong> добавляем группировку <code>Номенклатура</code> — это подписи по горизонтальной оси (каждый товар — столбик).</li>
<li>В <strong>Серии</strong> при необходимости добавляем <code>Контрагент</code> — тогда у каждого товара будет несколько столбиков разного цвета, по одному на покупателя.</li>
<li>Выделяем диаграмму → <strong>Выбранные поля</strong> → <code>Выручка</code> (высота столбиков).</li>
<li>На закладке <strong>Другие настройки</strong> диаграммы выбираем <strong>Тип диаграммы</strong> — «Гистограмма».</li>
</ol>

























<div class="table-wrap"><table><thead><tr><th>Узел диаграммы</th><th>Что это</th><th>Пример</th></tr></thead><tbody><tr><td><strong>Точки</strong></td><td>Категории по оси X</td><td>Чайник, Блендер</td></tr><tr><td><strong>Серии</strong></td><td>Наборы значений разного цвета внутри каждой точки</td><td>Ромашка (синий), Петров (оранжевый)</td></tr><tr><td><strong>Выбранные поля</strong></td><td>Что откладывать по оси Y</td><td>Выручка</td></tr></tbody></table></div>
<p>Если товаров сотни, диаграмма превратится в «забор» — ограничьте их отбором или выводите только первые N по выручке.</p>
<h2 id="варианты-отчёта">Варианты отчёта</h2>
<p><strong>Вариант</strong> — именованный набор настроек на одной схеме. Новый вариант <strong>не требует</strong> нового запроса, если нужные поля уже есть в наборе.</p>
<p>В режиме пользователя:</p>
<ul>
<li>кнопка <strong>Выбрать вариант…</strong> (или <strong>Ещё → Выбрать вариант</strong>) переключает варианты;</li>
<li><strong>Ещё → Изменить вариант…</strong> открывает полный редактор настроек;</li>
<li><strong>Ещё → Сохранить вариант…</strong> сохраняет собственный вариант пользователя (если это позволяет конфигурация).</li>
</ul>
