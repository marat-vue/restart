<div class="callout-title">Коротко</div>
<div class="callout-body"><p>Запрос можно собрать в <strong>конструкторе</strong> (таблицы → поля → порядок) или написать текстом. В коде: <code>Запрос = Новый Запрос; Запрос.Текст = "…"; Результат = Запрос.Выполнить();</code> → <code>Выгрузить()</code> (таблица значений) или <code>Выбрать()</code> (выборка). Запросы выполняем <strong>на сервере</strong>; символ <code>|</code> — продолжение строки встроенного языка, а не часть запроса.</p></div>

<h2 id="подготовим-место-для-кода">Подготовим место для кода</h2>
<p>Запрос выполняется на сервере, поэтому код запроса пишем в серверном модуле. Создадим для учебных запросов отдельный общий модуль:</p>
<ol>
<li>В дереве конфигурации раскрываем <strong>Общие → Общие модули → ПКМ → Добавить</strong>.</li>
<li>Имя — <code>УчебныеЗапросыСервер</code>.</li>
<li>В свойствах модуля оставляем флажок <strong>Сервер</strong>, остальные флажки (Клиент, Вызов сервера, Глобальный) снимаем.</li>
</ol>
<p>Подробно об общих модулях и флажках — в <a href="/restart/l/02/26/" data-internal="true">26. Общие модули и контекст выполнения</a>.</p>
<h2 id="соберём-запрос-визуально">Соберём запрос визуально</h2>
<p>Текст запроса можно написать вручную, но новичку проще собрать его мышкой в <strong>конструкторе запроса</strong>. Конструктор открывается прямо из текста модуля:</p>
<ol>
<li>Открываем модуль <code>УчебныеЗапросыСервер</code>, ставим курсор на пустую строку.</li>
<li><strong>ПКМ → Конструктор запроса…</strong> Платформа сообщит «Не найден текст запроса. Создать новый запрос?» — отвечаем <strong>Да</strong>.</li>
</ol>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/03.%20%D0%AF%D0%B7%D1%8B%D0%BA%20%D0%B7%D0%B0%D0%BF%D1%80%D0%BE%D1%81%D0%BE%D0%B2%20%D0%B8%20%D0%A1%D0%9A%D0%94/02-%D0%92%D1%8B%D0%B7%D0%BE%D0%B2-%D0%BA%D0%BE%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D0%BE%D1%80%D0%B0-%D0%B8%D0%B7-%D0%BC%D0%BE%D0%B4%D1%83%D0%BB%D1%8F.png" alt="02-Вызов-конструктора-из-модуля.png" loading="lazy" decoding="async"></p>
<p><em>Контекстное меню в тексте модуля: пункт «Конструктор запроса…». Пункт «…с обработкой результата» дополнительно сгенерирует код обхода результата.</em></p>
<ol start="3">
<li>В левом списке <strong>База данных</strong> раскрываем <strong>Справочники</strong>. Двойным щелчком по <code>Номенклатура</code> переносим её в средний список <strong>Таблицы</strong>.</li>
<li>Раскрываем таблицу <code>Номенклатура</code> в среднем списке. Двойным щелчком переносим поля <code>Ссылка</code>, <code>Код</code>, <code>Наименование</code> в правый список <strong>Поля</strong>. Порядок полей в списке — это порядок колонок результата; его можно поменять стрелками.</li>
</ol>
<p><img src="/restart/vault/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/03.%20%D0%AF%D0%B7%D1%8B%D0%BA%20%D0%B7%D0%B0%D0%BF%D1%80%D0%BE%D1%81%D0%BE%D0%B2%20%D0%B8%20%D0%A1%D0%9A%D0%94/02-%D0%9A%D0%BE%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D0%BE%D1%80-%D0%9D%D0%BE%D0%BC%D0%B5%D0%BD%D0%BA%D0%BB%D0%B0%D1%82%D1%83%D1%80%D0%B0-%D0%BF%D0%BE%D0%BB%D1%8F.png" alt="02-Конструктор-Номенклатура-поля.png" loading="lazy" decoding="async"></p>
<p><em>Вкладка «Таблицы и поля»: слева — все таблицы базы, в центре — выбранная таблица <code>Номенклатура</code> и её поля, справа — поля, которые попадут в результат запроса.</em></p>
<ol start="5">
<li>На вкладке <strong>Порядок</strong> переносим <code>Наименование</code> вправо, направление — <strong>Возрастание</strong>.</li>
<li>Нажимаем <strong>ОК</strong>. Конструктор вставит в модуль готовый текст запроса — уже с символами <code>|</code> в начале строк.</li>
</ol>
<p>Конструктор <strong>только строит текст</strong>, результат он не показывает. Чтобы увидеть данные, запрос нужно выполнить из кода — этим займёмся ниже. Тот же конструктор открывается и из других мест: из схемы компоновки данных отчёта (<a href="/restart/l/03/20/" data-internal="true">20. Создание отчёта и набора данных</a>) и из свойства «Текст запроса» динамического списка.</p>
<div class="callout callout-tip" data-callout="tip">
<div class="callout-title">Повторное редактирование</div>
<div class="callout-body"><p>Если позже понадобится изменить запрос, ставим курсор <strong>внутрь</strong> уже существующего текста запроса и снова вызываем <strong>ПКМ → Конструктор запроса…</strong> — конструктор откроется с текущими таблицами и полями.</p></div>
</div>

<h3 id="разберём-по-строкам">Разберём по строкам</h3>

































<div class="table-wrap"><table><thead><tr><th>Строка</th><th>Что происходит</th></tr></thead><tbody><tr><td><code>Запрос = Новый Запрос;</code></td><td>Создаём объект «Запрос» — пока пустой, без текста</td></tr><tr><td><code>Запрос.Текст = "ВЫБРАТЬ …";</code></td><td>Кладём в него текст на <strong>языке запросов</strong>. <h3 id="выгрузить-или-выбрать"><code>Выгрузить()</code> или <code>Выбрать()</code>?</h3>
<p>У результата запроса два основных способа получить строки:</p>

























<div class="table-wrap"><table><thead><tr><th></th><th><code>Выгрузить()</code></th><th><code>Выбрать()</code></th></tr></thead><tbody><tr><td>Что возвращает</td><td><code>ТаблицаЗначений</code> — все строки сразу</td><td><strong>Выборку</strong> — курсор, который идёт по строкам по одной</td></tr><tr><td>Память</td><td>Держит весь результат</td><td>Держит одну текущую строку</td></tr><tr><td>Удобно, когда</td><td>Таблицу нужно передать дальше, отсортировать, найти в ней строку, вывести на форму</td><td>Нужно просто пройти по строкам один раз</td></tr></tbody></table></div>
<p>Обход выборки выглядит так:</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bsl" data-theme="mono"><code data-language="bsl" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-foreground)">Выборка </span><span style="color:var(--shiki-token-keyword)">=</span><span style="color:var(--shiki-foreground)"> Запрос.Выполнить().Выбрать()</span><span style="color:var(--shiki-token-keyword)">;</span></span>
<span data-line=""><span style="color:var(--shiki-token-keyword)">Пока</span><span style="color:var(--shiki-foreground)"> Выборка.Следующий() </span><span style="color:var(--shiki-token-keyword)">Цикл</span><span style="color:var(--shiki-token-comment)">          // переходим к очередной строке, пока они есть</span></span>
<span data-line=""><span style="color:var(--shiki-token-function)">    Сообщить</span><span style="color:var(--shiki-foreground)">(Выборка.Наименование)</span><span style="color:var(--shiki-token-keyword)">;</span><span style="color:var(--shiki-token-comment)">    // поля строки — по именам колонок (псевдонимам)</span></span>
<span data-line=""><span style="color:var(--shiki-token-keyword)">КонецЦикла;</span></span></code></pre></figure>
<p><code>Следующий()</code> возвращает <code>Истина</code>, если удалось перейти к следующей строке, и <code>Ложь</code>, когда строки кончились. Для небольших результатов оба способа хороши; для больших (десятки тысяч строк) выборка экономнее.</p>
<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">Запрос — только на сервере</div>
<div class="callout-body"><p>Объект <code>Запрос</code> существует <strong>только на сервере</strong>. Если написать <code>Новый Запрос</code> в процедуре с директивой <code>&#x26;НаКлиенте</code>, получим ошибку «Тип не определён (Запрос)». Поэтому функция лежит в серверном общем модуле, а кнопка формы вызывает её через серверную процедуру.</p></div>
</div>

<p>Внутри функции получаем таблицу значений с тремя колонками; на форме выводятся сообщения с количеством строк и названиями. Например, для трёх товаров увидим:</p>

<div class="callout callout-tip" data-callout="tip">
<div class="callout-title">Это наш полигон на весь раздел</div>
<div class="callout-body"><p>Обработка <code>УчебныеЗапросы</code> и модуль <code>УчебныеЗапросыСервер</code> пригодятся в каждом следующем уроке. Чтобы проверить новый запрос, заменяйте текст в функции (или добавляйте новую функцию и кнопку) — не нужно каждый раз заново создавать обработку. Если справочник пустой, строк будет 0 — это нормальный результат. Свойство <code>Код</code> в этом примере имеет строковый тип, как в учебной базе.</p></div>
</div>
<p>Вертикальная черта <code>|</code> продолжает <strong>строку встроенного языка</strong>. В чистый текст запроса в СКД её не копируем. <code>Н</code> — короткое имя таблицы, <code>КАК Товар</code> — имя колонки результата.</p>
