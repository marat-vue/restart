Первый запрос в конструкторе и в коде

Коротко

Запрос можно собрать в конструкторе (таблицы → поля → порядок) или написать текстом. В коде: Запрос = Новый Запрос; Запрос.Текст = "…"; Результат = Запрос.Выполнить(); → Выгрузить() (таблица значений) или Выбрать() (выборка). Запросы выполняем на сервере; символ | — продолжение строки встроенного языка, а не часть запроса.

Подготовим место для кода

Запрос выполняется на сервере, поэтому код запроса пишем в серверном модуле. Создадим для учебных запросов отдельный общий модуль:

  1. В дереве конфигурации раскрываем Общие → Общие модули → ПКМ → Добавить.
  2. Имя — УчебныеЗапросыСервер.
  3. В свойствах модуля оставляем флажок Сервер, остальные флажки (Клиент, Вызов сервера, Глобальный) снимаем.

Подробно об общих модулях и флажках — в 26. Общие модули и контекст выполнения.

Соберём запрос визуально

Текст запроса можно написать вручную, но новичку проще собрать его мышкой в конструкторе запроса. Конструктор открывается прямо из текста модуля:

  1. Открываем модуль УчебныеЗапросыСервер, ставим курсор на пустую строку.
  2. ПКМ → Конструктор запроса… Платформа сообщит «Не найден текст запроса. Создать новый запрос?» — отвечаем Да.

Контекстное меню в тексте модуля: пункт «Конструктор запроса…». Пункт «…с обработкой результата» дополнительно сгенерирует код обхода результата.

  1. В левом списке База данных раскрываем Справочники. Двойным щелчком по Номенклатура переносим её в средний список Таблицы.
  2. Раскрываем таблицу Номенклатура в среднем списке. Двойным щелчком переносим поля Ссылка, Код, Наименование в правый список Поля. Порядок полей в списке — это порядок колонок результата; его можно поменять стрелками.

Вкладка «Таблицы и поля»: слева — все таблицы базы, в центре — выбранная таблица Номенклатура и её поля, справа — поля, которые попадут в результат запроса.

  1. На вкладке Порядок переносим Наименование вправо, направление — Возрастание.
  2. Нажимаем ОК. Конструктор вставит в модуль готовый текст запроса — уже с символами | в начале строк.

Конструктор только строит текст, результат он не показывает. Чтобы увидеть данные, запрос нужно выполнить из кода — этим займёмся ниже. Тот же конструктор открывается и из других мест: из схемы компоновки данных отчёта (20. Создание отчёта и набора данных) и из свойства «Текст запроса» динамического списка.

Повторное редактирование

Если позже понадобится изменить запрос, ставим курсор внутрь уже существующего текста запроса и снова вызываем ПКМ → Конструктор запроса… — конструктор откроется с текущими таблицами и полями.

Выполним в коде

Оформим запрос в функцию модуля УчебныеЗапросыСервер. Текст, который вставил конструктор, отличается от примера ниже только именами: здесь мы дали таблице короткий псевдоним Н (переименование таблицы в среднем списке), а полю Ссылка — имя колонки Товар (вкладка Объединения/Псевдонимы). Подробнее о псевдонимах — в 03. Выбор полей, псевдонимы и сортировка.

Внутри текста запроса тоже всё имеет смысл:

Выгрузить() или Выбрать()?

У результата запроса два основных способа получить строки:

Выгрузить()Выбрать()
Что возвращаетТаблицаЗначений — все строки сразуВыборку — курсор, который идёт по строкам по одной
ПамятьДержит весь результатДержит одну текущую строку
Удобно, когдаТаблицу нужно передать дальше, отсортировать, найти в ней строку, вывести на формуНужно просто пройти по строкам один раз

Следующий() возвращает Истина, если удалось перейти к следующей строке, и Ложь, когда строки кончились. Для небольших результатов оба способа хороши; для больших (десятки тысяч строк) выборка экономнее.

Запрос — только на сервере

Объект Запрос существует только на сервере. Если написать Новый Запрос в процедуре с директивой &НаКлиенте, получим ошибку «Тип не определён (Запрос)». Поэтому функция лежит в серверном общем модуле, а кнопка формы вызывает её через серверную процедуру.

Запуск с кнопки

Если учебной обработки ещё нет:

  1. Обработки → Добавить, имя УчебныеЗапросы.
  2. Формы → Добавить, создаём основную управляемую форму обработки.
  3. В редакторе формы на вкладке Команды создаём ПоказатьНоменклатуру.
  4. У команды в свойстве Действие создаём клиентский обработчик. Перетаскиваем команду в дерево Элементы, чтобы появилась кнопка.
  5. В модуле формы размещаем обработчик и серверную процедуру:
  1. Сохраняем конфигурацию, обновляем конфигурацию БД и запускаем 1С:Предприятие. Под административной ролью открываем Сервис и настройки → Функции для технического специалиста → Обработки → Учебные запросы, нажимаем кнопку.

Внутри функции получаем таблицу значений с тремя колонками; на форме выводятся сообщения с количеством строк и названиями. Например, для трёх товаров увидим:

Обработка УчебныеЗапросы и модуль УчебныеЗапросыСервер пригодятся в каждом следующем уроке. Чтобы проверить новый запрос, заменяйте текст в функции (или добавляйте новую функцию и кнопку) — не нужно каждый раз заново создавать обработку. Если справочник пустой, строк будет 0 — это нормальный результат. Свойство Код в этом примере имеет строковый тип, как в учебной базе.

Вертикальная черта | продолжает строку встроенного языка. В чистый текст запроса в СКД её не копируем. Н — короткое имя таблицы, КАК Товар — имя колонки результата.

Проверь себя

  1. Где выполняется Запрос.Выполнить() в управляемом приложении?

  2. Чем Выгрузить() отличается от Выбрать()?

  3. Почему при копировании текста в СКД нужно убрать |?

Ответы
  1. Только на сервере.
  2. Выгрузить возвращает всю таблицу значений в память, Выбрать — выборку для последовательного обхода.
  3. Это синтаксис многострочной строки встроенного языка, а не языка запросов.
