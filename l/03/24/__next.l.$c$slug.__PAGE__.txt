<div class="callout-title">Коротко</div>
<div class="callout-body"><p><strong>Отбор</strong> СКД — условие компоновки (может перейти в запрос), <strong>параметр</strong> — значение для запроса/выражения. Сортировку групп задают на уровне группировки. Элементы, которые пользователь может менять, включают в <strong>пользовательские настройки</strong>. Отбор отчёта не заменяет права доступа.</p></div>

<h2 id="отбор-показать-только-часть-данных">Отбор: показать только часть данных</h2>
<p>Отчёт за октябрь показывает продажи всем покупателям. Менеджер хочет видеть только «Ромашку». Переписывать запрос не нужно: в СКД есть <strong>отбор</strong> — условие, которое можно включать и выключать в настройках, в том числе самому пользователю.</p>
<h2 id="шаг-1-добавляем-отбор-по-покупателю">Шаг 1. Добавляем отбор по покупателю</h2>
<ol>
<li>На вкладке <strong>Настройки</strong> выделяем корень <strong>Отчёт</strong> (отбор будет действовать на весь отчёт).</li>
<li>Внизу открываем закладку <strong>Отбор</strong>. Слева — доступные поля, справа — условия.</li>
<li>Двойным щелчком переносим <code>Контрагент</code> вправо.</li>
<li><strong>Вид сравнения</strong> — <code>Равно</code>.</li>
<li><strong>Значение</strong> — выбираем контрагента кнопкой выбора из справочника. Не вводим название текстом: отбор сравнивает <strong>ссылки</strong>.</li>
<li>Флажок слева от строки — <strong>использование</strong> условия. Включён — отбор работает, выключен — условие «спит».</li>
</ol>
<p>Виды сравнения, которые пригодятся:</p>








































<div class="table-wrap"><table><thead><tr><th>Вид сравнения</th><th>Смысл</th><th>Пример</th></tr></thead><tbody><tr><td>Равно / Не равно</td><td>Одно значение</td><td>Покупатель = Ромашка</td></tr><tr><td>В списке / Не в списке</td><td>Несколько значений</td><td>Покупатель в списке (Ромашка, Петров)</td></tr><tr><td>В группе</td><td>Элемент группы иерархического справочника</td><td>Товар в группе «Чайники»</td></tr><tr><td>Заполнено / Не заполнено</td><td>Есть ли значение</td><td>Покупатель не заполнен</td></tr><tr><td>Больше / Меньше</td><td>Для чисел и дат</td><td>Выручка больше 1000</td></tr><tr><td>Содержит</td><td>Часть строки</td><td>Наименование содержит «чай»</td></tr></tbody></table></div>
<h3 id="несколько-условий">Несколько условий</h3>
<p>Условия в списке по умолчанию соединяются через <strong>И</strong>. Чтобы получить «Ромашка <strong>или</strong> Петров», создаём <strong>группу ИЛИ</strong>: кнопка <strong>Сгруппировать условия</strong> → тип группы «Группа ИЛИ» → переносим в неё оба условия. Хотя для этого случая проще вид сравнения «В списке».</p>
<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">«Выключено» ≠ «равно пустому»</div>
<div class="callout-body"><p>Если пользователю не нужен отбор, условие должно быть <strong>выключено</strong> (флажок снят). Включённое условие «Контрагент = <em>пусто</em>» — это не «без отбора», а поиск продаж <strong>с незаполненным</strong> покупателем. Скорее всего, отчёт будет пустым.</p></div>
</div>
<h2 id="шаг-2-даём-пользователю-менять-отбор">Шаг 2. Даём пользователю менять отбор</h2>
<p>По умолчанию отбор задаёт разработчик, а пользователь его не видит. Чтобы покупателя можно было выбрать на форме отчёта:</p>
<ol>
<li>Выделяем строку условия → <strong>ПКМ → Свойства элемента пользовательских настроек</strong>.</li>
<li>Включаем <strong>Включать в пользовательские настройки</strong>.</li>
<li>Режим — <strong>Быстрый доступ</strong> (поле в шапке отчёта) или <strong>Обычный</strong> (в окне «Настройки…»).</li>
<li>Само условие оставляем <strong>выключенным</strong>: пользователь включит его, когда понадобится.</li>
</ol>
<h2 id="сортировка">Сортировка</h2>
<p>Задача: товары с наибольшей выручкой — сверху.</p>
<ol>
<li>Выделяем в дереве <strong>группировку <code>Номенклатура</code></strong> — не корень! Сортируем именно строки товаров.</li>
<li>Внизу закладка <strong>Сортировка</strong> → переносим <code>Выручка</code> → направление <strong>По убыванию</strong>.</li>
</ol>





















<div class="table-wrap"><table><thead><tr><th>Выделен узел</th><th>Что отсортируется</th></tr></thead><tbody><tr><td>Группировка <code>Номенклатура</code></td><td>Порядок <strong>товаров</strong> по их итоговой выручке</td></tr><tr><td><code>&#x3C;Детальные записи></code></td><td>Порядок строк <strong>внутри</strong> каждого товара</td></tr><tr><td>Корень «Отчёт»</td><td>Общий порядок для узлов, у которых своя сортировка не задана</td></tr></tbody></table></div>
<p>После формирования проверяем порядок именно <strong>групп</strong> товаров, а не только строк покупателей.</p>
<h2 id="отбор-и-параметр--в-чём-разница">Отбор и параметр — в чём разница</h2>






























<div class="table-wrap"><table><thead><tr><th></th><th>Параметр (<a href="/restart/l/03/22/" data-internal="true">22. Параметры периода в СКД</a>)</th><th>Отбор</th></tr></thead><tbody><tr><td>Что это</td><td>Значение, которое передаётся <strong>в запрос</strong> или формулу (<code>&#x26;НачалоПериода</code>)</td><td>Условие на <strong>поля</strong> отчёта</td></tr><tr><td>Где виден в схеме</td><td>Вкладка «Параметры»</td><td>Закладка «Отбор» в настройках</td></tr><tr><td>Пример</td><td>Период отчёта</td><td>Только покупатель Ромашка</td></tr><tr><td>Можно выключить</td><td>Нет — запрос без значения не выполнится</td><td>Да — флажком</td></tr></tbody></table></div>
<p>СКД умеет сама переносить отбор в запрос: условие «Контрагент = Ромашка» станет частью <code>ГДЕ</code> или параметров виртуальной таблицы. Поэтому отбор не означает, что СКД сначала читает все данные, а потом фильтрует.</p>
<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">Отбор отчёта — не защита данных</div>
<div class="callout-body"><p>Если менеджеру <strong>нельзя</strong> видеть чужих покупателей, отбор в отчёте не поможет: он его просто выключит. Ограничивать доступ нужно правами (RLS) — <a href="/restart/l/01/19/" data-internal="true">19. Пользователи и Роли</a>.</p></div>
</div>
<h2 id="что-видит-пользователь">Что видит пользователь</h2>
<p>В режиме 1С:Предприятия у формы отчёта:</p>
<ul>
<li>в шапке — элементы <strong>быстрого доступа</strong> (период, покупатель);</li>
<li>кнопка <strong>Настройки…</strong> — элементы «обычного» режима;</li>

<p><em>Полный редактор варианта в режиме пользователя: здесь можно добавлять доступные условия отбора.</em></p>
<h2 id="проверка">Проверка</h2>
<ol>
<li>Сформируйте отчёт без отбора — запишите общий итог.</li>
<li>Включите отбор «Контрагент = Ромашка» — остались только её продажи; итог уменьшился и не превышает общего.</li>
<li>Включите отбор с пустым значением — отчёт пустой (или только продажи без покупателя). Выключите отбор.</li>
<li>Задайте сортировку по выручке на группировке — товары выстроились по убыванию итогов.</li>
</ol>

<li>На вкладке «Сортировка» у группировки <code>Номенклатура</code>.</li>
<li>Параметр передаёт значение в запрос; отбор — условие компоновки, которое СКД применяет сама.</li>
