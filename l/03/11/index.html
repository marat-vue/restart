Итоги и обход результата запроса

Коротко

ИТОГИ СУММА(…) ПО ОБЩИЕ, Поле добавляет к детальным строкам строки итогов по уровням. Результат обходим Выбрать() (детали) или Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам, "Поле") (группа → вложенные детали). При ручном суммировании не смешиваем строки итогов и деталей.

Чем ИТОГИ отличается от группировки

СГРУППИРОВАТЬ ПО из прошлого урока заменяет подробные строки свёрнутыми: были продажи по покупателям — остались только суммы по товарам. Подробности пропадают.

ИТОГИ работает иначе: подробные строки остаются, а между ними появляются дополнительные строки итогов. Получается как в бухгалтерской ведомости:

СГРУППИРОВАТЬ ПОИТОГИ … ПО
Подробные строкиИсчезаютОстаются
Итоги по уровнямНет — только свёрнутые строкиДа, по каждому указанному полю
РезультатПлоская таблицаИерархия: итог → вложенные строки

Пример запроса с итогами

Разберём часть ИТОГИ:

ЗаписьСмысл
ИТОГИ СУММА(Выручка)Какие колонки и как считать в строках итогов. Пишем псевдоним из ВЫБРАТЬ
ПО ОБЩИЕДобавить одну строку общего итога по всему результату
НоменклатураДобавить строку итога по каждому товару

Порядок полей после ПО задаёт вложенность: сначала ОБЩИЕ, внутри — товары, внутри товаров — детальные строки.

Обход «плоско»: все строки подряд

Выбрать() без параметров в запросе с итогами вернёт и строки итогов, и детальные строки вперемешку — в том порядке, как в «ведомости» выше. Если просуммировать в цикле все Выручка, получится утроенная сумма: детальные строки + итоги по товарам + общий итог.

Не складывайте всё подряд

При ручном суммировании результата с ИТОГИ складывайте только детальные строки или только итоги одного уровня — иначе показатели посчитаются несколько раз.

Обход по группировкам: сначала товар, потом его покупатели

Чаще итоги нужны, чтобы обойти результат иерархически: для каждого товара — его итог и строки покупателей.

Вывод:

КодЧто делает
ОбходРезультатаЗапроса.ПоГруппировкамРежим обхода «по уровням итогов»
"Номенклатура"С какого уровня итогов начать
ВыборкаТоваров.Выбрать()«Войти внутрь» текущего товара — получить его вложенные строки

Это удобно, например, для печатной формы, где по каждому товару выводится заголовок с итогом и строки ниже.

Когда ИТОГИ, а когда СКД

ИТОГИ в запросе нужны, когда результат обходит код — печатная форма, обработка, выгрузка. В отчётах СКД итоги задают иначе: через Ресурсы (что и как считать) и Настройки (по каким группировкам) — 21. Поля и ресурсы СКД. ИТОГИ в тексте запроса СКД обычно не пишут.

Итоги в конструкторе

На вкладке Итоги:

  1. Выделяем поле в левом списке и верхней кнопкой «>» переносим его в таблицу Группировочное поле — это уровни итогов (ПО Номенклатура). Колонка Тип итогов — «Элементы» для обычного справочника.
  2. Числовые поля нижней кнопкой «>» переносим в таблицу Итоговое поле — конструктор сам предложит выражение СУММА(…).
  3. Флажок Общие итоги добавляет ОБЩИЕ.

Вкладка «Итоги» для запроса к табличной части накладной: группировочное поле Товар, итоговые поля Количество и Сумма с выражением СУММА(…), включён флажок «Общие итоги».

Проверка

  1. Выполните запрос и обойдите результат обычным Выбрать() — посчитайте строки. Их больше, чем детальных: добавились итоги.
  2. Обойдите по группировкам — у каждого товара итог равен сумме его детальных строк.
Проверь себя

  1. Чем ИТОГИ отличается от СГРУППИРОВАТЬ ПО?

  2. Как обойти результат сначала по товарам, потом по покупателям внутри товара?

  3. Где обычно задают итоги в отчёте СКД?

Ответы
  1. Группировка сворачивает строки, итоги добавляют итоговые уровни, сохраняя детали.
  2. Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам, "Номенклатура"), затем Группа.Выбрать().
  3. В ресурсах и структуре настроек, а не в ИТОГИ запроса.
