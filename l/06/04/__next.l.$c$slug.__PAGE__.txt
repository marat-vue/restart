<div class="callout-title">Коротко</div>
<div class="callout-body"><p>В алгоритмических задачах строку удобно представлять как <strong>массив символов</strong>. В 1С символ получаем через <code>Сред(Строка, Позиция, 1)</code>, позиции нумеруются <strong>с 1</strong> до <code>СтрДлина(Строка)</code> — в отличие от массива, где индексы с 0. Строки неизменяемы: «изменить символ» нельзя, собираем новую строку. Склейка строки в цикле через <code>+</code> для длинных строк медленная — собираем части в массив и склеиваем один раз <code>СтрСоединить</code>. Классические задачи: разворот, палиндром, подсчёт символов, сжатие строки.</p></div>

<h2 id="строки-неизменяемы">Строки неизменяемы</h2>
<p>В 1С нельзя «заменить третий символ» в существующей строке — любая операция создаёт <strong>новую</strong> строку. Отсюда важное следствие для скорости.</p>
<p>Склейка в цикле:</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bsl" data-theme="mono"><code data-language="bsl" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-foreground)">Результат </span><span style="color:var(--shiki-token-keyword)">=</span><span style="color:var(--shiki-token-string-expression)"> ""</span><span style="color:var(--shiki-token-keyword)">;</span></span>
<span data-line=""><span style="color:var(--shiki-token-keyword)">Для</span><span style="color:var(--shiki-foreground)"> Позиция </span><span style="color:var(--shiki-token-keyword)">=</span><span style="color:var(--shiki-token-constant)"> 1</span><span style="color:var(--shiki-token-keyword)"> По</span><span style="color:var(--shiki-token-function)"> СтрДлина</span><span style="color:var(--shiki-foreground)">(Текст) </span><span style="color:var(--shiki-token-keyword)">Цикл</span></span>
<span data-line=""><span style="color:var(--shiki-foreground)">	Результат </span><span style="color:var(--shiki-token-keyword)">=</span><span style="color:var(--shiki-foreground)"> Результат </span><span style="color:var(--shiki-token-keyword)">+</span><span style="color:var(--shiki-token-function)"> Сред</span><span style="color:var(--shiki-foreground)">(Текст</span><span style="color:var(--shiki-token-keyword)">,</span><span style="color:var(--shiki-foreground)"> Позиция</span><span style="color:var(--shiki-token-keyword)">,</span><span style="color:var(--shiki-token-constant)"> 1</span><span style="color:var(--shiki-foreground)">)</span><span style="color:var(--shiki-token-keyword)">;</span><span style="color:var(--shiki-token-comment)">   // каждый раз копируется вся строка</span></span>
<span data-line=""><span style="color:var(--shiki-token-keyword)">КонецЦикла;</span></span></code></pre></figure>
<p>На каждом шаге платформа создаёт новую строку и копирует в неё всё накопленное. Для строки длиной <code>n</code> это около <code>n²/2</code> операций копирования — <code>O(n²)</code>. Для коротких строк незаметно, для строк в десятки тысяч символов — заметно.</p>

<h2 id="задача-для-закрепления-первый-неповторяющийся-символ">Задача для закрепления: первый неповторяющийся символ</h2>
<p><strong>Условие.</strong> Найти первый символ строки, который встречается в ней ровно один раз. <code>"абракадабра"</code> → <code>"к"</code>. Если такого нет — вернуть пустую строку.</p>
<details class="callout callout-example" data-callout="example">
<summary class="callout-title">Подсказка</summary>
<div class="callout-body"><p>Простое решение — для каждого символа посчитать вхождения <code>СтрЧислоВхождений</code> — это <code>O(n²)</code>. Быстрее: первым проходом посчитать, сколько раз встречается каждый символ (в соответствии), вторым — найти первый с количеством 1. Как считать в соответствии — в <a href="/restart/l/06/05/" data-internal="true">05. Соответствие как хеш-таблица</a>.</p></div>
</details>
<details class="callout callout-question" data-callout="question">
<summary class="callout-title">Проверь себя</summary>
<div class="callout-body"><ol>
<li>
<p>С какой позиции начинается строка в <code>Сред</code> и с какого индекса — массив?</p>
</li>
<li>
<p>Почему склейка строки через <code>+</code> в длинном цикле медленная и как её ускорить?</p>
</li>
<li>
<p>Как проверить палиндром без создания копии строки?</p>
</li>
<li>
<p>Какую ошибку чаще всего делают в задаче сжатия строки?</p>
</li>
</ol><details class="callout callout-success" data-callout="success">
<summary class="callout-title">Ответы</summary>
<div class="callout-body"><ol>
<li>Строка — с 1, массив — с 0.</li>
<li>Каждый раз создаётся новая строка с копированием накопленного — <code>O(n²)</code>. Собирать части в массив и склеить один раз <code>СтрСоединить</code> — <code>O(n)</code>.</li>
<li>Двумя указателями: сравнивать символы с начала и с конца, сдвигаясь к середине.</li>
<li>Забывают записать последнюю серию после цикла.</li>
</ol></div>
