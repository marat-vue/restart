Строки и символы

Коротко

В алгоритмических задачах строку удобно представлять как массив символов. В 1С символ получаем через Сред(Строка, Позиция, 1), позиции нумеруются с 1 до СтрДлина(Строка) — в отличие от массива, где индексы с 0. Строки неизменяемы: «изменить символ» нельзя, собираем новую строку. Склейка строки в цикле через + для длинных строк медленная — собираем части в массив и склеиваем один раз СтрСоединить. Классические задачи: разворот, палиндром, подсчёт символов, сжатие строки.

Строка как цепочка символов

Функции работы со строками разобраны в 04. Работа со строками. Для алгоритмов главное — уметь пройти по строке символ за символом:

ДлинаСтрДлина(Текст)5
Символ на позицииСред(Текст, 2, 1)«а»
Первый / последний символЛев(Текст, 1) / Прав(Текст, 1)«К» / «к»
Код символаКодСимвола("а")1072
Символ по кодуСимвол(1072)«а»
В нижний регистрНРег(Текст)«кабак»
Позиции с 1, индексы массива с 0

Это главный источник ошибок: в строке первый символ — Сред(Текст, 1, 1), а в массиве первый элемент — Массив[0]. Если превращаете строку в массив символов, помните о сдвиге на единицу.

Строку в массив символов удобно превращать, когда нужен доступ «по индексу» и обмен символов:

Обратно — СтрСоединить(Символы, "").

Строки неизменяемы

В 1С нельзя «заменить третий символ» в существующей строке — любая операция создаёт новую строку. Отсюда важное следствие для скорости.

Склейка в цикле:

На каждом шаге платформа создаёт новую строку и копирует в неё всё накопленное. Для строки длиной n это около n²/2 операций копирования — O(n²). Для коротких строк незаметно, для строк в десятки тысяч символов — заметно.

Задача 1. Разворот строки

"Привет" → "тевирП".

Идём с последнего символа к первому и собираем их в массив. Время O(n), память O(n).

Задача 2. Палиндром

Палиндром — строка, которая читается одинаково слева направо и справа налево: «шалаш», «А роза упала на лапу Азора».

Простая версия: проверить, что строка без изменений — палиндром. Можно развернуть и сравнить: РазвернутьСтроку(Т) = Т. Это O(n) времени, но O(n) памяти на копию.

Лучше — два указателя без копирования: сравниваем первый символ с последним, второй с предпоследним…

Время O(n), память O(1).

Усложнённая версия (частая на собеседовании): не учитывать регистр, пробелы и знаки препинания. «А роза упала на лапу Азора» → палиндром.

Шаг 1 — оставить только буквы и цифры в нижнем регистре; шаг 2 — проверить как раньше:

Приём ВРег(Символ) <> НРег(Символ) отличает букву от пробела и знака препинания: у пробела верхний и нижний вариант совпадают. Работает и для русских, и для латинских букв. Отдельно в 1С есть буква «ё»: если по условию «е» и «ё» равны — замените «ё» на «е» через СтрЗаменить.

Задача 3. Сжатие строки (кодирование длин серий)

Условие. Заменить серии одинаковых символов на «символ + количество». "aaabccdddd" → "a3b1c2d4".

Идея: идём по строке и считаем, сколько раз подряд повторяется текущий символ. Когда символ сменился — записываем серию.

Последняя серия

Самая частая ошибка — забыть записать последнюю серию после цикла: внутри цикла серия записывается только при смене символа, а после последнего символа смены уже не будет.

Время O(n).

Задача для закрепления: первый неповторяющийся символ

Условие. Найти первый символ строки, который встречается в ней ровно один раз. "абракадабра" → "к". Если такого нет — вернуть пустую строку.

Подсказка

Простое решение — для каждого символа посчитать вхождения СтрЧислоВхождений — это O(n²). Быстрее: первым проходом посчитать, сколько раз встречается каждый символ (в соответствии), вторым — найти первый с количеством 1. Как считать в соответствии — в 05. Соответствие как хеш-таблица.

Проверь себя

  1. С какой позиции начинается строка в Сред и с какого индекса — массив?

  2. Почему склейка строки через + в длинном цикле медленная и как её ускорить?

  3. Как проверить палиндром без создания копии строки?

  4. Какую ошибку чаще всего делают в задаче сжатия строки?

Ответы
  1. Строка — с 1, массив — с 0.
  2. Каждый раз создаётся новая строка с копированием накопленного — O(n²). Собирать части в массив и склеить один раз СтрСоединить — O(n).
  3. Двумя указателями: сравнивать символы с начала и с конца, сдвигаясь к середине.
  4. Забывают записать последнюю серию после цикла.
