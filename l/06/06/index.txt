<div class="callout-title">Коротко</div>
<div class="callout-body"><p><strong>Два указателя</strong> — две переменные-индекса, которые движутся по массиву по определённому правилу. Варианты: <strong>навстречу</strong> друг другу (с концов к середине — разворот, палиндром, пара с суммой в <strong>отсортированном</strong> массиве), <strong>в одном направлении</strong> с разной скоростью («читатель» и «писатель» — удаление дубликатов, сдвиг нулей), <strong>по двум массивам</strong> (слияние отсортированных). Приём превращает <code>O(n²)</code> в <code>O(n)</code> и часто не требует дополнительной памяти.</p></div>
</div>
<h2 id="идея">Идея</h2>
<p>Указатель — это просто индекс элемента, «палец», который показывает на позицию в массиве. Приём «два указателя» использует <strong>два пальца</strong> одновременно и на каждом шаге решает, какой из них сдвинуть.</p>
<p>Мы уже применяли его: разворот массива (<a href="/restart/l/06/03/" data-internal="true">03. Массивы — базовые приёмы</a>) и проверка палиндрома (<a href="/restart/l/06/04/" data-internal="true">04. Строки и символы</a>) — указатели шли с краёв навстречу друг другу.</p>

























<div class="table-wrap"><table><thead><tr><th>Вариант</th><th>Как движутся</th><th>Типичные задачи</th></tr></thead><tbody><tr><td>Навстречу</td><td>Левый с начала вправо, правый с конца влево</td><td>Разворот, палиндром, пара с суммой в отсортированном массиве</td></tr><tr><td>В одном направлении</td><td>«Читатель» идёт по всем элементам, «писатель» — только по нужным</td><td>Удаление дубликатов, фильтрация на месте</td></tr><tr><td>По двум массивам</td><td>По указателю в каждом массиве</td><td>Слияние отсортированных массивов, пересечение</td></tr></tbody></table></div>
<h2 id="вариант-1-навстречу-пара-с-суммой-в-отсортированном-массиве">Вариант 1. Навстречу: пара с суммой в отсортированном массиве</h2>
<p><strong>Условие.</strong> Массив <strong>отсортирован</strong> по возрастанию. Найти два элемента с суммой <code>Цель</code>. <code>[1, 3, 4, 6, 9]</code>, <code>Цель = 10</code> → <code>1 + 9</code> или <code>4 + 6</code>.</p>
<p>В прошлом уроке мы решили похожую задачу через соответствие — <code>O(n)</code> времени и <code>O(n)</code> памяти. Отсортированность позволяет обойтись <strong>без дополнительной памяти</strong>.</p>
<p>Идея: левый указатель на самом маленьком числе, правый — на самом большом. Смотрим на их сумму:</p>
<ul>
<li>сумма <strong>меньше</strong> цели → нужно больше → двигаем <strong>левый</strong> вправо (к большим числам);</li>
<li>сумма <strong>больше</strong> цели → нужно меньше → двигаем <strong>правый</strong> влево;</li>
<li><strong>равна</strong> — ответ найден.</li>
</ul>

<p>Почему мы не пропустим ответ? Если сумма слишком мала, то левый элемент не подходит ни с каким элементом правее текущего правого — ведь они ещё меньше. Значит, его можно смело отбросить. Аналогично с правым.</p>
<p>За каждый шаг один из указателей сдвигается, и они встречаются не позже чем через <code>n</code> шагов: время <code>O(n)</code>, память <code>O(1)</code>.</p>

<h2 id="вариант-2-в-одном-направлении-удаление-дубликатов">Вариант 2. В одном направлении: удаление дубликатов</h2>
<p><strong>Условие.</strong> Массив отсортирован. Удалить повторы <strong>на месте</strong>, вернуть количество уникальных элементов; уникальные должны стоять в начале массива. <code>[1, 1, 2, 3, 3, 3, 4]</code> → <code>4</code>, начало массива <code>[1, 2, 3, 4, …]</code>.</p>
<p>Идея: два указателя идут в одну сторону.</p>
<ul>
<li><strong>Читатель</strong> проходит по всем элементам.</li>
<li><strong>Писатель</strong> указывает, куда записать следующий уникальный элемент.</li>
</ul>
<p>Так как массив отсортирован, повторы стоят рядом: элемент новый, если он отличается от последнего записанного.</p>

<h2 id="вариант-3-по-двум-массивам-слияние-отсортированных">Вариант 3. По двум массивам: слияние отсортированных</h2>
<p><strong>Условие.</strong> Даны два отсортированных массива. Слить их в один отсортированный. <code>[1, 4, 7]</code> и <code>[2, 3, 8, 9]</code> → <code>[1, 2, 3, 4, 7, 8, 9]</code>.</p>
<p>Простое решение — сложить и отсортировать: <code>O(n log n)</code>. Но массивы <strong>уже</strong> отсортированы — можно за <code>O(n)</code>.</p>
