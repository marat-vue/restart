Два указателя

Коротко

Два указателя — две переменные-индекса, которые движутся по массиву по определённому правилу. Варианты: навстречу друг другу (с концов к середине — разворот, палиндром, пара с суммой в отсортированном массиве), в одном направлении с разной скоростью («читатель» и «писатель» — удаление дубликатов, сдвиг нулей), по двум массивам (слияние отсортированных). Приём превращает O(n²) в O(n) и часто не требует дополнительной памяти.

Идея

Указатель — это просто индекс элемента, «палец», который показывает на позицию в массиве. Приём «два указателя» использует два пальца одновременно и на каждом шаге решает, какой из них сдвинуть.

Мы уже применяли его: разворот массива (03. Массивы — базовые приёмы) и проверка палиндрома (04. Строки и символы) — указатели шли с краёв навстречу друг другу.

НавстречуЛевый с начала вправо, правый с конца влевоРазворот, палиндром, пара с суммой в отсортированном массиве

Вариант 1. Навстречу: пара с суммой в отсортированном массиве

Условие. Массив отсортирован по возрастанию. Найти два элемента с суммой Цель. [1, 3, 4, 6, 9], Цель = 10 → 1 + 9 или 4 + 6.

В прошлом уроке мы решили похожую задачу через соответствие — O(n) времени и O(n) памяти. Отсортированность позволяет обойтись без дополнительной памяти.

Идея: левый указатель на самом маленьком числе, правый — на самом большом. Смотрим на их сумму:

  • сумма меньше цели → нужно больше → двигаем левый вправо (к большим числам);
  • сумма больше цели → нужно меньше → двигаем правый влево;
  • равна — ответ найден.

Почему мы не пропустим ответ? Если сумма слишком мала, то левый элемент не подходит ни с каким элементом правее текущего правого — ведь они ещё меньше. Значит, его можно смело отбросить. Аналогично с правым.

За каждый шаг один из указателей сдвигается, и они встречаются не позже чем через n шагов: время O(n), память O(1).

Вариант 2. В одном направлении: удаление дубликатов

Условие. Массив отсортирован. Удалить повторы на месте, вернуть количество уникальных элементов; уникальные должны стоять в начале массива. [1, 1, 2, 3, 3, 3, 4] → 4, начало массива [1, 2, 3, 4, …].

Идея: два указателя идут в одну сторону.

  • Читатель проходит по всем элементам.
  • Писатель указывает, куда записать следующий уникальный элемент.

Так как массив отсортирован, повторы стоят рядом: элемент новый, если он отличается от последнего записанного.

Прогон по [1, 1, 2, 3, 3]:

ЧитательЧисла[Читатель]Последний записанныйДействиеМассивПисатель
——1старт[1, 1, 2, 3, 3]1
111повтор, пропускаем[1, 1, 2, 3, 3]1
221новый → пишем в [1][1, 2, 2, 3, 3]2
332новый → пишем в [2][1, 2, 3, 3, 3]3
433повтор[1, 2, 3, 3, 3]3

Ответ 3, первые три элемента — 1, 2, 3. Время O(n), память O(1).

Тот же шаблон «читатель/писатель» решает задачу сдвига нулей из урока 03 и любую «фильтрацию на месте».

Вариант 3. По двум массивам: слияние отсортированных

Условие. Даны два отсортированных массива. Слить их в один отсортированный. [1, 4, 7] и [2, 3, 8, 9] → [1, 2, 3, 4, 7, 8, 9].

Простое решение — сложить и отсортировать: O(n log n). Но массивы уже отсортированы — можно за O(n).

Идея: как сливают две стопки карт, лежащие по возрастанию, — каждый раз берём меньшую из двух верхних карт.

Время O(n + m), где n и m — длины массивов. Эта функция — сердце сортировки слиянием (09. Сортировки).

Хвосты

Частая ошибка — забыть дописать остаток второго массива после основного цикла. Проверяйте решение на случае, когда один массив намного длиннее другого или пустой.

Задача для закрепления: квадраты отсортированного массива

Условие. Дан отсортированный массив, в нём могут быть отрицательные числа. Вернуть отсортированный массив квадратов. [-4, -1, 0, 3, 10] → [0, 1, 9, 16, 100].

Подсказка

Самые большие квадраты — на краях (у самого отрицательного и самого положительного). Поставьте указатели на оба края, на каждом шаге берите больший квадрат и заполняйте результат с конца.

Решение

Новый Массив(N) создаёт массив из N ячеек, которые мы заполняем по индексу. Время O(n).

Проверь себя

  1. Почему для пары с суммой указатели навстречу работают только на отсортированном массиве?

  2. Чем «читатель» отличается от «писателя» в задаче удаления дубликатов?

  3. Какая сложность у слияния двух отсортированных массивов длиной n и m?

  4. Что нужно не забыть после основного цикла слияния?

Ответы
  1. Решение «сдвинуть левый, если сумма мала» опирается на то, что справа числа больше, а слева меньше. В неотсортированном массиве это неверно.
  2. Читатель проходит все элементы; писатель сдвигается, только когда записан нужный (уникальный) элемент.
  3. O(n + m).
  4. Дописать оставшиеся элементы того массива, который не закончился.
