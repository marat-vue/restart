<div class="callout-title">Коротко</div>
<div class="callout-body"><p><strong>Стек</strong> — «последним пришёл, первым ушёл» (стопка тарелок): кладём и берём сверху. В 1С — массив: <code>Добавить()</code> в конец, читать и удалять <code>ВГраница()</code>. Задачи: правильные скобки, отмена действий, вычисление выражений, «ближайший больший элемент». <strong>Очередь</strong> — «первым пришёл, первым ушёл» (очередь в кассу): добавляем в конец, берём из начала. В 1С <code>Массив.Удалить(0)</code> стоит <code>O(n)</code>, поэтому для больших очередей храним индекс «головы». Очередь — основа обхода в ширину (<a href="/restart/l/06/13/" data-internal="true">13. Обход в глубину и ширину</a>).</p></div>
</div>
<h2 id="стек">Стек</h2>
<p><strong>Стек</strong> работает как стопка тарелок: новую кладём <strong>сверху</strong>, и брать можем только <strong>сверху</strong>. Последняя положенная тарелка будет взята первой — принцип <strong>LIFO</strong> (last in, first out).</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="plaintext" data-theme="mono"><code data-language="plaintext" data-theme="mono" style="display: grid;"><span data-line=""><span>Положили 1, 2, 3:        Сняли верхнюю:</span></span>
<span data-line=""><span>   ┌───┐                    ┌───┐</span></span>
<span data-line=""><span>   │ 3 │ ← верх              │ 2 │ ← верх</span></span>
<span data-line=""><span>   ├───┤                    ├───┤</span></span>
<span data-line=""><span>   │ 2 │                    │ 1 │</span></span>
<span data-line=""><span>   ├───┤                    └───┘</span></span>
<span data-line=""><span>   │ 1 │                 сняли 3</span></span>
<span data-line=""><span>   └───┘</span></span></code></pre></figure>
<p>Примеры из жизни программ: кнопка «Отменить» (отменяется последнее действие), кнопка «Назад» в браузере, вызовы процедур (последняя вызванная завершается первой — стек вызовов в отладчике 1С).</p>
<h3 id="стек-в-1с">Стек в 1С</h3>
<p>Отдельного типа «стек» во встроенном языке нет. Используем массив, где <strong>конец массива — верх стопки</strong>: все операции с концом массива — <code>O(1)</code>.</p>






























<div class="table-wrap"><table><thead><tr><th>Операция стека</th><th>Код 1С</th><th>Сложность</th></tr></thead><tbody><tr><td>Положить (push)</td><td><code>Стек.Добавить(Значение)</code></td><td><code>O(1)</code></td></tr><tr><td>Посмотреть верх (peek)</td><td><code>Стек[Стек.ВГраница()]</code></td><td><code>O(1)</code></td></tr><tr><td>Снять (pop)</td><td><code>Верх = Стек[Стек.ВГраница()]; Стек.Удалить(Стек.ВГраница());</code></td><td><code>O(1)</code></td></tr><tr><td>Пуст ли</td><td><code>Стек.Количество() = 0</code></td><td><code>O(1)</code></td></tr></tbody></table></div>
<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">Пустой стек</div>
<div class="callout-body"><p>Перед чтением или снятием верхнего элемента всегда проверяйте, что стек не пуст: у пустого массива <code>ВГраница() = −1</code>, и обращение <code>Стек[-1]</code> — ошибка.</p></div>
</div>
<h3 id="задача-правильная-скобочная-последовательность">Задача: правильная скобочная последовательность</h3>
<p>Самая популярная задача на стек.</p>
<p><strong>Условие.</strong> Строка состоит из скобок <code>()[]{}</code>. Проверить, правильно ли они расставлены: каждая открывающая закрыта скобкой того же типа и в правильном порядке.</p>








































<div class="table-wrap"><table><thead><tr><th>Строка</th><th>Ответ</th><th>Почему</th></tr></thead><tbody><tr><td><code>()[]{}</code></td><td>Да</td><td></td></tr><tr><td><code>{[()]}</code></td><td>Да</td><td>Вложены правильно</td></tr><tr><td><code>(]</code></td><td>Нет</td><td>Тип не совпадает</td></tr><tr><td><code>([)]</code></td><td>Нет</td><td>Порядок нарушен: <code>[</code> закрыта после <code>)</code></td></tr><tr><td><code>((</code></td><td>Нет</td><td>Остались незакрытые</td></tr><tr><td><code>)(</code></td><td>Нет</td><td>Закрывающая без открывающей</td></tr></tbody></table></div>
<p><strong>Идея.</strong> Открывающие скобки кладём в стек. Встретив закрывающую — смотрим на <strong>верх</strong> стека: там должна лежать парная открывающая. Если да — снимаем её, если нет (или стек пуст) — ошибка. В конце стек должен быть пустым.</p>

<h3 id="задача-ближайший-больший-справа-монотонный-стек">Задача: ближайший больший справа (монотонный стек)</h3>
<p><strong>Условие.</strong> Для каждого дня известна температура. Для каждого дня найти, через сколько дней станет теплее. Если не станет — 0. <code>[73, 74, 75, 71, 69, 72, 76, 73]</code> → <code>[1, 1, 4, 2, 1, 1, 0, 0]</code>.</p>
<p>Простое решение — для каждого дня искать вперёд: <code>O(n²)</code>.</p>
<p><strong>Идея монотонного стека.</strong> Храним в стеке <strong>индексы дней</strong>, для которых ещё не нашли ответ. Температуры этих дней в стеке идут по убыванию. Когда приходит новый день, он «закрывает» все дни на верху стека, которые холоднее его.</p>

<h2 id="очередь">Очередь</h2>
<p><strong>Очередь</strong> работает как очередь в кассу: новые встают в <strong>конец</strong>, обслуживают из <strong>начала</strong>. Принцип <strong>FIFO</strong> (first in, first out).</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="plaintext" data-theme="mono"><code data-language="plaintext" data-theme="mono" style="display: grid;"><span data-line=""><span>Встали: A, B, C          Обслужили первого:</span></span>
<span data-line=""><span>начало → [A][B][C] ← конец     начало → [B][C] ← конец</span></span></code></pre></figure>
<p>Примеры: очередь заданий на печать, обработка сообщений по порядку поступления, обход в ширину.</p>
<h3 id="очередь-в-1с">Очередь в 1С</h3>
<p>Простейший вариант — массив: <code>Добавить()</code> в конец, читать <code>[0]</code> и <code>Удалить(0)</code>. Это работает, но <code>Удалить(0)</code> сдвигает все остальные элементы — <code>O(n)</code> на каждое извлечение.</p>
<p>Для больших очередей храним <strong>индекс головы</strong>: элементы не удаляем, а просто сдвигаем указатель на начало.</p>

<h2 id="стек-или-очередь">Стек или очередь?</h2>

















<div class="table-wrap"><table><thead><tr><th>Нужно обработать</th><th>Структура</th></tr></thead><tbody><tr><td>Сначала самое последнее (вложенность, отмена, скобки)</td><td>Стек</td></tr><tr><td>В порядке поступления (по уровням, по времени)</td><td>Очередь</td></tr></tbody></table></div>
<details class="callout callout-question" data-callout="question">
<summary class="callout-title">Проверь себя</summary>
<div class="callout-body"><ol>
<li>
<p>Что значит LIFO и FIFO? Приведите пример из жизни для каждого.</p>
</li>
<li>
<p>Почему конец массива — удобный «верх» стека в 1С?</p>
</li>
<li>
<p>Опишите алгоритм проверки скобок. Какие три ситуации означают ошибку?</p>
</li>
<li>
<p>Почему <code>Массив.Удалить(0)</code> плохо подходит для большой очереди и как это обойти?</p>
</li>
</ol><details class="callout callout-success" data-callout="success">
<summary class="callout-title">Ответы</summary>
<div class="callout-body"><ol>
<li>LIFO — последним пришёл, первым ушёл (стопка тарелок); FIFO — первым пришёл, первым ушёл (очередь в кассу).</li>
<li>Добавление в конец и удаление последнего элемента — <code>O(1)</code>, ничего не сдвигается.</li>
<li>Открывающие кладём в стек, на закрывающую проверяем верх стека. Ошибки: закрывающая при пустом стеке; верх не совпадает по типу; после прохода стек не пуст.</li>
<li>Каждое удаление сдвигает все элементы — <code>O(n)</code>. Храним индекс головы и сдвигаем его вместо удаления.</li>
</ol></div>
