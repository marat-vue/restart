<div class="callout-body"><p>Массив в 1С — пронумерованный список с индексами от <code>0</code> до <code>ВГраница()</code> (<code>= Количество() − 1</code>). Обращение по индексу — <code>O(1)</code>, вставка и удаление в начале — <code>O(n)</code>. Базовые приёмы: проход с накоплением (сумма, минимум, счётчик), проход по индексам, обмен двух элементов через временную переменную, разворот, создание нового массива-результата. <h2 id="приём-2-обмен-двух-элементов">Приём 2. Обмен двух элементов</h2>
<p>Чтобы поменять местами два элемента, нужна <strong>временная переменная</strong> — как при обмене содержимым двух стаканов нужен третий, пустой:</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="bsl" data-theme="mono"><code data-language="bsl" data-theme="mono" style="display: grid;"><span data-line=""><span style="color:var(--shiki-foreground)">Временная </span><span style="color:var(--shiki-token-keyword)">=</span><span style="color:var(--shiki-foreground)"> Числа[i]</span><span style="color:var(--shiki-token-keyword)">;</span></span>
<span data-line=""><span style="color:var(--shiki-foreground)">Числа[i] </span><span style="color:var(--shiki-token-keyword)">=</span><span style="color:var(--shiki-foreground)"> Числа[j]</span><span style="color:var(--shiki-token-keyword)">;</span></span>
<span data-line=""><span style="color:var(--shiki-foreground)">Числа[j] </span><span style="color:var(--shiki-token-keyword)">=</span><span style="color:var(--shiki-foreground)"> Временная</span><span style="color:var(--shiki-token-keyword)">;</span></span></code></pre></figure>
<p>Без временной переменной значение <code>Числа[i]</code> потеряется после второй строки.</p>
<h2 id="приём-3-разворот-массива-на-месте">Приём 3. Разворот массива на месте</h2>
<p><strong>Задача:</strong> развернуть массив без создания нового. <code>[1, 2, 3, 4, 5]</code> → <code>[5, 4, 3, 2, 1]</code>.</p>

<h2 id="приём-4-новый-массив-результат">Приём 4. Новый массив-результат</h2>

<h2 id="задача-для-закрепления-сдвиг-нулей-в-конец">Задача для закрепления: сдвиг нулей в конец</h2>
<p><strong>Условие.</strong> Переставить все нули в конец массива, сохранив порядок остальных элементов. Сделать на месте. <code>[0, 1, 0, 3, 12]</code> → <code>[1, 3, 12, 0, 0]</code>.</p>
