Префиксные суммы

Коротко

Префиксная сумма П[i] — сумма первых i элементов массива. Посчитав её один раз за O(n), сумму любого отрезка от l до r получаем за O(1): П[r + 1] − П[l]. Приём полезен, когда запросов «сумма на отрезке» много. В паре с соответствием он решает задачу «сколько подмассивов дают сумму K» за O(n): ищем, сколько раз раньше встречалась префиксная сумма Текущая − K.

Идея на примере

Представьте накопительный счётчик пробега автомобиля. Чтобы узнать, сколько машина проехала со вторника по четверг, не нужно складывать поездки за каждый день — достаточно вычесть показание одометра на утро вторника из показания на вечер четверга.

Префиксные суммы — это «одометр» для массива.

П[k] — сумма первых k элементов:

  • П[0] = 0 — сумма нуля элементов;
  • П[1] = 3 — только первый элемент;
  • П[3] = 3 + 1 + 4 = 8;
  • П[5] = 14 — сумма всего массива.

Массив префиксов на один элемент длиннее исходного: начинаем с нуля. Это убирает особый случай «отрезок с самого начала».

Сумма отрезка за O(1)

Сумма элементов с индекса l по индекс r включительно:

Пример: сумма Числа[1..3] = 1 + 4 + 1 = 6. П[4] − П[1] = 9 − 3 = 6 ✓

Почему это верно: П[4] — сумма элементов 0..3, П[1] — сумма элемента 0. Вычитая, убираем лишнее начало и получаем ровно 1..3.

Когда это выгодно

СценарийБез префиксовС префиксами
Одна сумма отрезкаO(n)O(n) на подготовку — выигрыша нет
q запросов сумм отрезковO(n · q)O(n + q)

Пример из 1С-жизни: выручка по дням за год (365 значений) и сотни запросов вида «выручка с 10 по 25 число». Префиксы считаем один раз, дальше каждый ответ — одно вычитание. По тому же принципу устроены итоги регистров накопления: платформа хранит накопленные остатки, чтобы не складывать все движения с начала времён (17. Регистры накоплений).

Префиксы + соответствие: подмассивы с суммой K

Это классическая задача среднего уровня.

Условие. Сколько непрерывных подмассивов имеют сумму ровно K? Числа могут быть отрицательными. [1, 1, 1], K = 2 → 2 ([1, 1] дважды). [1, 2, 3], K = 3 → 2 ([1, 2] и [3]).

Простое решение — перебрать все пары границ: O(n²).

Быстрое. Сумма отрезка l..r равна П[r + 1] − П[l]. Мы хотим, чтобы она равнялась K:

То есть для каждой текущей префиксной суммы Текущая нужно знать: сколько раз раньше встречалась префиксная сумма Текущая − K? Каждая такая встреча — начало подходящего отрезка. А «сколько раз встречалось» — это подсчёт частот в соответствии (05. Соответствие как хеш-таблица).

Прогон по [1, 2, 3], K = 3:

ЭлементТекущаяИщем Текущая − 3Сколько раз былоОтветЧастоты после шага
—0——0{0:1}
11−200{0:1, 1:1}
2301 → отрезок [1, 2]1{0:1, 1:1, 3:1}
3631 → отрезок [3]2{…, 6:1}

Ответ 2. Время O(n), память O(n).

Не забудьте начальный ноль

Запись СколькоРазБыло.Вставить(0, 1) учитывает отрезки, которые начинаются с самого первого элемента. Без неё подмассив [1, 2] в примере потерялся бы.

Почему здесь не скользящее окно

Окно (07. Скользящее окно) работает, когда все числа положительные: расширение увеличивает сумму, сужение — уменьшает. С отрицательными числами это правило ломается, а префиксы с соответствием работают всегда.

В последнем примере подходят [1, −1], [1, −1, 0] и [0].

Задача для закрепления: точка равновесия

Условие. Найти индекс, где сумма элементов слева равна сумме элементов справа (сам элемент не входит ни в одну из сумм). [1, 7, 3, 6, 5, 6] → 3 (слева 1+7+3 = 11, справа 5+6 = 11). Если такого нет — -1.

Подсказка

Посчитайте общую сумму. Идите по массиву, накапливая сумму слева. Сумма справа = общая − слева − текущий элемент.

Решение

Время O(n), память O(1) — отдельный массив префиксов здесь не нужен, хватает одной накопленной суммы.

Проверь себя

  1. Чему равен П[0] и зачем массив префиксов на один длиннее исходного?

  2. Как получить сумму элементов с индекса 2 по 5 через префиксы?

  3. Когда префиксные суммы дают выигрыш по сравнению с прямым подсчётом?

  4. Что ищем в соответствии в задаче «подмассивы с суммой K»?

Ответы
  1. П[0] = 0 — сумма пустого начала; благодаря ему формула работает и для отрезков, начинающихся с индекса 0.
  2. П[6] − П[2].
  3. Когда запросов сумм отрезков много: подготовка O(n), каждый запрос O(1).
  4. Сколько раз раньше встречалась префиксная сумма Текущая − K.
