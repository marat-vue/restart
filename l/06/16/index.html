Практика — задачи с собеседований

Коротко

Десять задач в формате собеседования — от разминки до среднего уровня. Для каждой: условие, примеры, подсказка и решение с разбором и сложностью (свёрнуты). Решайте в песочнице (01. Что такое алгоритм и как решать задачи) до того, как откроете решение, и проговаривайте ход мыслей вслух — как на собеседовании.

Как тренироваться

  1. Прочитайте условие и задайте себе уточняющие вопросы: пустой ввод? отрицательные числа? что вернуть, если ответа нет?
  2. Решите пример руками.
  3. Напишите сначала простое решение, назовите его сложность.
  4. Подумайте, какой приём из раздела ускорит решение.
  5. Напишите код в песочнице и проверьте на примерах и крайних случаях.
  6. Только потом откройте разбор и сравните.

Ориентир по времени на собеседовании: 15–25 минут на задачу, включая объяснение.

1. FizzBuzz

Классическая разминка: проверяет, что вы спокойно пишете цикл и условия.

Условие. Вывести числа от 1 до n. Вместо чисел, кратных 3, выводить «Fizz», кратных 5 — «Buzz», кратных и 3, и 5 — «FizzBuzz».

n = 15 → 1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz.

Решение

Главная ловушка — порядок условий: проверку на 15 (и 3, и 5) ставим первой, иначе число 15 попадёт в ветку «Fizz» и до «FizzBuzz» дело не дойдёт. Время O(n).

2. Пропущенное число

Условие. В массиве n различных чисел от 0 до n — одно число пропущено. Найти его. [3, 0, 1] → 2. [0, 1] → 2.

Подсказка

Сумма всех чисел от 0 до n известна заранее: n × (n + 1) / 2. Чем она отличается от суммы массива?

Решение

В массиве n элементов, значит, числа берутся из диапазона 0..n — их n + 1, одного не хватает. Разница между полной суммой и суммой массива и есть пропущенное число. Время O(n), память O(1). Альтернативы: множество (O(n) памяти) или сортировка (O(n log n)) — назовите их и объясните, почему сумма лучше.

3. Палиндром числа

Условие. Проверить, является ли целое число палиндромом, не превращая его в строку. 121 → Истина, -121 → Ложь (читается как «121-»), 10 → Ложь.

Подсказка

Последнюю цифру числа даёт Число % 10, а убрать её можно так: Цел(Число / 10). Соберите из цифр перевёрнутое число и сравните с исходным.

Решение
ОстатокЦифраПеревёрнутое
12111
12212
11121

Время O(d), где d — число цифр. В 1С числа не переполняются, как в некоторых языках, поэтому разворот всего числа безопасен.

4. Перевернуть слова

Условие. Перевернуть порядок слов в строке. Слова разделены одним или несколькими пробелами; в результате — ровно один пробел между словами и без пробелов по краям. " мама мыла раму " → "раму мыла мама".

Подсказка

СтрРазделить(Текст, " ", Ложь) — третий параметр Ложь означает «не включать пустые строки», то есть лишние пробелы исчезнут сами.

Решение

Разбили на слова, развернули массив двумя указателями (03. Массивы — базовые приёмы), склеили через один пробел. Время O(n). Если интервьюер запретит СтрРазделить, слова выделяют вручную: идём по символам и копим текущее слово до пробела.

5. Самый длинный общий префикс

Условие. Найти самое длинное общее начало у всех строк массива. ["цветок", "цвет", "цветение"] → "цвет". ["кот", "собака"] → "".

Подсказка

Сравнивайте символы на одной и той же позиции во всех строках. Как только в какой-то строке символ отличается или строка кончилась — префикс найден.

Решение

Идём «по столбцам»: позиция 1 во всех строках, позиция 2 во всех… Время O(S), где S — суммарная длина строк: каждый символ сравниваем не больше одного раза.

6. Пересечение двух массивов

Условие. Вернуть уникальные элементы, которые есть в обоих массивах. [1, 2, 2, 1] и [2, 2] → [2]. [4, 9, 5] и [9, 4, 9, 8, 4] → [4, 9] (порядок не важен).

Подсказка

Положите элементы первого массива во множество. Идите по второму массиву и проверяйте вхождение. Как не добавить один элемент дважды?

Решение

Время O(n + m), память O(n). Простое решение «для каждого элемента — Найти во втором массиве» — O(n × m). Если массивы отсортированы, можно обойтись без соответствия: два указателя, как при слиянии (06. Два указателя).

7. Элемент большинства

Условие. В массиве есть элемент, который встречается больше половины раз. Найти его. [2, 2, 1, 1, 1, 2, 2] → 2.

Подсказка

Решение с подсчётом частот в соответствии — O(n) времени и O(n) памяти. А можно ли за O(1) памяти? Подумайте про «голосование»: разные элементы «гасят» друг друга.

Решение

Способ 1 — подсчёт (05. Соответствие как хеш-таблица): посчитать частоты и вернуть элемент с частотой больше n / 2.

Способ 2 — голосование (алгоритм Бойера — Мура), память O(1):

Идея: каждую пару «элемент большинства + другой элемент» можно вычеркнуть — большинство всё равно останется. Поскольку элемент большинства встречается больше половины раз, вычеркнуть его полностью невозможно, и он останется кандидатом в конце. Время O(n), память O(1).

8. Сжатие диапазонов

Условие. Дан отсортированный массив различных целых чисел. Записать его в виде диапазонов. [0, 1, 2, 4, 5, 7] → "0-2,4-5,7".

Похожая задача встречается в 1С: вывести номера пропущенных документов или занятые номера мест одной строкой.

Подсказка

Идите по массиву и запоминайте начало текущего диапазона. Диапазон заканчивается, когда следующее число не равно текущему + 1 (или массив кончился).

Решение

Внутренний Пока двигает тот же индекс i, что и внешний, поэтому каждый элемент просматривается один раз: время O(n). Условие i < Числа.ВГраница() стоит перед обращением к Числа[i + 1] — сокращённое вычисление защищает от выхода за границу.

9. Минимальное число монет

Условие. Даны номиналы монет (каждого — сколько угодно) и сумма. Найти минимальное число монет, чтобы набрать сумму ровно. Если нельзя — вернуть -1. Номиналы [1, 3, 4], сумма 6 → 2 (3 + 3). Номиналы [2], сумма 3 → -1.

Подсказка

Жадный алгоритм здесь ошибается (15. Жадные алгоритмы и интервалы). Пусть ДП[s] — минимум монет для суммы s. Последней монетой в наборе может быть любая монета м; тогда до неё нужно набрать s − м.

Решение
ВопросОтвет
СостояниеДП[s] — минимальное число монет для суммы s
ПереходДП[s] = Мин по всем монетам м ≤ s из (ДП[s − м] + 1)
БазаДП[0] = 0
ОтветДП[Сумма], если сумму удалось набрать

Для [1, 3, 4] и суммы 6: ДП = [0, 1, 2, 1, 1, 2, 2] — например, ДП[6] = ДП[3] + 1 = 2. Время O(Сумма × k), где k — число номиналов. «Нельзя» — значение больше любого реального ответа (монет не может быть больше суммы при минимальном номинале 1), оно работает как «бесконечность».

10. Кратчайший путь в лабиринте

Условие. Лабиринт — сетка, "." — проход, "#" — стена. Найти минимальное число шагов из левого верхнего угла в правый нижний (ходить вверх, вниз, влево, вправо). Если пути нет — -1.

Ответ: 6 шагов.

Подсказка

«Минимальное число шагов» — сигнал к обходу в ширину (13. Обход в глубину и ширину). Храните в очереди клетки, а в соответствии — расстояние до каждой посещённой клетки.

Решение

Проверка: КратчайшийПуть(СтрРазделить("..#.,#.#.,....,.##.", ",")) → 6.

Массивы СдвигиСтрок и СдвигиСтолбцов задают четыре направления — так не нужно писать четыре почти одинаковых блока. Строки нумеруем с 0 (индекс массива), столбцы — с 1 (позиция в строке для Сред). BFS гарантирует, что первое попадание в выход — по кратчайшему пути. Время O(Строк × Столбцов).

После практики

Если задача не получилась — это нормально. Вернитесь к уроку с соответствующим приёмом, решите разобранные там примеры заново без подсказок, а через 2–3 дня повторите и эту задачу. Регулярная практика по 1–2 задачи в день даёт больше, чем разовое чтение всех решений.
