<h2 id="главное-правило-обхода-отмечать-посещённые">Главное правило обхода: отмечать посещённые</h2>
<p>В графе могут быть <strong>циклы</strong>: Москва → Тверь → Москва → Тверь… Если не запоминать, где мы уже были, обход никогда не закончится. Поэтому всегда храним <strong>множество посещённых</strong> вершин (<a href="/restart/l/06/05/" data-internal="true">05. Соответствие как хеш-таблица</a>).</p>
<h2 id="обход-в-глубину-dfs">Обход в глубину (DFS)</h2>

<h2 id="обход-в-ширину-bfs">Обход в ширину (BFS)</h2>

<div class="callout-body"><p>Обход в ширину находит <strong>кратчайший путь по числу рёбер</strong>: вершина впервые попадает в очередь именно тогда, когда до неё найден самый короткий путь. DFS такого не гарантирует. Если в задаче «минимальное число шагов / переходов / пересадок» — почти наверняка нужен BFS.</p></div>

<h2 id="dfs-или-bfs">DFS или BFS</h2>



































<div class="table-wrap"><table><thead><tr><th></th><th>Обход в глубину (DFS)</th><th>Обход в ширину (BFS)</th></tr></thead><tbody><tr><td>Как идёт</td><td>Вглубь по ветке, потом назад</td><td>Волнами, по уровням</td></tr><tr><td>Структура</td><td>Рекурсия или стек</td><td>Очередь</td></tr><tr><td>Кратчайший путь по шагам</td><td>Не гарантирует</td><td><strong>Находит</strong></td></tr><tr><td>Типичные задачи</td><td>Достижимость, компоненты, циклы, перебор путей</td><td>Кратчайший путь, «минимум ходов», уровни дерева</td></tr><tr><td>Сложность</td><td><code>O(V + E)</code></td><td><code>O(V + E)</code></td></tr></tbody></table></div>
<p><code>V</code> — число вершин, <code>E</code> — число рёбер: каждую вершину обрабатываем один раз и каждое ребро просматриваем один-два раза.</p>
<h2 id="задача-количество-островов">Задача: количество островов</h2>
<p>Очень популярная задача на собеседованиях.</p>
<p><strong>Условие.</strong> Карта — сетка из <code>"1"</code> (суша) и <code>"0"</code> (вода). Остров — группа клеток суши, соседних <strong>по горизонтали или вертикали</strong>. Посчитать острова.</p>
<figure data-rehype-pretty-code-figure=""><pre tabindex="0" data-language="plaintext" data-theme="mono"><code data-language="plaintext" data-theme="mono" style="display: grid;"><span data-line=""><span>1 1 0 0 0</span></span>
<span data-line=""><span>1 1 0 0 0</span></span>
<span data-line=""><span>0 0 1 0 0</span></span>
<span data-line=""><span>0 0 0 1 1</span></span></code></pre></figure>
<p>Ответ: <strong>3</strong> острова — большой слева вверху, одна клетка в центре и две клетки справа внизу.</p>
<p><strong>Идея.</strong> Сетка — это граф: клетки — вершины, соседние клетки — рёбра. Идём по всем клеткам; встретив непосещённую сушу — нашли <strong>новый</strong> остров: увеличиваем счётчик и обходом (DFS) «затапливаем» весь этот остров, отмечая его клетки посещёнными. Тогда этот же остров не посчитается второй раз.</p>
<p>Карту храним как массив строк, клетку читаем через <code>Сред</code>. Посещённые клетки — в соответствии с ключом <code>"строка:столбец"</code>.</p>

<p>Время <code>O(R × C)</code> — каждая клетка обрабатывается константное число раз; <code>R × C</code> — размер карты.</p>
<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">Глубина рекурсии</div>
<div class="callout-body"><p>На огромной сплошной карте рекурсивный DFS может уйти очень глубоко. В рабочем коде (или если интервьюер спросит) рекурсию заменяют <strong>явным стеком</strong> или используют BFS с очередью — логика та же, только вместо вызова <code>Затопить(…)</code> клетка кладётся в стек или очередь.</p></div>

</li>

<p>Какой обход найдёт минимальное число пересадок между станциями и почему?</p>
</li>

<summary class="callout-title">Ответы</summary>
<div class="callout-body"><ol>
<li>Соответствие «вершина → массив соседей» (список смежности).</li>
<li>Иначе при наличии циклов обход будет ходить по кругу бесконечно и обрабатывать вершины повторно.</li>
<li>DFS — рекурсия или стек; BFS — очередь.</li>
<li>BFS: он обходит вершины волнами по расстоянию, и первая найденная дорога до вершины — кратчайшая по числу рёбер.</li>
<li>Найдя новую сушу, сразу «затопить» весь остров обходом и отметить его клетки посещёнными.</li>
