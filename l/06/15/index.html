Жадные алгоритмы и интервалы

Коротко

Жадный алгоритм на каждом шаге делает локально лучший выбор и никогда его не пересматривает. Он прост и быстр, но верен не всегда — правильность нужно обосновать (или найти контрпример). Классика: выдача сдачи (работает для «удобных» номиналов), максимум непересекающихся встреч (выбираем ту, что раньше заканчивается). Задачи на интервалы почти всегда начинаются с сортировки по началу: слияние пересекающихся интервалов, вставка интервала, подсчёт комнат. Сложность обычно определяется сортировкой — O(n log n).

Что такое жадный алгоритм

Жадный алгоритм на каждом шаге берёт то, что выглядит лучшим прямо сейчас, и не возвращается к прошлым решениям.

Пример из жизни — сдача. Нужно выдать 87 рублей минимальным числом монет и купюр номиналами 50, 10, 5, 2, 1. Кассир действует жадно: каждый раз берёт самую крупную купюру, которая ещё помещается.

Жадность работает не всегда

Пусть номиналы 1, 3 и 4, а выдать нужно 6. Жадно: 4 + 1 + 1 — три монеты. Оптимально: 3 + 3 — две монеты. Для «неудобных» номиналов жадный алгоритм ошибается, и нужна динамика (14. Динамическое программирование). На собеседовании, предлагая жадное решение, будьте готовы объяснить, почему оно верное, — или сами приведите контрпример.

Задача 1. Максимум встреч в одной переговорной

Условие. Есть список встреч [начало, конец]. Переговорная одна. Какое максимальное число встреч можно в ней провести без пересечений? Встреча, которая заканчивается в 10:00, не мешает встрече, которая начинается в 10:00.

Какой жадный выбор правильный? Попробуем варианты:

ПравилоПроблема
Брать самую раннюю по началуДлинная встреча [0, 100] займёт весь день
Брать самую короткуюКороткая встреча может мешать двум длинным, которые не мешали бы друг другу
Брать ту, что раньше заканчивается✓ Освобождает переговорную как можно раньше — остаётся больше времени для остальных

Алгоритм: отсортировать встречи по концу; идти по порядку и брать встречу, если она начинается не раньше конца последней взятой.

Решение:

Почему жадность здесь верна. Возьмём любое оптимальное расписание. Его первую встречу можно заменить на встречу, которая заканчивается раньше всех, — она освободит переговорную не позже, и все остальные встречи расписания по-прежнему поместятся. Повторяя рассуждение для каждой следующей встречи, получаем: жадный выбор не хуже оптимального.

Задача 2. Слияние пересекающихся интервалов

Одна из самых частых задач собеседований.

Условие. Дан список интервалов. Слить все пересекающиеся. [1,3] [2,6] [8,10] [15,18] → [1,6] [8,10] [15,18]. Интервалы, которые касаются ([1,4] и [4,5]), тоже сливаются.

Алгоритм:

  1. Отсортировать интервалы по началу.
  2. Идти по порядку. Если текущий интервал начинается не позже конца последнего слитого — они пересекаются: растягиваем конец последнего до Макс(концов). Иначе — начинаем новый слитый интервал.

После сортировки пересекаться с текущим может только последний слитый интервал: все предыдущие закончились ещё раньше.

ДетальПочему
Макс(Последний.Конец, Интервал.Конец)Интервал может лежать внутри последнего: [1,10] и [2,3] → конец остаётся 10
<= в условии пересеченияКасающиеся интервалы [1,4] и [4,5] сливаются
Новые структуры в результатеЧтобы не менять исходные интервалы при растягивании

Время O(n log n) на сортировку плюс O(n) на проход.

Задачи из 1С-практики

Слияние интервалов встречается и в реальной работе: объединить периоды отпусков сотрудника, периоды действия договоров, интервалы простоя оборудования.

Задача для закрепления: сколько нужно переговорных

Условие. Даны встречи [начало, конец]. Сколько переговорных нужно, чтобы провести все? [0,30] [5,10] [15,20] → 2.

Подсказка

Разбейте каждую встречу на два события: «начало» (+1 занятая комната) и «конец» (−1). Отсортируйте события по времени; при равном времени «конец» ставьте раньше «начала». Пройдите по событиям, считая текущее число занятых комнат, — максимум и есть ответ.

Проверь себя

  1. Что отличает жадный алгоритм от динамического программирования?

  2. Приведите пример, когда жадная выдача сдачи ошибается.

  3. По какому признаку сортировать встречи, чтобы провести их максимум в одной комнате, и почему?

  4. Почему при слиянии интервалов достаточно сравнивать текущий интервал только с последним слитым?

Ответы
  1. Жадный делает локально лучший выбор и не пересматривает его; ДП рассматривает все варианты подзадач и выбирает лучший по запомненным ответам.
  2. Номиналы 1, 3, 4, сумма 6: жадно 4+1+1 (3 монеты), оптимально 3+3 (2 монеты).
  3. По времени окончания: ранний конец освобождает комнату для максимального числа следующих встреч.
  4. После сортировки по началу все более ранние слитые интервалы заканчиваются не позже последнего, поэтому пересечься с текущим может только последний.
