Скользящее окно

Коротко

Скользящее окно — непрерывный отрезок массива или строки между левой и правой границей, который «едет» по данным. Вместо пересчёта каждого отрезка заново мы добавляем элемент, вошедший справа, и убираем элемент, вышедший слева. Фиксированное окно (длина k задана) — максимальная сумма k подряд идущих элементов. Переменное окно — правая граница расширяет окно, левая сужает его, пока условие нарушено (самая длинная подстрока без повторов). Сложность O(n) вместо O(n·k) или O(n²).

Переменное окно: самая длинная подстрока без повторов

Это одна из самых популярных задач собеседований.

Условие. Найти длину самой длинной подстроки, в которой все символы различны. "abcabcbb" → 3 ("abc"), "bbbb" → 1, "pwwkew" → 3 ("wke").

Здесь длина окна не задана. Правило:

  • правая граница всегда идёт вперёд и добавляет символ в окно;
  • если новый символ уже есть в окне — окно «плохое», и мы сдвигаем левую границу, выбрасывая символы, пока повтор не исчезнет;
  • после каждого шага окно «хорошее» — запоминаем его длину, если она рекордная.

Какие символы сейчас в окне — храним в множестве (соответствии) — проверка за O(1) (05. Соответствие как хеш-таблица).

Время O(n), хотя внутри цикла есть цикл: каждый символ один раз добавляется правой границей и не больше одного раза удаляется левой. Всего не больше 2n действий.

Цикл в цикле — не всегда

O(n²) В переменном окне внутренний Пока не начинает каждый раз сначала: левая граница только движется вперёд и за всю работу пройдёт строку один раз. Это частый вопрос на собеседовании: «Почему тут O(n), если циклы вложенные?».

Задача для закрепления: кратчайший подмассив с суммой не меньше S

Условие. Даны положительные числа и число S. Найти длину самого короткого непрерывного подмассива с суммой ≥ S. Если такого нет — вернуть 0. [2, 3, 1, 2, 4, 3], S = 7 → 2 ([4, 3]).

Подсказка

Расширяйте окно вправо, прибавляя элемент к сумме. Как только сумма ≥ S — окно подходит: запомните длину и сужайте слева, вычитая элементы, пока сумма остаётся ≥ S — так найдёте самое короткое подходящее окно с этой правой границей.

Решение

Время O(n). Работает только для положительных чисел: с отрицательными сужение окна может увеличить сумму, и правило ломается.

Проверь себя

  1. Как получить сумму следующего окна длины k из суммы текущего?

  2. Почему решение «подстрока без повторов» работает за O(n), хотя содержит цикл внутри цикла?

  3. Где хранить символы текущего окна, чтобы быстро проверять повторы?

  4. Почему приём «сужать, пока сумма ≥ S» не работает для отрицательных чисел?

Ответы
  1. Прибавить вошедший справа элемент и вычесть ушедший слева: Сумма + Числа[i] − Числа[i − k].
  2. Левая граница только движется вперёд: каждый символ добавляется один раз и удаляется не больше одного раза — всего до 2n операций.
  3. В соответствии-множестве (символ → Истина).
  4. Удаление отрицательного элемента слева увеличивает сумму — сужение больше не означает уменьшение суммы, и логика «сужаем, пока подходит» перестаёт быть верной.
