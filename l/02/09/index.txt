<div class="callout-title">Коротко</div>
<div class="callout-body"><p><strong>Процедура</strong> выполняет действия, <strong>функция</strong> ещё и возвращает значение через <code>Возврат</code>. Параметры по умолчанию передаются <strong>по ссылке</strong> (изменение внутри видно снаружи), <code>Знач</code> — по значению. Параметры могут иметь значения по умолчанию. <code>Экспорт</code> делает метод доступным из других модулей.</p></div>

<h2 id="зачем-нужны-процедуры-и-функции">Зачем нужны процедуры и функции</h2>
<p>Представьте, что расчёт суммы строки с учётом скидки нужен в пяти местах программы. Можно скопировать одну и ту же формулу пять раз — но если правило расчёта изменится, придётся искать и исправлять все копии. Удобнее один раз описать алгоритм, дать ему <strong>имя</strong> и дальше просто вызывать по имени. Такой именованный кусок кода называется <strong>методом</strong>.</p>
<p>Методы бывают двух видов:</p>






























<div class="table-wrap"><table><thead><tr><th></th><th>Процедура</th><th>Функция</th></tr></thead><tbody><tr><td>Что делает</td><td>Выполняет действия</td><td>Выполняет действия <strong>и возвращает результат</strong></td></tr><tr><td>Объявление</td><td><code>Процедура Имя() … КонецПроцедуры</code></td><td><code>Функция Имя() … КонецФункции</code></td></tr><tr><td>Результат можно присвоить</td><td>Нет</td><td>Да: <code>Х = Имя();</code></td></tr><tr><td>Пример встроенного метода</td><td><code>Сообщить("Текст")</code> — просто выводит текст</td><td><code>Окр(12.345, 2)</code> — возвращает <code>12.35</code></td></tr></tbody></table></div>
<p>Платформа уже содержит сотни встроенных методов (<code>Сообщить</code>, <code>Окр</code>, <code>СтрДлина</code>…). Их описание ищем в Синтакс-помощнике. Свои методы пишем сами — об этом урок.</p>
<div class="callout callout-info" data-callout="info">
<div class="callout-title">Где метод можно вызвать</div>
<div class="callout-body"><p>Не каждый метод доступен везде: часть работает только на сервере, часть — только на клиенте. Это указано в разделе «Доступность» Синтакс-помощника (<a href="/restart/l/02/01/" data-internal="true">01. Основы программирования</a>). Пока все примеры пишем в одном модуле, и об этом можно не думать; клиент и сервер разберём в <a href="/restart/l/02/26/" data-internal="true">26. Общие модули и контекст выполнения</a>.</p></div>

<p>Разберём код:</p>
<ul>
<li><code>Количество</code>, <code>Цена</code>, <code>Скидка</code> — параметры, которые получает функция.</li>
<li><code>Скидка = 0</code> — значение по умолчанию. Этот параметр можно не передавать.</li>
<li><code>Возврат</code> — завершает функцию и отдаёт результат вызывающему коду.</li>

<div class="callout callout-warning" data-callout="warning">
<div class="callout-title">Важно</div>
<div class="callout-body"><p><code>Знач</code> не создаёт глубокую копию изменяемого объекта. Если передать массив через <code>Знач</code> и вызвать у него <code>Добавить()</code>, изменится тот же массив. Для независимой коллекции нужна отдельная копия.</p></div>
