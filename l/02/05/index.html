Работа с числами

Коротко

Арифметика: + - * / и % (остаток). Округление — Окр(Число, Знаков), целая часть — Цел() (отбрасывает дробь, не округляет вниз). В коде дробь отделяется точкой. Для вывода — Формат(Число, "ЧДЦ=2"), результат которого — строка. Денежные суммы округляем по единому правилу везде.

Что такое число в 1С

Число — один тип для всех числовых значений: и целых (5, -12), и дробных (12.5). Отдельных типов «целое» и «дробное», как в некоторых других языках, нет.

Точка, а не запятая

Цена = 149,90; — это ошибка: запятая в коде разделяет параметры. В полях формы пользователь может видеть и вводить 149,90 — это зависит от региональных настроек, но в тексте программы пишем только точку.

Арифметика

ОператорЗначениеПример → результат
+Сложение7 + 2 → 9
-Вычитание или смена знака7 - 2 → 5; -Сумма
*Умножение7 * 2 → 14
/Деление7 / 2 → 3.5
%Остаток от деления7 % 2 → 1

Обратите внимание: 7 / 2 даёт 3.5, а не 3. Деление в 1С всегда «честное». Если нужна только целая часть — используем Цел(7 / 2) → 3.

Деление на ноль

Сумма / 0 вызывает ошибку «Деление на 0», и выполнение кода прерывается. Перед делением проверяем делитель: Если Количество <> 0 Тогда … (10. Блок условия).

Окр и Цел — в чём разница

Окр округляет по математическим правилам: Окр(2.5) → 3, Окр(2.4) → 2. Без второго параметра округляет до целого.

Цел отбрасывает дробную часть, не глядя на неё: Цел(2.9) → 2. У отрицательных чисел тоже просто отбрасывает: Цел(-12.54) → -12 (а не -13, как было бы при округлении «вниз»).

Одно правило округления

Округление каждой строки и округление только общего итога могут дать разные результаты (разница в копейках). Правило округления должно быть одинаковым в форме, при записи и в печатной форме — иначе суммы в документе и на бумаге разойдутся.

Число из строки

Число() пригодится, когда значение пришло текстом — из файла или поля ввода. Если строка не похожа на число ("12 шт"), возникнет ошибка. Как такие ошибки перехватывать — в 27. Ошибки и сообщения пользователю.

Форматирование для вывода

Чтобы показать число пользователю в нужном виде, используем Формат():

ПараметрСмысл
ЧДЦ=2Число дробных цифр — два знака после запятой
ЧГ=0Отключить группировку разрядов (пробелы между тысячами)
ЧН=…Текст, если число равно нулю (ноль)

Строку формата не обязательно помнить наизусть: в коде ставим курсор внутрь кавычек второго параметра и вызываем ПКМ → Конструктор форматной строки… — параметры настраиваются галочками.

Результат Формат() имеет тип Строка. Само число не меняется. Для расчётов используем число, а форматирование применяем только при выводе.

Проверь себя

  1. Чему равно Цел(-7.8)?

  2. Окр(2.5) и Окр(12.345, 2) — результат?

  3. Почему нельзя считать дальше с результатом Формат()?

  4. Как получить остаток от деления 17 на 5?

  5. Что выведет Сообщить(7 / 2)?

Ответы
  1. −7: дробная часть отбрасывается.
  2. 3 и 12.35 (по умолчанию 0,5 округляется вверх).
  3. Формат() возвращает строку, а не число.
  4. 17 % 5 = 2.
  5. 3,5 — деление в 1С не отбрасывает дробную часть.
