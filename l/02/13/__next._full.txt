<div class="callout-title">Коротко</div>
<div class="callout-body"><p><code>Асинх</code> помечает метод, внутри которого можно <code>Ждать</code> результат асинхронной операции (вопрос, ввод, предупреждение) без блокировки интерфейса. <code>Асинх Функция</code> возвращает <strong>Обещание</strong>. Асинхронность — это про <strong>клиентское ожидание</strong>, а не про параллельные вычисления: тяжёлый расчёт переносят в фоновое задание.</p></div>
</div>
<h2 id="что-это">Что это?</h2>
<p><strong>Асинхронность</strong> — возможность начать операцию, результат которой будет готов позже, и организовать продолжение кода после её завершения без блокировки всего клиентского приложения.</p>
<p>При синхронном вызове вызывающий код получает результат после завершения метода. При асинхронном вызове результат может ещё не быть готов. Для ожидания используем <code>Ждать</code> внутри метода с модификатором <code>Асинх</code>. Ожидание приостанавливает продолжение этого метода, а не всю работу интерфейса. Механизм описан в <a href="https://kb.1ci.com/1C_Enterprise_Platform/FAQ/Development/Standards/Enhancements_to_1C_Enterprise_language_syntax_for_asynchronous_functions__synchronous_asynchrony/?language=en" target="_blank" rel="noopener noreferrer">материале разработчиков 1С</a>.</p>

<p>Этот пример размещаем в модуле управляемого приложения. В нём мы ожидаем, пока пользователь введёт дату рождения или отменит ввод. При отмене завершаем процедуру, не передавая <code>Неопределено</code> в расчёт.</p>
<hr>
<p>Обработчик запуска вызывает асинхронную процедуру → начинается ввод даты → процедура ожидает результат → после ввода рассчитывает количество дней → ожидает закрытия предупреждения → показывает оповещение и завершается.</p>
<p>Вызывающий обработчик <code>ПриНачалеРаботыСистемы</code> не ждёт завершения <code>ПосчитатьВозраст</code>: у асинхронной процедуры нет возвращаемого обещания для <code>Ждать</code>. Поэтому нельзя считать, что обработчик обязательно закончится только после закрытия всех окон.</p>
<hr>
<h2 id="обещание">Обещание</h2>
<p>Асинхронная <strong>функция</strong> возвращает значение типа <code>Обещание</code>. Оно представляет будущий результат операции. <code>Ждать</code> получает результат, когда операция завершится, или передаёт возникшее исключение.</p>
<p>Если нужна собственная асинхронная операция с возвращаемым значением, объявляем её как <code>Асинх Функция</code>, а вызываем с <code>Ждать</code> из другого асинхронного метода.</p>
<h2 id="что-асинхронность-не-делает-автоматически">Что асинхронность не делает автоматически</h2>
<p>Если внутри асинхронной процедуры выполнить долгий обычный цикл, он останется обычным вычислением. Модификатор <code>Асинх</code> сам по себе не переносит расчёт на сервер и не запускает отдельный поток.</p>
<p>Для отдельного выполнения длительной серверной операции используем <a href="/restart/l/02/32/" data-internal="true">32. Фоновые и регламентные задания</a>. Обычный вызов серверного метода и <code>Ждать</code> — тоже разные механизмы.</p>
