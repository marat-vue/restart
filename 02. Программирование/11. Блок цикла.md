> [!abstract] Коротко
> Три цикла: `Для Сч = 1 По N Цикл` (счётчик), `Для Каждого Эл Из Коллекция Цикл` (обход коллекции), `Пока Условие Цикл` (пока истинно). `Прервать` выходит из цикла, `Продолжить` переходит к следующей итерации. В `Пока` обязательно меняем то, от чего зависит условие.

## Зачем нужен цикл

**Цикл** повторяет одни и те же строки кода несколько раз. Без него, чтобы вывести числа от 1 до 100, пришлось бы написать 100 строк `Сообщить()`. Каждое повторение называется **итерацией**.

В 1С три вида цикла:

| Цикл | Когда используем | Пример задачи |
| --- | --- | --- |
| `Для … По …` | Знаем, **сколько раз** повторить | Вывести номера талонов с 1 по 3 |
| `Для Каждого … Из …` | Нужно перебрать **все элементы коллекции** | Обойти строки табличной части документа |
| `Пока …` | Повторяем, **пока выполняется условие**; число повторов заранее неизвестно | Уменьшать остаток, пока он не станет нулём |

Все три заканчиваются словом `КонецЦикла;`.

## Для — цикл со счётчиком

```1C
Для НомерТалона = 1 По 3 Цикл
	Сообщить(НомерТалона);
КонецЦикла;
```

Как это работает:
1. Переменной-**счётчику** `НомерТалона` присваивается начальное значение `1`.
2. Если счётчик не больше конечного значения `3`, выполняется тело цикла (строки между `Цикл` и `КонецЦикла`).
3. Счётчик автоматически увеличивается на 1, и всё повторяется с шага 2.

Результат — три сообщения: `1`, `2`, `3`. Шаг всегда равен 1; если начальное значение больше конечного (`Для Н = 5 По 1`), тело не выполнится ни разу.

## Пока — цикл с условием

```1C
ОстатокКонфет = 3;

Пока ОстатокКонфет > 0 Цикл
	Сообщить("Осталось конфет: " + ОстатокКонфет);
	ОстатокКонфет = ОстатокКонфет - 1;
КонецЦикла;

Сообщить("Конфеты закончились");
```

Перед **каждой** итерацией проверяется условие после `Пока`. Пока оно истинно — тело выполняется; как только стало ложным — программа переходит к строке после `КонецЦикла`.

Результат: `Осталось конфет: 3`, `Осталось конфет: 2`, `Осталось конфет: 1`, `Конфеты закончились`.

> [!warning] Бесконечный цикл
> Если внутри `Пока` забыть строку `ОстатокКонфет = ОстатокКонфет - 1`, условие всегда будет истинным, и программа «зависнет». Прервать такой цикл в 1С:Предприятии можно сочетанием `Ctrl+Break`. Правило: в теле `Пока` обязательно меняем то, от чего зависит условие.

## Для Каждого — обход коллекции

**Коллекция** — это значение, в котором хранится несколько элементов: массив, строки табличной части, результат запроса. Подробно коллекции разберём в [[18. Массивы]] и следующих уроках, а пока достаточно знать, что массив — это список значений.

```1C
Товары = Новый Массив;      // создали пустой список
Товары.Добавить("Телефон"); // добавили элементы
Товары.Добавить("Ноутбук");

Для Каждого Товар Из Товары Цикл
	Сообщить(Товар);
КонецЦикла;
```

Переменная `Товар` на каждой итерации содержит очередной элемент: сначала `"Телефон"`, потом `"Ноутбук"`. Счётчик не нужен — цикл сам закончится после последнего элемента.

Точно так же обходят строки табличной части документа. Например, в модуле объекта `РасходнаяНакладная`, где `Товары` — её табличная часть, а `СтрокаТовара` — одна строка:

```1C
Для Каждого СтрокаТовара Из Товары Цикл
	СтрокаТовара.Сумма = СтрокаТовара.Количество * СтрокаТовара.Цена;
КонецЦикла;
```

> [!tip] Шаблоны
> Наберите `Для`, `ДляКаждого` или `Пока` и нажмите `Ctrl+Q` — Конфигуратор вставит заготовку цикла.

## Прервать и Продолжить

`Прервать` заканчивает ближайший цикл целиком. `Продолжить` пропускает остаток текущей итерации и переходит к следующей:
```1C
Для Номер = 1 По 10 Цикл

	Если Номер = 3 Тогда
		Продолжить;
	КонецЕсли;

	Если Номер = 6 Тогда
		Прервать;
	КонецЕсли;

	Сообщить(Номер);

КонецЦикла;
```

Результат: 1, 2, 4, 5. Тройку пропустили, а на шестёрке закончили цикл.

> [!warning] Удаление элементов в цикле
> При удалении элементов коллекции во время обхода нужно отдельно продумать индексы: следующий элемент может сдвинуться и остаться необработанным.

> [!question]- Проверь себя
> 1. Какой цикл удобнее для обхода табличной части?
> 2. Чем `Прервать` отличается от `Продолжить`?
> 3. Почему опасно удалять элементы массива в цикле с возрастающим индексом?
>
> > [!success]- Ответы
> > 1. `Для Каждого Строка Из Товары Цикл`.
> > 2. `Прервать` завершает весь цикл, `Продолжить` — только текущую итерацию.
> > 3. Элементы сдвигаются, и следующий окажется пропущен. Удаляем, обходя с конца: `Инд = Массив.ВГраница(); Пока Инд >= 0 Цикл … Инд = Инд - 1; КонецЦикла;`.
