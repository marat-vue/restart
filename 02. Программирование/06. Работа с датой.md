> [!abstract] Коротко
> Дата в 1С хранит год…секунды; литерал — `'20260912183000'`, конструктор — `Дата(2026, 9, 12)`. Разность дат — **секунды**, прибавление числа — секунды; месяцы добавляем `ДобавитьМесяц()`. Границы периодов — `НачалоДня/КонецДня/НачалоМесяца/КонецМесяца…`. На сервере для даты документа — `ТекущаяДатаСеанса()`.

## Что такое дата в 1С

Тип **Дата** хранит момент времени: сразу год, месяц, день, час, минуту и секунду. Отдельного типа «только время» или «только день» нет — у даты без времени часы, минуты и секунды просто равны нулю.

Дату в коде можно записать **литералом** — в одинарных кавычках `'…'` (не в двойных, как строку!). Порядок всегда «год, месяц, день, часы, минуты, секунды», разделители не обязательны:
```1C
Дата_1 = '20260912210000';
Дата_2 = '2026.09.12. 21:00:00';
Дата_3 = '2026-09-12 21:00:00';
Дата_4 = '2026/09/12 21:00:00';
```

Второй способ — функция `Дата()`, в которую части даты передаются числами. Её удобно использовать, когда год, месяц и день лежат в переменных:
```1C
Дата_1 = Дата(2026, 9, 12);
Дата_2 = Дата(2026, 9, 12, 18, 30, 45);
```

## Операции с датами

Даты можно вычитать, результат будет в секундах:
```1C
Дата_1 = Дата(2026, 9, 12, 18, 30, 45);
Дата_2 = Дата(2026, 9, 12, 18, 30, 0);

Сообщить(Дата_1 - Дата_2); // 45
```

К дате можно прибавлять числовые значения в секундах:
```1C
Дата_1 = Дата(2026, 9, 12, 18, 30, 0);
Дата_1 = Дата_1 + 60;

Сообщить(Дата_1); // 12.09.2026 18:31:00
```

Чтобы прибавить дни, переводим их в секунды: в сутках 24 × 60 × 60 = 86 400 секунд.
```1C
Дата_1 = Дата(2026, 9, 12, 18, 30, 0);
Дата_1 = Дата_1 + 5 * 24 * 60 * 60;

Сообщить(Дата_1); // 17.09.2026 18:30:00
```

Если нужно добавить месяц, нельзя просто прибавить 30 дней, так как месяцы имеют разную длину:
```1C
НоваяДата = ДобавитьМесяц(Дата(2026, 1, 31), 1);
Сообщить(НоваяДата); // 28.02.2026
```
## Функции работы с датой

В примерах используем дату `Д = '20260912210324';` — 12 сентября 2026 года, 21:03:24.

**Получить часть даты** (результат — число):

| Функция | Что возвращает | Пример → результат |
| --- | --- | --- |
| `Год(Д)` | Год | `Год(Д)` → `2026` |
| `Месяц(Д)` | Номер месяца | `Месяц(Д)` → `9` |
| `День(Д)` | День месяца | `День(Д)` → `12` |
| `Час(Д)`, `Минута(Д)`, `Секунда(Д)` | Часы, минуты, секунды | `Час(Д)` → `21` |
| `ДеньНедели(Д)` | Номер дня недели: 1 — понедельник … 7 — воскресенье | `ДеньНедели(Д)` → `6` (суббота) |
| `НеделяГода(Д)` | Номер недели в году | `НеделяГода(Д)` → `37` |

**Получить границу периода** (результат — дата). Нужны постоянно: «продажи за месяц» — это всё, что между началом и концом месяца.

| Функция | Пример → результат |
| --- | --- |
| `НачалоДня(Д)` / `КонецДня(Д)` | `12.09.2026 0:00:00` / `12.09.2026 23:59:59` |
| `НачалоМесяца(Д)` / `КонецМесяца(Д)` | `01.09.2026 0:00:00` / `30.09.2026 23:59:59` |
| `НачалоГода(Д)` / `КонецГода(Д)` | `01.01.2026 0:00:00` / `31.12.2026 23:59:59` |

Есть и аналоги для часа, минуты, недели и квартала: `НачалоНедели`, `КонецКвартала` и т. д.

**Текущая дата:** `ТекущаяДата()` → например, `12.09.2026 21:03:24` (подробнее — в конце урока).

## Форматирование даты

`Сообщить(Д)` выводит дату в стандартном виде `12.09.2026 21:03:24`. Чтобы показать её иначе, используем `Формат()` — как и для чисел ([[05. Работа с числами]]):

```1C
Д = '20260912183000';

Сообщить(Формат(Д, "ДФ=dd.MM.yyyy"));            // 12.09.2026
Сообщить(Формат(Д, "ДФ='dd.MM.yyyy HH:mm'"));    // 12.09.2026 18:30
Сообщить(Формат(Д, "ДЛФ=DD"));                   // 12 сентября 2026 г.
```

В строке формата `dd` — день, `MM` — месяц (заглавные!), `yyyy` — год, `HH` — часы, `mm` — минуты (строчные). Перепутать `MM` и `mm` — частая ошибка. Если в формате есть пробел, берём его в одинарные кавычки, как во втором примере. Строку формата удобно собрать через **ПКМ → Конструктор форматной строки…**.

## Текущая дата сеанса

`ТекущаяДата()` возвращает дату и время компьютера, где выполняется код. На клиенте это компьютер пользователя, на сервере — сервер.

Если нужна текущая дата с учётом часового пояса сеанса, в серверном прикладном коде используем `ТекущаяДатаСеанса()`. Например, так можно заполнить дату создаваемого документа.

> [!warning] Важно
> Само значение типа `Дата` не хранит часовой пояс. При обмене данными нужно заранее договориться, какое время мы передаём.

> [!question]- Проверь себя
> 1. Как прибавить к дате 3 дня?
> 2. Что вернёт `ДобавитьМесяц('20260131', 1)`?
> 3. Почему `ТекущаяДата()` на клиенте может отличаться от серверной?
> 4. Документ от 31.10 15:00. Попадёт ли он в условие `Дата <= '20261031'`?
>
> > [!success]- Ответы
> > 1. `Дата + 3 * 86400` (86400 секунд в сутках).
> > 2. 28.02.2026 — последний день месяца, а не 03.03.
> > 3. Она берёт время компьютера, где выполняется код.
> > 4. Нет: литерал означает 31.10 00:00:00. Нужен `КонецДня()`.
