> [!abstract] Коротко
> **Процедура** выполняет действия, **функция** ещё и возвращает значение через `Возврат`. Параметры по умолчанию передаются **по ссылке** (изменение внутри видно снаружи), `Знач` — по значению. Параметры могут иметь значения по умолчанию. `Экспорт` делает метод доступным из других модулей.

## Зачем нужны процедуры и функции

Представьте, что расчёт суммы строки с учётом скидки нужен в пяти местах программы. Можно скопировать одну и ту же формулу пять раз — но если правило расчёта изменится, придётся искать и исправлять все копии. Удобнее один раз описать алгоритм, дать ему **имя** и дальше просто вызывать по имени. Такой именованный кусок кода называется **методом**.

Методы бывают двух видов:

| | Процедура | Функция |
| --- | --- | --- |
| Что делает | Выполняет действия | Выполняет действия **и возвращает результат** |
| Объявление | `Процедура Имя() … КонецПроцедуры` | `Функция Имя() … КонецФункции` |
| Результат можно присвоить | Нет | Да: `Х = Имя();` |
| Пример встроенного метода | `Сообщить("Текст")` — просто выводит текст | `Окр(12.345, 2)` — возвращает `12.35` |

Платформа уже содержит сотни встроенных методов (`Сообщить`, `Окр`, `СтрДлина`…). Их описание ищем в Синтакс-помощнике. Свои методы пишем сами — об этом урок.

> [!info] Где метод можно вызвать
> Не каждый метод доступен везде: часть работает только на сервере, часть — только на клиенте. Это указано в разделе «Доступность» Синтакс-помощника ([[01. Основы программирования]]). Пока все примеры пишем в одном модуле, и об этом можно не думать; клиент и сервер разберём в [[26. Общие модули и контекст выполнения]].

## Собственная функция

Для расчёта суммы строки создадим функцию:
```1C
Функция РассчитатьСумму(Количество, Цена, Скидка = 0)

	Сумма = Количество * Цена * (1 - Скидка / 100);
	Возврат Окр(Сумма, 2);

КонецФункции
```

Разберём код:
- `Количество`, `Цена`, `Скидка` — параметры, которые получает функция.
- `Скидка = 0` — значение по умолчанию. Этот параметр можно не передавать.
- `Возврат` — завершает функцию и отдаёт результат вызывающему коду.

Объявление функции само по себе ничего не выполняет — это только «рецепт». Чтобы функция сработала, её нужно **вызвать**: написать имя и в скобках передать значения параметров. Например, из другой процедуры того же модуля:
```1C
СуммаБезСкидки = РассчитатьСумму(2, 150);
СуммаСоСкидкой = РассчитатьСумму(2, 150, 10);

Сообщить(СуммаБезСкидки); // 300
Сообщить(СуммаСоСкидкой); // 270
```

## Процедура и ранний выход

В процедуре `Возврат` используется без значения. Он позволяет закончить выполнение раньше:
```1C
Процедура ПоказатьСумму(Количество, Цена)

	Если Количество <= 0 Тогда
		Сообщить("Количество должно быть больше нуля");
		Возврат;
	КонецЕсли;

	Сообщить(РассчитатьСумму(Количество, Цена));

КонецПроцедуры
```

После `Возврат` оставшийся код этой процедуры не выполняется.

## Передача параметров и Знач

По умолчанию параметр может изменять переменную, переданную при вызове:
```1C
Процедура Увеличить(Количество)
	Количество = Количество + 1;
КонецПроцедуры

Процедура ПроверитьПередачу()
	КоличествоТовара = 5;
	Увеличить(КоличествоТовара);
	Сообщить(КоличествоТовара); // 6
КонецПроцедуры
```

Если написать `Процедура Увеличить(Знач Количество)`, присваивание нового значения параметру уже не изменит переменную вызывающего кода.

> [!warning] Важно
> `Знач` не создаёт глубокую копию изменяемого объекта. Если передать массив через `Знач` и вызвать у него `Добавить()`, изменится тот же массив. Для независимой коллекции нужна отдельная копия.

## Экспорт

Метод с ключевым словом `Экспорт` можно вызывать из другого модуля, если это допускается видом модуля и контекстом:
```1C
Функция РассчитатьСумму(Количество, Цена) Экспорт
	Возврат Окр(Количество * Цена, 2);
КонецФункции
```

Если поместить такую функцию в неглобальный общий модуль `РасчетыКлиентСервер`, вызов будет таким:
```1C
Сумма = РасчетыКлиентСервер.РассчитатьСумму(2, 150);
```

Настройку общего модуля разберём в [[26. Общие модули и контекст выполнения]]. Эти два варианта функции — отдельные примеры. Два метода с одним именем в одном модуле объявлять нельзя.

> [!question]- Проверь себя
> 1. Можно ли присвоить результат процедуры переменной?
> 2. `Процедура П(Х) Х = Х + 1; КонецПроцедуры` — изменится ли переменная, переданная в П?
> 3. Защищает ли `Знач` массив от `Добавить()` внутри метода?
> 4. Как вызвать метод общего модуля `РасчетыКлиентСервер` из другого модуля?
>
> > [!success]- Ответы
> > 1. Нет, только результат функции.
> > 2. Да, без `Знач` параметр передаётся по ссылке.
> > 3. Нет: `Знач` не копирует сам массив, изменится тот же экземпляр.
> > 4. Объявить его с `Экспорт` и вызвать `РасчетыКлиентСервер.ИмяМетода(...)`.
