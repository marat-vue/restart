> [!abstract] Коротко
> **Структура** настроек определяет вид отчёта: группировки (вложенные уровни) и `<Детальные записи>`. **Выбранные поля** — какие колонки выводить; у каждого узла структуры могут быть свои. Конструктор настроек удобен для первого раза, но при повторном запуске перезапишет ручные правки.

## Структура — скелет отчёта

Набор данных, ресурсы и параметры готовы, но отчёт пока пустой. Не хватает главного: **как** раскладывать строки. Это задаёт **структура** — дерево на вкладке **Настройки**.

Сравним два отчёта на одних и тех же данных:

**Структура «Номенклатура → Детальные записи»:**

```text
Чайник           3    500
   Ромашка       2    300
   Петров        1    200
Блендер          1    300
   Петров        1    300
Итого            4    800
```

**Структура «Контрагент → Номенклатура»:**

```text
Петров           2    500
   Чайник        1    200
   Блендер       1    300
Ромашка          2    300
   Чайник        2    300
Итого            4    800
```

Данные одни, а вид разный — его определяет только структура.

| Элемент структуры | Что это |
| --- | --- |
| **Отчёт** | Корень дерева: настройки всего отчёта |
| **Группировка** (например, `Номенклатура`) | Уровень, на котором строки сворачиваются по значению поля и показывается итог |
| **`<Детальные записи>`** | Группировка **без поля**: выводит исходные строки набора как есть |

Вложенность в дереве = вложенность в отчёте: группировка внутри группировки даёт подуровень.

## Шаг 1. Быстрый старт — конструктор настроек

Для первой настройки удобно воспользоваться мастером:

1. Открываем вкладку **Настройки**. Слева вверху — дерево структуры, внизу — закладки настроек выбранного элемента.
2. Нажимаем кнопку **Открыть конструктор настроек** (на панели над деревом).
3. Тип отчёта — **Список**. **Далее**.
4. Переносим поля `Номенклатура`, `Контрагент`, `Количество`, `Выручка` в правый список. **Далее**.
5. Группировка: переносим `Номенклатура`. **Далее**.
6. Порядок: `Номенклатура` по возрастанию. **Готово**.

## Шаг 2. Проверяем дерево

Должно получиться:

```text
Отчёт
└─ Номенклатура
   └─ <Детальные записи>
```

![[09-Структура-и-параметры-настроек.jpg]]

*Вкладка «Настройки»: дерево структуры вверху, закладки настроек выбранного узла внизу.*

Если детальных записей нет (только `Номенклатура`), добавляем их вручную: выделяем группировку `Номенклатура` → **ПКМ → Новая группировка** → поле группировки **не выбираем** → **ОК**. Группировка без поля и есть `<Детальные записи>`.

## Шаг 3. Какие колонки показывать — «Выбранные поля»

1. Выделяем корень **Отчёт**.
2. Внизу открываем закладку **Выбранные поля**.
3. Слева — все доступные поля, справа — выводимые. Переносим нужные и задаём порядок стрелками.
4. Флажок слева от поля включает или временно выключает его вывод.

![[10-Выбранные-поля.jpg]]

*Закладка «Выбранные поля» существующего отчёта (поля с исходными именами `КоличествоОборот`, `СуммаОборот`; в новом отчёте — `Количество`, `Выручка`).*

> [!warning] Поле есть в наборе, но не выводится
> Наличие поля в наборе данных означает только, что его **можно** вывести. Выводятся лишь поля из «Выбранных полей». Не видите колонку — проверьте выбранные поля и флажок рядом с ней.

### Настройки у каждого узла свои

Закладки внизу (Выбранные поля, Отбор, Сортировка, Условное оформление…) показывают настройки **выделенного** узла дерева. У корня «Отчёт» — для всего отчёта, у группировки — только для неё. Прежде чем что-то менять внизу, посмотрите, какой узел выделен вверху. Новички часто меняют настройки не того уровня и удивляются, что ничего не изменилось.

## Варианты структуры

| Нужно | Как сделать |
| --- | --- |
| Только итоги по товарам, без покупателей | Снять флажок у `<Детальные записи>` или удалить этот узел |
| Сначала покупатель, внутри товар | Группировка `Контрагент`, внутри неё — `Номенклатура` |
| Плоский список без группировок | Только `<Детальные записи>` прямо под «Отчёт» |
| Итог по товару без строки «Итого» внизу | Закладка **Другие настройки** корня → «Расположение общих итогов по вертикали» → Нет |

## Осторожно с повторным запуском конструктора

Конструктор настроек создаёт структуру **заново**. Если вы вручную донастроили отчёт, а потом снова запустили конструктор, ручные изменения будут потеряны — платформа об этом предупредит:

![[13-Повторный-запуск-конструктора-настроек.jpg]]

*Повторный запуск конструктора настроек: «Настройки, введённые вручную, будут утеряны. Продолжить?». Отвечаем «Нет», если структура уже донастроена руками.*

Конструктор — для первого раза. Дальше правим дерево и закладки напрямую.

## Проверка

1. Сохраните, обновите БД, сформируйте отчёт за октябрь.
2. Видны товары с итогами и вложенные строки покупателей; внизу — «Итого».
3. Отключите `<Детальные записи>` — остались только строки товаров, итоги те же.
4. Поменяйте структуру на «Контрагент → Номенклатура» — общий итог не изменился.

> [!question]- Проверь себя
> 1. Как получить детальные строки внутри группы товара?
> 2. Поле есть в наборе, но не выводится. Почему?
> 3. Нужны только итоги по товарам. Что сделать?
>
> > [!success]- Ответы
> > 1. Добавить в группу вложенную группировку без поля — `<Детальные записи>`.
> > 2. Оно не добавлено в выбранные поля.
> > 3. Отключить `<Детальные записи>`.
