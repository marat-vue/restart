> [!abstract] Коротко
> `NULL` — «нет значения» в результате запроса (чаще всего при левом соединении). Проверяем `ЕСТЬ NULL` / `ЕСТЬ НЕ NULL` (не `= NULL`), заменяем `ЕСТЬNULL(Поле, 0)`. `NULL + 10 = NULL`. `NULL`, пустая ссылка, `0`, `""` и `Неопределено` — разные значения.

## Откуда берётся NULL

В прошлом уроке левое соединение оставило кружку без пары в продажах. Что тогда лежит в колонке «Выручка» у кружки? Не 0 и не пустая строка, а особое значение **`NULL`** — «значения нет вообще».

| Товар | П.СуммаОборот |
| --- | --- |
| Чайник | 500 |
| Блендер | 300 |
| Кружка | **NULL** |

Аналогия: анкета, где вопрос «Сколько у вас детей?». Ответ «0» — это значение: человек ответил «ноль». Пустая графа — это `NULL`: ответа **нет**, и мы не знаем, сколько детей.

Чаще всего `NULL` появляется:
- при **левом/правом/полном соединении**, когда пары не нашлось;
- при обращении через точку к реквизиту, которого нет у объекта (например, после `ВЫРАЗИТЬ` к «чужому» типу).

## NULL, ноль, пустая ссылка — это разные вещи

| Значение | Что означает | Пример |
| --- | --- | --- |
| `0` | Число ноль — значение есть | Продали на 0 ₽ |
| `""` | Пустая строка — значение есть, но без символов | Комментарий не заполнен |
| Пустая ссылка | Значение ссылочного типа «ничего не выбрано» | Покупатель не выбран |
| `NULL` | Значения нет — строки-пары не существует | Продаж кружки нет вообще |
| `Неопределено` | Значение **встроенного языка**, а не запроса | Переменная без значения |

> [!info] Что получит код
> Когда результат запроса попадает в код на встроенном языке, `NULL` остаётся значением типа `NULL`. Проверить его в коде можно так: `Если Выборка.Выручка = NULL Тогда`. В **тексте запроса** так нельзя — см. ниже.

## Как проверить NULL в запросе

```1C
ГДЕ П.Номенклатура ЕСТЬ NULL
```

Так находим товары **без продаж** — у них правой пары нет. Обратное условие: `ЕСТЬ НЕ NULL`.

> [!warning] `= NULL` не работает
> В языке запросов любое сравнение с `NULL` через `=`, `<>`, `>` даёт «неизвестно», а не «истина». Поэтому `ГДЕ П.Номенклатура = NULL` не отберёт **ни одной** строки. Для проверки всегда пишем `ЕСТЬ NULL`.

## Как заменить NULL: `ЕСТЬNULL`

```1C
ЕСТЬNULL(П.СуммаОборот, 0) КАК Выручка
```

Функция `ЕСТЬNULL(Значение, Замена)` возвращает:
- `Значение`, если оно не `NULL`;
- `Замена`, если `Значение` равно `NULL`.

| П.СуммаОборот | ЕСТЬNULL(П.СуммаОборот, 0) |
| --- | --- |
| 500 | 500 |
| 0 | 0 |
| NULL | **0** |

Обратите внимание: слово пишется **слитно** — `ЕСТЬNULL` — это функция. `ЕСТЬ NULL` с пробелом — это условие проверки.

Значение замены выбираем того же типа: для суммы — `0`, для строки — `""`. Если тип замены другой (например, длинная строка вместо короткой), значение может обрезаться до длины первого аргумента.

`ЕСТЬNULL` **не трогает** пустую ссылку и пустую строку — это не `NULL`. Для них нужны свои условия.

## Почему NULL «съедает» строки и суммы

**Арифметика:** любое действие с `NULL` даёт `NULL`.

```1C
П.СуммаОборот + 10        // для кружки: NULL + 10 = NULL
ЕСТЬNULL(П.СуммаОборот, 0) + 10   // для кружки: 0 + 10 = 10
```

**Условия:** условие с `NULL` не истинно — строка не пройдёт `ГДЕ`.

```1C
ГДЕ П.СуммаОборот < 100   // хотим «продажи меньше 100 или их нет»
```

Кружка (`NULL`) **не попадёт** в результат: `NULL < 100` — не истина. Правильно:

```1C
ГДЕ ЕСТЬNULL(П.СуммаОборот, 0) < 100
```

> [!tip] Правило
> После левого соединения все поля правой таблицы могут быть `NULL`. Используете их в расчёте или условии — сначала оберните в `ЕСТЬNULL`.

## Проверка

1. Возьмите запрос с левым соединением из прошлого урока, но без `ЕСТЬNULL`. Найдите строку с `NULL` у непроданного товара.
2. Добавьте условие `ГДЕ П.Номенклатура ЕСТЬ NULL` — останутся только непроданные товары.
3. Замените `ЕСТЬ NULL` на `= NULL` — результат станет пустым. Это доказательство, что сравнивать через `=` нельзя.
4. Выведите рядом `П.СуммаОборот` и `ЕСТЬNULL(П.СуммаОборот, 0)` — объясните, почему у непроданного товара значения различаются.

> [!question]- Проверь себя
> 1. Как найти товары, для которых не нашлось продаж?
> 2. Заменит ли `ЕСТЬNULL` пустую ссылку?
> 3. Почему нельзя писать `= NULL`?
>
> > [!success]- Ответы
> > 1. `ГДЕ П.Номенклатура ЕСТЬ NULL`.
> > 2. Нет, только `NULL`.
> > 3. Сравнение с NULL не даёт Истину; нужен оператор `ЕСТЬ NULL`.
