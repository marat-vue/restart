> [!abstract] Коротко
> Значения из программы передаём **параметрами**: в тексте `&Имя`, в коде `Запрос.УстановитьПараметр("Имя", Значение)`. Параметром можно передать дату, ссылку, массив, но не имя таблицы. Дата содержит время: для периода используем полуоткрытый интервал `>= &Начало И < &СледующийДень` или конец периода `КонецДня()`.

## Зачем нужны параметры

В прошлом уроке мы писали числа прямо в текст запроса: `Н.ИтоговаяСумма >= 1000`. Но обычно значение заранее неизвестно: пользователь выбирает период, покупателя, товар. Значит, его нужно **передать в запрос из программы**. Для этого служат **параметры**.

Аналогия: текст запроса — это **бланк** с пустыми полями «с ____ по ____». Параметр — это пустое поле бланка, а `УстановитьПараметр` — заполнение этого поля перед отправкой.

В тексте запроса параметр обозначается знаком `&` и именем: `&Начало`, `&Покупатель`. Имя придумываем сами.

## Пример: накладные за октябрь

```1C
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|    Н.Ссылка,
|    Н.Дата,
|    Н.ИтоговаяСумма
|ИЗ
|    Документ.РасходнаяНакладная КАК Н
|ГДЕ
|    Н.Дата >= &Начало
|    И Н.Дата < &КонецИсключая
|    И Н.Проведен";

Запрос.УстановитьПараметр("Начало", Дата(2026, 10, 1));
Запрос.УстановитьПараметр("КонецИсключая", Дата(2026, 11, 1));
Результат = Запрос.Выполнить();
```

Разберём:

| Строка | Смысл |
| --- | --- |
| `Н.Дата >= &Начало` | Дата документа не раньше значения параметра «Начало» |
| `Н.Дата < &КонецИсключая` | И строго раньше значения «КонецИсключая» |
| `УстановитьПараметр("Начало", …)` | Передаём значение. Имя — **без** `&`, и оно должно точно совпадать с именем в тексте |

Фрагмент выполняем **на сервере** (например, в функции модуля `УчебныеЗапросыСервер` из [[02. Первый запрос в конструкторе и в коде]]). Он выбирает весь октябрь: 1 октября 00:00:00 включено, 1 ноября 00:00:00 — уже нет.

> [!warning] Забыли передать параметр
> Если в тексте есть `&Начало`, а `УстановитьПараметр("Начало", …)` не вызван (или имя написано с опечаткой: `"Начла"`), `Выполнить()` завершится ошибкой вида «Не задано значение параметра "Начало"». Увидев её, сверяем имена параметров в тексте и в коде буква в букву.

## Что можно передать параметром

| Тип значения | Пример условия | Что передаём |
| --- | --- | --- |
| Дата | `Н.Дата >= &Начало` | `Дата(2026, 10, 1)` |
| Число | `Н.ИтоговаяСумма > &МинСумма` | `1000` |
| Строка | `Н.Наименование ПОДОБНО &Шаблон` | `"Чай%"` |
| Ссылка | `Н.Покупатель = &Покупатель` | Ссылка на элемент справочника |
| Список значений | `Н.Покупатель В (&Покупатели)` | Массив ссылок |
| Значение перечисления | `Н.ВидНоменклатуры = &Вид` | `Перечисления.ВидыНоменклатуры.Товар` |

Чего параметром передать **нельзя**: имя таблицы, имя поля, кусок текста запроса. Параметр — это всегда *значение*, а не часть «грамматики» запроса.

## Почему не склеивать текст запроса

Так делать **нельзя**:

```1C
// ПЛОХО
Запрос.Текст = "ВЫБРАТЬ … ГДЕ Н.Наименование = """ + ТекстИзПоля + """";
```

Проблемы:
1. Если в названии есть кавычка (`ООО "Ромашка"`), запрос сломается.
2. Число или дата превратятся в строку с пробелами и запятыми, и сравнение не сработает.
3. Пользователь может ввести текст, который изменит смысл запроса.

Параметр решает всё сразу: значение передаётся «как есть», со своим типом.

## Дата всегда содержит время

Это самая частая ошибка новичков в запросах. Значение типа Дата в 1С хранит **и день, и время**. `Дата(2026, 10, 31)` — это **31 октября 00:00:00**, самое начало дня.

Посмотрим, что будет с условием `Н.Дата <= &Конец`, где `&Конец = Дата(2026, 10, 31)`:

| Документ | Дата и время | Попадёт? |
| --- | --- | --- |
| №1 | 30.10.2026 18:00:00 | Да |
| №2 | 31.10.2026 00:00:00 | Да |
| №3 | 31.10.2026 15:00:00 | **Нет!** 15:00 позже 00:00 |

Документ №3 пропал, хотя пользователь выбрал период «по 31 октября». Два правильных способа:

| Подход | Условие | Что передаём в «конец» |
| --- | --- | --- |
| Полуоткрытый интервал | `Н.Дата >= &Начало И Н.Дата < &СледующийДень` | Начало **следующего** дня: `Дата(2026, 11, 1)` |
| Обе границы включены | `Н.Дата МЕЖДУ &Начало И &Конец` | Конец дня: `КонецДня(Дата(2026, 10, 31))` = 31.10.2026 23:59:59 |

```1C
ДатаОкончания = Дата(2026, 10, 31);                      // выбрал пользователь
Запрос.УстановитьПараметр("Конец", КонецДня(ДатаОкончания)); // 31.10.2026 23:59:59
```

`КонецДня()` — функция **встроенного языка** ([[02. Программирование/06. Работа с датой|06. Работа с датой]]); вызываем её в коде, *до* передачи параметра. В самом тексте запроса такой функции нет. В отчётах СКД для этого используется другой синтаксис: [[22. Параметры периода в СКД]].

> [!info] Виртуальные таблицы
> У виртуальных таблиц регистров (`Обороты`, `Остатки`) собственные правила границ периода. Их разбираем в [[16. Виртуальные таблицы регистров накопления]].

## Параметр-список

Чтобы выбрать накладные нескольких покупателей, передаём **массив**:

```1C
Покупатели = Новый Массив;
Покупатели.Добавить(ПокупательИванов);
Покупатели.Добавить(ПокупательПетров);
Запрос.УстановитьПараметр("Покупатели", Покупатели);
```

```1C
ГДЕ Н.Покупатель В (&Покупатели)
```

Передаём **ссылки** на контрагентов, а не строки с их названиями: у двух контрагентов может быть одинаковое название, а ссылка у каждого своя.

## Параметры в конструкторе

На вкладке **Условия** в правой части условия пишем `&Начало` — конструктор поймёт, что это параметр. Значения параметров конструктор не задаёт: их всегда передаёт код через `УстановитьПараметр`.

## Проверка

1. Создайте накладную от 31.10.2026 15:00 и накладную от 01.11.2026 00:00.
2. Выполните запрос с условием `Н.Дата <= &Конец`, где `Конец = Дата(2026, 10, 31)`. Накладная 31.10 **не** попадёт.
3. Передайте `КонецДня(Дата(2026, 10, 31))` — накладная 31.10 появится, ноябрьская по-прежнему не попадёт.
4. Закомментируйте строку `УстановитьПараметр("Начало", …)` — получите ошибку «Не задано значение параметра». Верните строку.

> [!question]- Проверь себя
> 1. Почему нельзя склеивать значение пользователя с текстом запроса?
> 2. Документ от 31.10 15:00 и условие `Дата <= &Конец` с `&Конец = Дата(2026,10,31)`. Попадёт?
> 3. Можно ли параметром передать список покупателей?
>
> > [!success]- Ответы
> > 1. Теряется тип, появляются ошибки с кавычками и уязвимость; параметры решают это.
> > 2. Нет. Конец нужно передать как `КонецДня(...)`.
> > 3. Да, массив ссылок для условия `В (&Покупатели)`.
