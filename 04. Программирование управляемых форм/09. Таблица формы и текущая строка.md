> [!abstract] Коротко
> Различаем три вещи: `Объект.Товары` — **данные** всех строк, `Элементы.Товары` — **таблица на экране**, `Элементы.Товары.ТекущиеДанные` — **данные текущей строки** (или `Неопределено`). Обходим и меняем данные, текущую строку получаем через элемент. Активную строку задаём идентификатором: `ТекущаяСтрока = Строка.ПолучитьИдентификатор()`.

## Три разные вещи с похожими именами

С таблицей товаров на форме связаны **три** объекта, и новички их постоянно путают. Вспомним аналогию «температура и термометр» из урока 01:

| Выражение | Что это | Аналогия | Что с ним делаем |
| --- | --- | --- | --- |
| `Объект.Товары` | **Данные**: коллекция всех строк | Список покупок на бумаге | Обходим циклом, добавляем, удаляем строки, считаем итог |
| `Элементы.Товары` | **Элемент**: таблица на экране | Экран, на котором список показан | Узнаём, какая строка выделена; скрываем таблицу |
| `Элементы.Товары.ТекущиеДанные` | **Данные одной строки**, где стоит курсор (или `Неопределено`) | Строка списка, на которую указывает палец | Читаем и меняем значения этой строки |
| `Элементы.ТоварыКоличество` | Элемент-колонка «Количество» | Столбец на экране | Скрыть колонку, сделать только для просмотра |

`ТоварыКоличество` — имя **элемента**-колонки, `Количество` — имя **реквизита** строки. Колонкой управляем через `Элементы`, значение читаем из данных строки.

## Проверяем таблицу и колонки

У таблицы `Товары` в дереве элементов **ПутьКДанным = `Объект.Товары`**, у колонок — `Объект.Товары.Товар`, `.Количество`, `.Цена`, `.Сумма`.

![[УФ-10-Таблица-и-колонки.png]]

*Таблица `Товары` и её колонки в дереве элементов.*

Нет нужной колонки — перетаскиваем реквизит из `Объект → Товары` (правая панель) внутрь таблицы в дереве. Не создаём реквизит `Количество` в корне формы: это будет одно число на всю форму, а не количество строки.

## Текущая строка: где стоит курсор

Создадим команду `ПоказатьТекущуюСтроку` и кнопку для неё в командной панели таблицы (как в [[06. Команды формы и кнопки]]):

```1C
&НаКлиенте
Процедура ПоказатьТекущуюСтроку(Команда)

	СтрокаТовара = Элементы.Товары.ТекущиеДанные;
	Если СтрокаТовара = Неопределено Тогда
		Сообщить("Выберите строку в таблице товаров");
		Возврат;
	КонецЕсли;

	Сообщить(СтрШаблон("Товар: %1; количество: %2; сумма: %3",
		СтрокаТовара.Товар, СтрокаТовара.Количество, СтрокаТовара.Сумма));

КонецПроцедуры
```

Проверка на `Неопределено` **обязательна**: если таблица пустая или ни одна строка не выделена, `ТекущиеДанные` вернёт `Неопределено`, и обращение к `.Товар` вызовет ошибку.

`ТекущиеДанные` — не копия: присваивание `СтрокаТовара.Количество = 2` изменит строку прямо в форме.

## Все строки: обходим данные

Когда нужно что-то сделать со **всеми** строками — обходим **данные** `Объект.Товары`, а не элемент:

```1C
&НаКлиенте
Процедура ПоказатьКоличествоСтрок(Команда)

	ОбщееКоличество = 0;
	Для Каждого СтрокаТовара Из Объект.Товары Цикл
		ОбщееКоличество = ОбщееКоличество + СтрокаТовара.Количество;
	КонецЦикла;

	Сообщить(СтрШаблон("Строк: %1; общее количество: %2",
		Объект.Товары.Количество(), ОбщееКоличество));

КонецПроцедуры
```

| Код | Смысл |
| --- | --- |
| `Для Каждого СтрокаТовара Из Объект.Товары` | Перебираем все строки данных ([[02. Программирование/11. Блок цикла|11. Блок цикла]]) |
| `Объект.Товары.Количество()` | Число строк в таблице (метод коллекции) |
| `СтрокаТовара.Количество` | Количество товара в строке (реквизит) — не путать с методом выше |

Цикл по `Элементы.Товары` написать нельзя — это элемент интерфейса, а не коллекция. Сортировка таблицы на экране не влияет на порядок в данных и на расчёт.

## Добавить строку программно

```1C
&НаКлиенте
Процедура ДобавитьСтрокуУчебно(Команда)

	НоваяСтрока = Объект.Товары.Добавить();
	НоваяСтрока.Количество = 1;

	Элементы.Товары.ТекущаяСтрока = НоваяСтрока.ПолучитьИдентификатор();
	Модифицированность = Истина;

КонецПроцедуры
```

| Строка | Что делает |
| --- | --- |
| `Объект.Товары.Добавить()` | Добавляет строку в **данные** — она сразу появится в таблице на экране |
| `НоваяСтрока.Количество = 1` | Заполняет поле новой строки |
| `Элементы.Товары.ТекущаяСтрока = …ПолучитьИдентификатор()` | Ставит курсор на новую строку. Принимает **идентификатор** строки, а не номер: `0` не означает «первая строка» |
| `Модифицированность = Истина` | Отмечает форму как изменённую: при закрытии платформа спросит о сохранении. Это не запись |

## Удалить текущую строку

```1C
&НаКлиенте
Процедура УдалитьСтрокуУчебно(Команда)

	СтрокаТовара = Элементы.Товары.ТекущиеДанные;
	Если СтрокаТовара = Неопределено Тогда
		Возврат;
	КонецЕсли;

	Объект.Товары.Удалить(СтрокаТовара);
	Модифицированность = Истина;
	// После программного удаления зависимые расчёты вызываем явно (тема 10)

КонецПроцедуры
```

Удаляем из **данных** (`Объект.Товары.Удалить`), передавая саму строку. Стандартная кнопка удаления в таблице умеет больше (например, удалить несколько выделенных строк) — своя кнопка нужна не всегда.

## Текущая строка — только на клиенте

На сервере нет понятия «где стоит курсор»: курсор — это состояние экрана пользователя. Если серверу нужен выбранный товар, получаем строку на клиенте и передаём **значение** параметром: `ОбработатьНаСервере(СтрокаТовара.Товар)`. См. [пояснение 1С о реквизитах и элементах](https://kb.1ci.com/1C_Enterprise_Platform/FAQ/Development/Controls/Attributes_and_items_of_the_form__referring_to_them_from_the_module_of_the_form/?language=en).

## Проверка

1. Пустая таблица → «Показать строку» → сообщение «Выберите строку», а не ошибка.
2. Две строки → команда показывает именно выделенную.
3. Общее количество учитывает обе строки.
4. «Добавить строку» → новая строка с количеством 1, курсор на ней.
5. Удаление текущей строки сохраняет остальные.
6. Закройте без записи — в базе ничего не изменилось.

> [!question]- Проверь себя
> 1. Как обойти все строки товаров на клиенте?
> 2. Почему `Элементы.Товары.ТекущаяСтрока = 0` — ошибка в логике?
> 3. Записывает ли `Модифицированность = Истина` документ?
>
> > [!success]- Ответы
> > 1. `Для Каждого Строка Из Объект.Товары Цикл`.
> > 2. Свойство ожидает идентификатор строки, а не её номер.
> > 3. Нет, только помечает форму изменённой.
