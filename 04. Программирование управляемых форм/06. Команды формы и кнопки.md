> [!abstract] Коротко
> **Команда** описывает действие, **кнопка** даёт пользователю его вызвать, **обработчик** выполняет код. Связка: кнопка (`ИмяКоманды`) → команда (`Действие`) → процедура. Создаём команду на вкладке «Команды», обработчик — кнопкой у свойства «Действие», кнопку — перетаскиванием команды в дерево элементов.

## Кнопка, команда, обработчик — три разных объекта

Новички ожидают: «нарисовал кнопку — написал код кнопки». В управляемой форме всё устроено чуть сложнее — и удобнее. Есть **три** связанных объекта:

| Объект | Что это | Аналогия |
| --- | --- | --- |
| **Команда** | Описание действия: имя, заголовок, картинка, какая процедура выполняется | **Выключатель света** как функция «включить свет» |
| **Кнопка** | Элемент на форме, который вызывает команду | **Клавиша** выключателя на стене |
| **Обработчик** | Процедура в модуле формы — сам код действия | **Провода и лампа**, которые реально зажигают свет |

```text
Кнопка ──ИмяКоманды──▶ Команда ПоказатьИтогТоваров ──Действие──▶ Процедура-обработчик
```

Зачем такое разделение? Одну команду можно вызвать **несколькими** кнопками: в командной панели формы, в меню «Ещё», в контекстном меню таблицы. Логика пишется один раз — в обработчике команды.

**Стандартные** команды (Записать, Провести, Закрыть) платформа даёт сама. В этом уроке создаём **собственную команду формы** «Показать итог товаров».

## Шаг 1. Создаём команду

1. В редакторе формы справа открываем вкладку **Команды** → кнопка **Добавить**.
2. В свойствах новой команды:
   - **Имя** — `ПоказатьИтогТоваров` (для кода, без пробелов);
   - **Заголовок** — «Показать итог товаров» (увидит пользователь на кнопке).
3. Находим свойство **Действие** и нажимаем кнопку с лупой рядом с ним.
4. Платформа спросит, где создать обработчик — выбираем **«Создать на клиенте»**.

![[УФ-06-Команды-формы.png]]

*Вкладка «Команды» формы: собственные команды и свойство «Действие».*

Конфигуратор сам перейдёт на вкладку **Модуль** и вставит заготовку:

```1C
&НаКлиенте
Процедура ПоказатьИтогТоваров(Команда)
	// Вставить содержимое обработчика.
КонецПроцедуры
```

А в свойстве **Действие** команды появится имя этой процедуры — так команда «знает», какой код запускать.

> [!warning] Если команда уже есть
> Открываем её свойство «Действие» и переходим к существующей процедуре. Не создаём вторую процедуру с тем же именем. Если меняете имя обработчика, меняйте его и в модуле, и в свойстве «Действие» — иначе связь порвётся.

## Шаг 2. Пишем код обработчика

Заменяем комментарий в заготовке на код:

```1C
&НаКлиенте
Процедура ПоказатьИтогТоваров(Команда)

	ИтогТоваров = Объект.Товары.Итог("Сумма");
	Сообщить("Итого товаров: " + Формат(ИтогТоваров, "ЧДЦ=2"));

КонецПроцедуры
```

| Строка | Что делает |
| --- | --- |
| `&НаКлиенте` | Процедура выполняется на клиенте — по нажатию кнопки |
| `(Команда)` | Параметр, который передаёт платформа: какая команда вызвана. Здесь не используется, но удалять его нельзя |
| `ИтогТоваров = …` | Считает сумму колонки «Сумма» и кладёт в реквизит формы — поле на экране обновится само |
| `Сообщить(…)` | Выводит итог в окно сообщений, чтобы увидеть результат |

Серверный вызов здесь не нужен: суммы строк уже есть в данных формы на клиенте. Команда **не** записывает документ и не трогает `ИтоговаяСумма` и услуги.

## Шаг 3. Размещаем кнопку

Команда есть, обработчик есть — но кнопки на форме пока нет. Пользователь не сможет нажать то, чего не видит.

1. Перетаскиваем команду `ПоказатьИтогТоваров` мышью из вкладки **Команды** в дерево элементов слева: например, в **командную панель формы** (верхняя полоса кнопок) или на страницу «Товары» рядом с итогом.
2. Платформа создаст элемент-кнопку. Проверяем у неё свойство **ИмяКоманды** = `ПоказатьИтогТоваров`.

Другой способ: в дереве элементов **ПКМ → Добавить → Кнопка**, затем в свойстве **ИмяКоманды** выбрать команду.

Не кладём кнопку внутрь таблицы между колонками. Если кнопка оказалась в меню «Ещё», а не на панели, проверьте, в какую группу её положили.

## Проверка

`Ctrl+S` → `F7` → откройте накладную с двумя строками:

| Количество | Цена | Сумма |
| ---: | ---: | ---: |
| 2 | 150 | 300 |
| 3 | 100 | 300 |

Нажмите кнопку «Показать итог товаров» — в поле «Итого товаров» и в сообщении **600**. Для пустой таблицы — **0**. Услуги не прибавляются.

| Симптом | Что проверить |
| --- | --- |
| Кнопки нет | Кнопка не размещена в дереве элементов; открыта другая форма; не обновлена БД |
| Кнопка есть, реакции нет | Пустое свойство **Действие** у команды |
| Ошибка про `ИтогТоваров` | Реквизит формы, его имя и путь; никакого `Объект.ИтогТоваров` |
| Сумма не та | Значения `Сумма` в строках — команда складывает готовые суммы, а не считает `Количество × Цена` |

**Самостоятельно:** создайте команду «Показать покупателя», которая вызывает серверную функцию `ПредставлениеПокупателя` из [[05. Модуль формы и клиент-сервер]] и выводит наименование сообщением.

> [!question]- Проверь себя
> 1. Написали процедуру `ПоказатьИтогТоваров` в модуле, но кнопки нет. Почему?
> 2. Чем команда отличается от кнопки?
>
> > [!success]- Ответы
> > 1. Нужна команда с этим действием и кнопка в дереве элементов.
> > 2. Команда — описание действия; кнопка — элемент интерфейса, вызывающий команду. Одну команду можно разместить несколькими кнопками и в меню.
