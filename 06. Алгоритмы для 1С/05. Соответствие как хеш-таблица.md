> [!abstract] Коротко
> `Соответствие` в 1С — это **хеш-таблица**: хранит пары «ключ → значение» и находит значение по ключу за `O(1)` в среднем, не перебирая все элементы. Это главный инструмент ускорения: «поиск в цикле» за `O(n)` превращается в мгновенную проверку, и решение `O(n²)` становится `O(n)`. Типовые применения: **подсчёт частот**, **множество** уже встреченных значений, **индекс** «значение → позиция» (задача о двух слагаемых), **группировка** (анаграммы).

## Что такое хеш-таблица простыми словами

Представьте гардероб. Вы сдаёте пальто и получаете номерок. Когда возвращаетесь, гардеробщик не перебирает все пальто подряд — он идёт сразу к крючку с вашим номером. Номерок — **ключ**, пальто — **значение**.

Хеш-таблица работает так же: по ключу она сразу вычисляет «номер крючка», где лежит значение. Поэтому поиск не зависит от того, сколько всего элементов хранится: и при 10, и при миллионе — примерно одинаково быстро.

| Действие | В массиве | В соответствии |
| --- | --- | --- |
| Есть ли значение X? | `Массив.Найти(X)` — перебор, `O(n)` | `Соотв.Получить(X) <> Неопределено` — `O(1)` |
| Добавить | `O(1)` | `O(1)` |
| Порядок элементов | Сохраняется | Не гарантируется при обходе |

## Основные операции

Подробно соответствие разобрано в [[02. Программирование/19. Структуры и соответствия|19. Структуры и соответствия]].

```1C
Цены = Новый Соответствие;

Цены.Вставить("Чайник", 1500);        // добавить или заменить значение по ключу
Цены.Вставить("Кружка", 200);

Цена = Цены.Получить("Чайник");       // 1500
Цена = Цены.Получить("Тостер");       // Неопределено — такого ключа нет

Если Цены.Получить("Кружка") <> Неопределено Тогда
	Сообщить("Кружка есть");
КонецЕсли;

Цены.Удалить("Кружка");               // удалить пару по ключу
Сообщить(Цены.Количество());          // 1

Для Каждого Пара Из Цены Цикл         // обход всех пар
	Сообщить(Пара.Ключ + " → " + XMLСтрока(Пара.Значение));
КонецЦикла;
```

Ключом может быть строка, число, дата, ссылка — любое значение, которое можно сравнить.

> [!warning] Ловушка: значение, равное `Неопределено`
> `Получить()` возвращает `Неопределено` и когда ключа нет, и когда по ключу записано `Неопределено`. В задачах храним осмысленные значения (числа, `Истина`), чтобы не путать эти случаи.

## Шаблон 1. Подсчёт частот

**Задача:** сколько раз встречается каждое значение. `["яблоко", "груша", "яблоко"]` → яблоко: 2, груша: 1.

```1C
&НаКлиенте
Функция ПосчитатьЧастоты(Значения)
	Частоты = Новый Соответствие;
	Для Каждого Элемент Из Значения Цикл
		Было = Частоты.Получить(Элемент);
		Если Было = Неопределено Тогда
			Частоты.Вставить(Элемент, 1);       // встретили впервые
		Иначе
			Частоты.Вставить(Элемент, Было + 1);
		КонецЕсли;
	КонецЦикла;
	Возврат Частоты;
КонецФункции
```

Время `O(n)`. Этот шаблон встречается настолько часто, что его стоит знать наизусть.

**Применение — первый неповторяющийся символ** (задача из прошлого урока): `"абракадабра"` → `"к"`.

```1C
&НаКлиенте
Функция ПервыйУникальныйСимвол(Текст)
	// Проход 1: считаем, сколько раз встречается каждый символ
	Частоты = Новый Соответствие;
	Для Позиция = 1 По СтрДлина(Текст) Цикл
		Символ = Сред(Текст, Позиция, 1);
		Было = Частоты.Получить(Символ);
		Частоты.Вставить(Символ, ?(Было = Неопределено, 1, Было + 1));
	КонецЦикла;

	// Проход 2: идём по строке и ищем первый символ с частотой 1
	Для Позиция = 1 По СтрДлина(Текст) Цикл
		Символ = Сред(Текст, Позиция, 1);
		Если Частоты.Получить(Символ) = 1 Тогда
			Возврат Символ;
		КонецЕсли;
	КонецЦикла;
	Возврат "";
КонецФункции
```

Второй проход идёт **по строке**, а не по соответствию: так мы найдём именно **первый** по порядку символ — порядок обхода соответствия не гарантирован. Два прохода по `n` — всё равно `O(n)`.

## Шаблон 2. Множество: «видели ли мы это раньше?»

Отдельного типа «множество» во встроенном языке нет — используем соответствие со значением `Истина`.

**Задача:** есть ли в массиве повторяющиеся элементы? `[1, 2, 3, 1]` → `Истина`.

Простое решение — два вложенных цикла, `O(n²)` ([[02. Сложность алгоритмов]]). С множеством — один проход:

```1C
&НаКлиенте
Функция ЕстьДубликаты(Числа)
	Встречались = Новый Соответствие;
	Для Каждого Элемент Из Числа Цикл
		Если Встречались.Получить(Элемент) <> Неопределено Тогда
			Возврат Истина;                    // уже видели — дубликат
		КонецЕсли;
		Встречались.Вставить(Элемент, Истина); // запоминаем
	КонецЦикла;
	Возврат Ложь;
КонецФункции
```

| Шаг | Элемент | Встречались до шага | Результат |
| --- | --- | --- | --- |
| 1 | 1 | {} | запомнили 1 |
| 2 | 2 | {1} | запомнили 2 |
| 3 | 3 | {1, 2} | запомнили 3 |
| 4 | 1 | {1, 2, 3} | **1 уже есть → Истина** |

Время `O(n)`, память `O(n)` — классический обмен памяти на скорость.

## Шаблон 3. Индекс «значение → позиция»: задача о двух слагаемых

Это, пожалуй, самая известная задача собеседований.

**Условие.** Дан массив чисел и число `Цель`. Найти индексы двух **разных** элементов, сумма которых равна `Цель`. Гарантируется, что ответ ровно один.

`Числа = [2, 7, 11, 15]`, `Цель = 9` → индексы `0, 1` (2 + 7 = 9).

**Простое решение** — перебрать все пары: `O(n²)`.

```1C
Для i = 0 По Числа.ВГраница() Цикл
	Для j = i + 1 По Числа.ВГраница() Цикл
		Если Числа[i] + Числа[j] = Цель Тогда
			// ответ i, j
```

**Быстрое решение.** Для каждого числа `Х` нам нужна «пара» — `Цель − Х`. Вопрос «встречалась ли уже пара?» — это поиск в соответствии за `O(1)`. Храним «значение → его индекс»:

```1C
&НаКлиенте
Функция ДваСлагаемых(Числа, Цель)
	ИндексПоЗначению = Новый Соответствие;
	Для i = 0 По Числа.ВГраница() Цикл
		Пара = Цель - Числа[i];
		ИндексПары = ИндексПоЗначению.Получить(Пара);
		Если ИндексПары <> Неопределено Тогда
			Ответ = Новый Массив;
			Ответ.Добавить(ИндексПары);
			Ответ.Добавить(i);
			Возврат Ответ;
		КонецЕсли;
		ИндексПоЗначению.Вставить(Числа[i], i);   // запоминаем ПОСЛЕ проверки
	КонецЦикла;
	Возврат Неопределено;   // ответа нет
КонецФункции
```

Прогон: `[2, 7, 11, 15]`, `Цель = 9`:

| i | Числа[i] | Ищем пару | В соответствии | Действие |
| --- | --- | --- | --- | --- |
| 0 | 2 | 7 | {} | нет; запоминаем 2 → 0 |
| 1 | 7 | 2 | {2→0} | **нашли 2 на индексе 0** → ответ `[0, 1]` |

Почему запоминаем **после** проверки? Иначе при `Числа = [3, 5]`, `Цель = 6` число 3 найдёт «пару» само в себе. А по условию нужны два **разных** элемента.

Время `O(n)`, память `O(n)`.

```1C
Проверить("Два слагаемых", МассивВСтроку(ДваСлагаемых(ЧислаИзСтроки("2,7,11,15"), 9)), "0,1");
Проверить("Одинаковые числа", МассивВСтроку(ДваСлагаемых(ЧислаИзСтроки("3,2,4,3"), 6)), "1,2");
```

## Шаблон 4. Группировка: анаграммы

**Анаграммы** — слова из одних и тех же букв: «кот» и «ток», «пила» и «липа».

**Задача 1:** являются ли две строки анаграммами? Посчитаем частоты букв в первой строке, вычтем частоты второй — в итоге все счётчики должны стать нулями.

```1C
&НаКлиенте
Функция ЭтоАнаграммы(Первая, Вторая)
	Если СтрДлина(Первая) <> СтрДлина(Вторая) Тогда
		Возврат Ложь;
	КонецЕсли;
	Счетчики = Новый Соответствие;
	Для Позиция = 1 По СтрДлина(Первая) Цикл
		Символ = Сред(Первая, Позиция, 1);
		Было = Счетчики.Получить(Символ);
		Счетчики.Вставить(Символ, ?(Было = Неопределено, 0, Было) + 1);
	КонецЦикла;
	Для Позиция = 1 По СтрДлина(Вторая) Цикл
		Символ = Сред(Вторая, Позиция, 1);
		Было = Счетчики.Получить(Символ);
		Если Было = Неопределено Или Было = 0 Тогда
			Возврат Ложь;   // во второй строке лишний символ
		КонецЕсли;
		Счетчики.Вставить(Символ, Было - 1);
	КонецЦикла;
	Возврат Истина;
КонецФункции
```

Время `O(n)`. Альтернатива — отсортировать буквы обеих строк и сравнить: `O(n log n)`.

**Задача 2:** сгруппировать слова-анаграммы. `["кот", "ток", "пила", "липа", "сон"]` → `[кот, ток]`, `[пила, липа]`, `[сон]`.

Идея: у всех анаграмм одинаковый «ключ» — буквы, отсортированные по алфавиту («кот» и «ток» → «кот»). Группируем по ключу в соответствии «ключ → массив слов»:

```1C
&НаКлиенте
Функция СгруппироватьАнаграммы(Слова)
	Группы = Новый Соответствие;
	Для Каждого Слово Из Слова Цикл
		Ключ = ОтсортироватьБуквы(Слово);
		Группа = Группы.Получить(Ключ);
		Если Группа = Неопределено Тогда
			Группа = Новый Массив;
			Группы.Вставить(Ключ, Группа);
		КонецЕсли;
		Группа.Добавить(Слово);   // массив хранится по ссылке — меняем его прямо в соответствии
	КонецЦикла;
	Возврат Группы;
КонецФункции

&НаКлиенте
Функция ОтсортироватьБуквы(Слово)
	Список = Новый СписокЗначений;
	Для Позиция = 1 По СтрДлина(Слово) Цикл
		Список.Добавить(Сред(Слово, Позиция, 1));
	КонецЦикла;
	Список.СортироватьПоЗначению();
	Возврат СтрСоединить(Список.ВыгрузитьЗначения(), "");
КонецФункции
```

Сортировку букв делаем через `СписокЗначений.СортироватьПоЗначению()` — у массива в 1С нет метода сортировки (подробнее — [[09. Сортировки]]).

## Когда соответствие — правильный выбор

Ищите в условии задачи слова-подсказки:

| Подсказка в задаче | Приём |
| --- | --- |
| «сколько раз встречается», «самый частый» | Подсчёт частот |
| «есть ли повторы», «уникальные элементы» | Множество |
| «найти пару с суммой / разницей» | Индекс «значение → позиция» |
| «сгруппировать по признаку» | Соответствие «ключ → массив» |

> [!question]- Проверь себя
> 1. Почему поиск в соответствии быстрее, чем `Массив.Найти()`?
> 2. Как реализовать «множество» во встроенном языке?
> 3. В задаче о двух слагаемых — почему значение кладём в соответствие после проверки, а не до?
> 4. Почему при поиске первого уникального символа второй проход идёт по строке, а не по соответствию?
>
> > [!success]- Ответы
> > 1. Соответствие — хеш-таблица: по ключу сразу вычисляется место хранения, без перебора; `O(1)` в среднем против `O(n)`.
> > 2. Соответствие, где ключ — элемент, а значение — `Истина`.
> > 3. Чтобы элемент не нашёл «пару» сам в себе (когда `Цель = 2 × элемент`).
> > 4. Порядок обхода соответствия не гарантирован, а нужен первый символ в порядке строки.
