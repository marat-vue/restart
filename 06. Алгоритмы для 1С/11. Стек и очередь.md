> [!abstract] Коротко
> **Стек** — «последним пришёл, первым ушёл» (стопка тарелок): кладём и берём сверху. В 1С — массив: `Добавить()` в конец, читать и удалять `ВГраница()`. Задачи: правильные скобки, отмена действий, вычисление выражений, «ближайший больший элемент». **Очередь** — «первым пришёл, первым ушёл» (очередь в кассу): добавляем в конец, берём из начала. В 1С `Массив.Удалить(0)` стоит `O(n)`, поэтому для больших очередей храним индекс «головы». Очередь — основа обхода в ширину ([[13. Обход в глубину и ширину]]).

## Стек

**Стек** работает как стопка тарелок: новую кладём **сверху**, и брать можем только **сверху**. Последняя положенная тарелка будет взята первой — принцип **LIFO** (last in, first out).

```text
Положили 1, 2, 3:        Сняли верхнюю:
   ┌───┐                    ┌───┐
   │ 3 │ ← верх              │ 2 │ ← верх
   ├───┤                    ├───┤
   │ 2 │                    │ 1 │
   ├───┤                    └───┘
   │ 1 │                 сняли 3
   └───┘
```

Примеры из жизни программ: кнопка «Отменить» (отменяется последнее действие), кнопка «Назад» в браузере, вызовы процедур (последняя вызванная завершается первой — стек вызовов в отладчике 1С).

### Стек в 1С

Отдельного типа «стек» во встроенном языке нет. Используем массив, где **конец массива — верх стопки**: все операции с концом массива — `O(1)`.

| Операция стека | Код 1С | Сложность |
| --- | --- | --- |
| Положить (push) | `Стек.Добавить(Значение)` | `O(1)` |
| Посмотреть верх (peek) | `Стек[Стек.ВГраница()]` | `O(1)` |
| Снять (pop) | `Верх = Стек[Стек.ВГраница()]; Стек.Удалить(Стек.ВГраница());` | `O(1)` |
| Пуст ли | `Стек.Количество() = 0` | `O(1)` |

> [!warning] Пустой стек
> Перед чтением или снятием верхнего элемента всегда проверяйте, что стек не пуст: у пустого массива `ВГраница() = −1`, и обращение `Стек[-1]` — ошибка.

### Задача: правильная скобочная последовательность

Самая популярная задача на стек.

**Условие.** Строка состоит из скобок `()[]{}`. Проверить, правильно ли они расставлены: каждая открывающая закрыта скобкой того же типа и в правильном порядке.

| Строка | Ответ | Почему |
| --- | --- | --- |
| `()[]{}` | Да | |
| `{[()]}` | Да | Вложены правильно |
| `(]` | Нет | Тип не совпадает |
| `([)]` | Нет | Порядок нарушен: `[` закрыта после `)` |
| `((` | Нет | Остались незакрытые |
| `)(` | Нет | Закрывающая без открывающей |

**Идея.** Открывающие скобки кладём в стек. Встретив закрывающую — смотрим на **верх** стека: там должна лежать парная открывающая. Если да — снимаем её, если нет (или стек пуст) — ошибка. В конце стек должен быть пустым.

```text
Строка: { [ ( ) ] }
{  → стек: {
[  → стек: { [
(  → стек: { [ (
)  → верх "(" — пара ✓ → стек: { [
]  → верх "[" — пара ✓ → стек: {
}  → верх "{" — пара ✓ → стек: пуст
Конец, стек пуст → правильно
```

```1C
&НаКлиенте
Функция СкобкиПравильные(Текст)
	Пары = Новый Соответствие;    // закрывающая → открывающая
	Пары.Вставить(")", "(");
	Пары.Вставить("]", "[");
	Пары.Вставить("}", "{");

	Стек = Новый Массив;
	Для Позиция = 1 По СтрДлина(Текст) Цикл
		Символ = Сред(Текст, Позиция, 1);
		Открывающая = Пары.Получить(Символ);

		Если Открывающая = Неопределено Тогда
			Стек.Добавить(Символ);                       // открывающая — в стек
		Иначе
			Если Стек.Количество() = 0 Тогда
				Возврат Ложь;                            // закрывать нечего
			КонецЕсли;
			Если Стек[Стек.ВГраница()] <> Открывающая Тогда
				Возврат Ложь;                            // не тот тип
			КонецЕсли;
			Стек.Удалить(Стек.ВГраница());               // пара найдена — снимаем
		КонецЕсли;
	КонецЦикла;

	Возврат Стек.Количество() = 0;                       // незакрытых не осталось
КонецФункции
```

Время `O(n)`, память `O(n)`.

```1C
Проверить("{[()]}", СкобкиПравильные("{[()]}"), Истина);
Проверить("([)]", СкобкиПравильные("([)]"), Ложь);
Проверить("((", СкобкиПравильные("(("), Ложь);
Проверить(")(", СкобкиПравильные(")("), Ложь);
Проверить("Пустая", СкобкиПравильные(""), Истина);
```

> [!tip] Если скобки одного типа
> Для строки только из `(` и `)` стек не нужен: хватит счётчика. `(` — плюс один, `)` — минус один. Если счётчик стал отрицательным — ошибка; в конце он должен быть равен нулю.

### Задача: ближайший больший справа (монотонный стек)

**Условие.** Для каждого дня известна температура. Для каждого дня найти, через сколько дней станет теплее. Если не станет — 0. `[73, 74, 75, 71, 69, 72, 76, 73]` → `[1, 1, 4, 2, 1, 1, 0, 0]`.

Простое решение — для каждого дня искать вперёд: `O(n²)`.

**Идея монотонного стека.** Храним в стеке **индексы дней**, для которых ещё не нашли ответ. Температуры этих дней в стеке идут по убыванию. Когда приходит новый день, он «закрывает» все дни на верху стека, которые холоднее его.

```1C
&НаКлиенте
Функция ДнейДоПотепления(Температуры)
	Ответ = Новый Массив(Температуры.Количество());
	Для i = 0 По Ответ.ВГраница() Цикл
		Ответ[i] = 0;
	КонецЦикла;

	Стек = Новый Массив;   // индексы дней, ожидающих потепления
	Для i = 0 По Температуры.ВГраница() Цикл
		Пока Стек.Количество() > 0 И Температуры[Стек[Стек.ВГраница()]] < Температуры[i] Цикл
			День = Стек[Стек.ВГраница()];
			Стек.Удалить(Стек.ВГраница());
			Ответ[День] = i - День;      // для дня «День» нашли более тёплый — день i
		КонецЦикла;
		Стек.Добавить(i);
	КонецЦикла;
	Возврат Ответ;
КонецФункции
```

Каждый индекс один раз кладётся в стек и не больше одного раза снимается — время `O(n)`, как и в скользящем окне.

## Очередь

**Очередь** работает как очередь в кассу: новые встают в **конец**, обслуживают из **начала**. Принцип **FIFO** (first in, first out).

```text
Встали: A, B, C          Обслужили первого:
начало → [A][B][C] ← конец     начало → [B][C] ← конец
```

Примеры: очередь заданий на печать, обработка сообщений по порядку поступления, обход в ширину.

### Очередь в 1С

Простейший вариант — массив: `Добавить()` в конец, читать `[0]` и `Удалить(0)`. Это работает, но `Удалить(0)` сдвигает все остальные элементы — `O(n)` на каждое извлечение.

Для больших очередей храним **индекс головы**: элементы не удаляем, а просто сдвигаем указатель на начало.

```1C
Очередь = Новый Массив;
Голова = 0;                            // индекс первого необслуженного

Очередь.Добавить("A");                 // встать в очередь
Очередь.Добавить("B");

Пока Голова <= Очередь.ВГраница() Цикл // пока в очереди кто-то есть
	Первый = Очередь[Голова];          // взять первого
	Голова = Голова + 1;               // «удалить» его — O(1)
	Сообщить(Первый);
КонецЦикла;
```

| Операция | Массив + `Удалить(0)` | Массив + индекс головы |
| --- | --- | --- |
| Добавить в конец | `O(1)` | `O(1)` |
| Взять из начала | `O(n)` | `O(1)` |
| Память | Освобождается | Обработанные элементы остаются в массиве |

Для задач собеседования вариант с индексом головы — правильный. Он понадобится в обходе в ширину ([[13. Обход в глубину и ширину]]).

## Стек или очередь?

| Нужно обработать | Структура |
| --- | --- |
| Сначала самое последнее (вложенность, отмена, скобки) | Стек |
| В порядке поступления (по уровням, по времени) | Очередь |

> [!question]- Проверь себя
> 1. Что значит LIFO и FIFO? Приведите пример из жизни для каждого.
> 2. Почему конец массива — удобный «верх» стека в 1С?
> 3. Опишите алгоритм проверки скобок. Какие три ситуации означают ошибку?
> 4. Почему `Массив.Удалить(0)` плохо подходит для большой очереди и как это обойти?
>
> > [!success]- Ответы
> > 1. LIFO — последним пришёл, первым ушёл (стопка тарелок); FIFO — первым пришёл, первым ушёл (очередь в кассу).
> > 2. Добавление в конец и удаление последнего элемента — `O(1)`, ничего не сдвигается.
> > 3. Открывающие кладём в стек, на закрывающую проверяем верх стека. Ошибки: закрывающая при пустом стеке; верх не совпадает по типу; после прохода стек не пуст.
> > 4. Каждое удаление сдвигает все элементы — `O(n)`. Храним индекс головы и сдвигаем его вместо удаления.
