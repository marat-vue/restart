## Как выбрать приём по условию

| В условии задачи | Попробуйте |
| --- | --- |
| «Найти пару / проверить, встречалось ли» | Соответствие (множество, индекс) — [[05. Соответствие как хеш-таблица]] |
| «Сколько раз встречается», «самый частый», «анаграммы» | Подсчёт частот в соответствии |
| Массив **отсортирован**, нужна пара с условием | Два указателя навстречу — [[06. Два указателя]] |
| «На месте», «без доп. памяти», «удалить / отфильтровать» | Читатель и писатель |
| «Подряд идущие», «подстрока», «подмассив длины k» | Скользящее окно — [[07. Скользящее окно]] |
| «Сумма на отрезке», много запросов; «подмассивы с суммой K» | Префиксные суммы (+ соответствие) — [[08. Префиксные суммы]] |
| Отсортировано, «найти позицию / первый, который…» | Бинарный поиск — [[10. Бинарный поиск]] |
| Скобки, вложенность, «отменить последнее» | Стек — [[11. Стек и очередь]] |
| «Ближайший больший / меньший» | Монотонный стек |
| Дерево, иерархия, «все варианты» | Рекурсия, перебор с возвратом — [[12. Рекурсия]] |
| Граф, сетка, «связанные области» | Обход в глубину — [[13. Обход в глубину и ширину]] |
| «Минимальное число шагов» | Обход в ширину |
| «Сколько способов», «максимум / минимум с выбором на каждом шаге» | Динамическое программирование — [[14. Динамическое программирование]] |
| Интервалы, расписание, встречи | Сортировка + жадный проход — [[15. Жадные алгоритмы и интервалы]] |
| Решение `O(n²)`, а нужно быстрее | Отсортировать? Соответствие? Два указателя? |

## Сложности, которые нужно знать наизусть

| Операция | Сложность |
| --- | --- |
| `Массив[i]`, `Добавить()` в конец, `ВГраница()` | `O(1)` |
| `Массив.Найти()`, `Вставить(0, …)`, `Удалить(0)` | `O(n)` |
| `Соответствие.Получить()`, `Вставить()`, `Удалить()` | `O(1)` в среднем |
| Один проход по массиву | `O(n)` |
| Два вложенных цикла по массиву | `O(n²)` |
| Хорошая сортировка, `СортироватьПоЗначению()` | `O(n log n)` |
| Бинарный поиск | `O(log n)` |
| Обход графа | `O(V + E)` |
| Все подмножества | `O(2ⁿ)` |

## Шаблоны кода

**Подсчёт частот:**

```1C
Частоты = Новый Соответствие;
Для Каждого Элемент Из Значения Цикл
	Было = Частоты.Получить(Элемент);
	Частоты.Вставить(Элемент, ?(Было = Неопределено, 0, Было) + 1);
КонецЦикла;
```

**Множество:**

```1C
Видели = Новый Соответствие;
Если Видели.Получить(Х) <> Неопределено Тогда … КонецЕсли;
Видели.Вставить(Х, Истина);
```

**Два указателя навстречу:**

```1C
Левый = 0;
Правый = Числа.ВГраница();
Пока Левый < Правый Цикл
	// сравнить Числа[Левый] и Числа[Правый], сдвинуть один или оба
КонецЦикла;
```

**Скользящее окно переменной длины:**

```1C
Левый = 0;
Для Правый = 0 По Числа.ВГраница() Цикл
	// добавить Числа[Правый] в состояние окна
	Пока <окно нарушает условие> Цикл
		// убрать Числа[Левый] из состояния
		Левый = Левый + 1;
	КонецЦикла;
	// обновить ответ по окну [Левый, Правый]
КонецЦикла;
```

**Бинарный поиск:**

```1C
Левый = 0;
Правый = Числа.ВГраница();
Пока Левый <= Правый Цикл
	Середина = Цел((Левый + Правый) / 2);
	Если Числа[Середина] = X Тогда Возврат Середина;
	ИначеЕсли Числа[Середина] < X Тогда Левый = Середина + 1;
	Иначе Правый = Середина - 1;
	КонецЕсли;
КонецЦикла;
Возврат -1;
```

**Стек и очередь:**

```1C
Стек.Добавить(Х);                         // положить
Верх = Стек[Стек.ВГраница()];             // посмотреть
Стек.Удалить(Стек.ВГраница());            // снять

Очередь.Добавить(Х);                      // встать в очередь
Первый = Очередь[Голова];                 // взять первого
Голова = Голова + 1;
```

**Обход в ширину:**

```1C
Расстояние.Вставить(Старт, 0);
Очередь.Добавить(Старт);
Пока Голова <= Очередь.ВГраница() Цикл
	Вершина = Очередь[Голова];
	Голова = Голова + 1;
	Для Каждого Сосед Из Соседи(Вершина) Цикл
		Если Расстояние.Получить(Сосед) = Неопределено Тогда
			Расстояние.Вставить(Сосед, Расстояние.Получить(Вершина) + 1);
			Очередь.Добавить(Сосед);
		КонецЕсли;
	КонецЦикла;
КонецЦикла;
```

**Динамическое программирование — четыре вопроса:** что значит `ДП[i]` → как выразить через предыдущие → база → где ответ.

## Особенности встроенного языка 1С в задачах

| Особенность | Как учитывать |
| --- | --- |
| Индексы массива с 0, позиции в строке с 1 | `Числа[0]`, но `Сред(Текст, 1, 1)` |
| Нет целочисленного деления | `Цел(a / b)` |
| Остаток от отрицательного: `-5 % 2 = -1` | Чётность проверять `% 2 = 0` |
| Нет сортировки у массива | `СписокЗначений.СортироватьПоЗначению()` или своя сортировка |
| Нет типа «множество» | Соответствие со значением `Истина` |
| Нет записи массива «в одну строку» | Вспомогательная функция `ЧислаИзСтроки("3,1,2")` |
| Массивы сравниваются по ссылке | Сравнивать через `МассивВСтроку` |
| `Строка(1000)` = «1 000» | Для вывода чисел — `XMLСтрока` |
| Цикл `Для` только вверх | Обратный проход — через `Пока` |
| Числа не переполняются | Не нужно бояться больших сумм и произведений |
| `ТаблицаЗначений` недоступна на клиенте | В задачах — массивы, соответствия, структуры |

## Частые ошибки

| Ошибка | Как избежать |
| --- | --- |
| `По Числа.Количество()` вместо `ВГраница()` | Последний индекс — `ВГраница()` |
| Обращение к элементу пустого массива | Проверять `Количество() = 0` в начале |
| Забыли последнюю серию / хвост после цикла | Проверять случай «данные кончились» |
| Удаление элементов в цикле по возрастающему индексу | Новый массив или проход с конца |
| `Пока Левый < Правый` в бинарном поиске | `<=` в классическом варианте |
| Нет базового случая в рекурсии | Сначала пишем базовый случай |
| Не отмечены посещённые вершины | Множество посещённых, отмечать **до** рекурсии / при добавлении в очередь |
| Жадное решение без обоснования | Проверить на контрпримере |
| Решение верное, но сложность не названа | Всегда говорить сложность по времени и памяти |

## Как вести себя на собеседовании

1. **Думайте вслух.** Интервьюеру важен ход рассуждений не меньше, чем ответ.
2. **Уточняйте условие** перед тем, как писать код.
3. **Начните с простого решения**, назовите его сложность — потом улучшайте.
4. **Проверьте код** на примере и крайних случаях сами, до того как скажете «готово».
5. **Не молчите, если застряли** — расскажите, что пробуете. Подсказка интервьюера — нормальная часть собеседования.

> [!question]- Проверь себя
> 1. Условие: «найти самый длинный подмассив, где сумма не больше S, все числа положительные». Какой приём?
> 2. Условие: «отсортированный массив, найти, сколько раз встречается X, быстрее чем за O(n)». Какой приём?
> 3. Условие: «минимальное число ходов коня из клетки A в клетку B». Какой приём?
> 4. Условие: «сколькими способами можно разменять сумму монетами». Какой приём?
>
> > [!success]- Ответы
> > 1. Скользящее окно переменной длины.
> > 2. Бинарный поиск: две нижние границы — для X и для X + 1, разность — количество.
> > 3. Обход в ширину: «минимальное число шагов».
> > 4. Динамическое программирование: «сколько способов».
