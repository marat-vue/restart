> [!abstract] Коротко
> Массив в 1С — пронумерованный список с индексами от `0` до `ВГраница()` (`= Количество() − 1`). Обращение по индексу — `O(1)`, вставка и удаление в начале — `O(n)`. Базовые приёмы: проход с накоплением (сумма, минимум, счётчик), проход по индексам, обмен двух элементов через временную переменную, разворот, создание нового массива-результата. Почти каждая задача на массив начинается с вопроса: «Можно ли решить за один проход?».

## Вспомним массив

Подробно массив разобран в [[02. Программирование/18. Массивы|18. Массивы]]. Для алгоритмов важно держать в голове картинку:

```text
Индекс:    0    1    2    3    4
Значение: [3]  [8]  [1]  [9]  [4]
           ▲                   ▲
       Числа[0]         Числа[4] = Числа[Числа.ВГраница()]
```

| Операция | Код | Сложность |
| --- | --- | --- |
| Создать пустой | `Числа = Новый Массив;` | `O(1)` |
| Создать из `n` пустых ячеек | `Числа = Новый Массив(5);` — пять ячеек со значением `Неопределено` | `O(n)` |
| Количество | `Числа.Количество()` | `O(1)` |
| Последний индекс | `Числа.ВГраница()` — для пустого массива `-1` | `O(1)` |
| Прочитать / записать по индексу | `Х = Числа[2]; Числа[2] = 7;` | `O(1)` |
| Добавить в конец | `Числа.Добавить(5)` | `O(1)` |
| Вставить по индексу | `Числа.Вставить(0, 5)` | `O(n)` — сдвигает элементы |
| Удалить по индексу | `Числа.Удалить(0)` | `O(n)` — сдвигает элементы |
| Найти значение | `Числа.Найти(5)` — индекс или `Неопределено` | `O(n)` |

> [!warning] Выход за границы
> Обращение `Числа[5]` к массиву из 5 элементов (индексы 0–4) — ошибка «Индекс находится за границами массива». Самая частая ошибка в задачах — `По Числа.Количество()` вместо `По Числа.ВГраница()` в цикле.

> [!info] Имена `i` и `j`
> В алгоритмических задачах для индексов принято использовать короткие имена `i`, `j`, `k`, как в математике. Встроенный язык это допускает. Для остальных переменных — понятные русские имена.

## Два способа обойти массив

**По элементам** — когда индекс не нужен:

```1C
Для Каждого Элемент Из Числа Цикл
	Сообщить(Элемент);
КонецЦикла;
```

**По индексам** — когда нужен номер позиции, соседний элемент или обход части массива:

```1C
Для i = 0 По Числа.ВГраница() Цикл
	Сообщить(XMLСтрока(i) + ": " + XMLСтрока(Числа[i]));
КонецЦикла;
```

**С конца** — цикл `Для` в 1С идёт только вверх, поэтому используем `Пока`:

```1C
i = Числа.ВГраница();
Пока i >= 0 Цикл
	Сообщить(Числа[i]);
	i = i - 1;
КонецЦикла;
```

## Приём 1. Накопление за один проход

Множество задач решаются так: заводим переменную-«копилку» и обновляем её на каждом шаге.

| Задача | Начальное значение | Шаг |
| --- | --- | --- |
| Сумма | `Сумма = 0` | `Сумма = Сумма + Элемент` |
| Количество положительных | `Счетчик = 0` | `Если Элемент > 0 Тогда Счетчик = Счетчик + 1` |
| Максимум | `Макс = Числа[0]` | `Если Элемент > Макс Тогда Макс = Элемент` |
| Индекс минимума | `ИндексМин = 0` | `Если Числа[i] < Числа[ИндексМин] Тогда ИндексМин = i` |

**Задача: второй по величине элемент.** Дан массив различных чисел, вернуть второй максимум. `[3, 8, 1, 9, 4]` → `8`.

Простое решение — отсортировать и взять предпоследний: `O(n log n)`. Но можно за **один проход** `O(n)`, храня **два** максимума:

```1C
&НаКлиенте
Функция ВторойМаксимум(Числа)

	Первый = Неопределено;   // самый большой
	Второй = Неопределено;   // второй по величине

	Для Каждого Элемент Из Числа Цикл
		Если Первый = Неопределено Или Элемент > Первый Тогда
			Второй = Первый;      // старый лидер становится вторым
			Первый = Элемент;
		ИначеЕсли Второй = Неопределено Или Элемент > Второй Тогда
			Второй = Элемент;
		КонецЕсли;
	КонецЦикла;

	Возврат Второй;

КонецФункции
```

Прогон по `[3, 8, 1, 9, 4]`:

| Элемент | Первый | Второй | Что произошло |
| --- | --- | --- | --- |
| 3 | 3 | — | Первый элемент |
| 8 | 8 | 3 | Новый лидер, 3 сдвинулось во «вторые» |
| 1 | 8 | 3 | Меньше обоих |
| 9 | 9 | 8 | Новый лидер |
| 4 | 9 | 8 | Меньше второго |

Ответ: **8**. Если в массиве меньше двух элементов, функция вернёт `Неопределено` — это стоит проговорить на собеседовании.

```1C
Проверить("Второй максимум", ВторойМаксимум(ЧислаИзСтроки("3,8,1,9,4")), 8);
Проверить("Лидер в начале", ВторойМаксимум(ЧислаИзСтроки("9,1,2")), 2);
```

## Приём 2. Обмен двух элементов

Чтобы поменять местами два элемента, нужна **временная переменная** — как при обмене содержимым двух стаканов нужен третий, пустой:

```1C
Временная = Числа[i];
Числа[i] = Числа[j];
Числа[j] = Временная;
```

Без временной переменной значение `Числа[i]` потеряется после второй строки.

## Приём 3. Разворот массива на месте

**Задача:** развернуть массив без создания нового. `[1, 2, 3, 4, 5]` → `[5, 4, 3, 2, 1]`.

Идея: меняем местами первый и последний, второй и предпоследний — и так до середины.

```text
[1, 2, 3, 4, 5]
 ↑           ↑   обмен 1 ↔ 5
[5, 2, 3, 4, 1]
    ↑     ↑      обмен 2 ↔ 4
[5, 4, 3, 2, 1]
       ↑         указатели встретились — стоп
```

```1C
&НаКлиенте
Процедура РазвернутьМассив(Числа)

	Левый = 0;
	Правый = Числа.ВГраница();
	Пока Левый < Правый Цикл
		Временная = Числа[Левый];
		Числа[Левый] = Числа[Правый];
		Числа[Правый] = Временная;
		Левый = Левый + 1;
		Правый = Правый - 1;
	КонецЦикла;

КонецПроцедуры
```

Сложность: `O(n)` по времени — каждый элемент трогаем один раз, `O(1)` памяти — новых массивов не создаём. Это «процедура», а не «функция»: она **изменяет** переданный массив, потому что массив передаётся по ссылке ([[02. Программирование/09. Процедуры и функции|09. Процедуры и функции]]).

```1C
Числа = ЧислаИзСтроки("1,2,3,4,5");
РазвернутьМассив(Числа);
Проверить("Разворот", МассивВСтроку(Числа), "5,4,3,2,1");
```

Это уже знакомство с приёмом **двух указателей** — подробно в [[06. Два указателя]].

## Приём 4. Новый массив-результат

Если нужно отобрать или преобразовать элементы, проще всего собирать результат в **новый** массив, не трогая исходный.

**Задача:** оставить только положительные числа, сохранив порядок. `[3, -1, 0, 5, -2]` → `[3, 5]`.

```1C
&НаКлиенте
Функция ТолькоПоложительные(Числа)
	Результат = Новый Массив;
	Для Каждого Элемент Из Числа Цикл
		Если Элемент > 0 Тогда
			Результат.Добавить(Элемент);
		КонецЕсли;
	КонецЦикла;
	Возврат Результат;
КонецФункции
```

Время `O(n)`, дополнительная память `O(n)`.

> [!warning] Не удаляйте элементы в цикле по возрастающему индексу
> Если удалять элементы из массива прямо во время прохода `Для i = 0 По …`, после удаления все элементы сдвигаются влево, и следующий элемент будет пропущен — а цикл может выйти за границу. Либо собирайте новый массив, либо удаляйте, идя **с конца** ([[02. Программирование/11. Блок цикла|11. Блок цикла]]).

## Задача для закрепления: сдвиг нулей в конец

**Условие.** Переставить все нули в конец массива, сохранив порядок остальных элементов. Сделать на месте. `[0, 1, 0, 3, 12]` → `[1, 3, 12, 0, 0]`.

> [!example]- Подсказка
> Заведите «позицию записи» `Запись = 0`. Проходите по массиву; каждый ненулевой элемент записывайте в `Числа[Запись]` и увеличивайте `Запись`. После прохода все ненулевые стоят в начале — заполните оставшиеся позиции нулями.

> [!example]- Решение
> ```1C
> &НаКлиенте
> Процедура НулиВКонец(Числа)
> 	Запись = 0;
> 	Для i = 0 По Числа.ВГраница() Цикл
> 		Если Числа[i] <> 0 Тогда
> 			Числа[Запись] = Числа[i];
> 			Запись = Запись + 1;
> 		КонецЕсли;
> 	КонецЦикла;
> 	Пока Запись <= Числа.ВГраница() Цикл
> 		Числа[Запись] = 0;
> 		Запись = Запись + 1;
> 	КонецЦикла;
> КонецПроцедуры
> ```
> Время `O(n)`, память `O(1)`. Порядок ненулевых сохраняется, потому что мы записываем их в том же порядке, в каком встречаем.

> [!question]- Проверь себя
> 1. Чему равен `ВГраница()` у пустого массива и у массива из 5 элементов?
> 2. Почему `Числа.Удалить(0)` — не `O(1)`?
> 3. Как обойти массив с конца, если `Для` идёт только вверх?
> 4. Найдите второй максимум за один проход — какие переменные нужны?
>
> > [!success]- Ответы
> > 1. `-1` и `4`.
> > 2. После удаления первого элемента все остальные сдвигаются на одну позицию влево — `n` операций.
> > 3. Циклом `Пока i >= 0` с уменьшением `i` на каждом шаге.
> > 4. Два «максимума»: первый и второй; при новом лидере старый первый становится вторым.
