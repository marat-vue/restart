> [!abstract] Коротко
> **Скользящее окно** — непрерывный отрезок массива или строки между левой и правой границей, который «едет» по данным. Вместо пересчёта каждого отрезка заново мы **добавляем** элемент, вошедший справа, и **убираем** элемент, вышедший слева. **Фиксированное окно** (длина `k` задана) — максимальная сумма `k` подряд идущих элементов. **Переменное окно** — правая граница расширяет окно, левая сужает его, пока условие нарушено (самая длинная подстрока без повторов). Сложность `O(n)` вместо `O(n·k)` или `O(n²)`.

## Идея на примере

**Задача.** Дана выручка магазина по дням. Найти максимальную выручку за любые **3 дня подряд**.

```text
Дни:      1    2    3    4    5    6
Выручка: [2]  [1]  [5]  [1]  [3]  [2]
```

Простое решение — для каждой тройки дней посчитать сумму заново:

```text
[2  1  5] 1  3  2  → 8
 2 [1  5  1] 3  2  → 7
 2  1 [5  1  3] 2  → 9   ← максимум
 2  1  5 [1  3  2] → 6
```

Каждая сумма — `k` сложений, троек `n − k + 1`. Итого `O(n·k)`. При `k = 1000` и `n = 100 000` — сто миллионов операций.

Заметим: соседние окна отличаются всего **двумя** элементами. Окно `[2, 1, 5]` превращается в `[1, 5, 1]`: ушло слева `2`, пришло справа `1`. Значит, новую сумму можно получить из старой за **два действия**:

```text
Сумма окна [1 5 1] = Сумма окна [2 1 5] − 2 + 1 = 8 − 2 + 1 = 7
```

Это и есть **скользящее окно**: окно «едет» вправо, и мы обновляем его состояние, а не пересчитываем.

## Фиксированное окно: максимальная сумма k элементов

```1C
&НаКлиенте
Функция МаксСуммаОкна(Числа, k)
	Если Числа.Количество() < k Тогда
		Возврат Неопределено;
	КонецЕсли;

	// 1. Сумма первого окна
	СуммаОкна = 0;
	Для i = 0 По k - 1 Цикл
		СуммаОкна = СуммаОкна + Числа[i];
	КонецЦикла;
	Максимум = СуммаОкна;

	// 2. Двигаем окно: справа входит Числа[i], слева уходит Числа[i - k]
	Для i = k По Числа.ВГраница() Цикл
		СуммаОкна = СуммаОкна + Числа[i] - Числа[i - k];
		Если СуммаОкна > Максимум Тогда
			Максимум = СуммаОкна;
		КонецЕсли;
	КонецЦикла;

	Возврат Максимум;
КонецФункции
```

Прогон по `[2, 1, 5, 1, 3, 2]`, `k = 3`:

| i | Входит `Числа[i]` | Уходит `Числа[i−k]` | Сумма окна | Максимум |
| --- | --- | --- | --- | --- |
| первое окно | — | — | 2+1+5 = 8 | 8 |
| 3 | 1 | 2 | 8 + 1 − 2 = 7 | 8 |
| 4 | 3 | 1 | 7 + 3 − 1 = 9 | 9 |
| 5 | 2 | 5 | 9 + 2 − 5 = 6 | 9 |

Время `O(n)` — каждый элемент один раз входит и один раз уходит. Память `O(1)`.

```1C
Проверить("Окно 3", МаксСуммаОкна(ЧислаИзСтроки("2,1,5,1,3,2"), 3), 9);
Проверить("Окно на весь массив", МаксСуммаОкна(ЧислаИзСтроки("1,2"), 2), 3);
```

## Переменное окно: самая длинная подстрока без повторов

Это одна из самых популярных задач собеседований.

**Условие.** Найти длину самой длинной подстроки, в которой все символы различны. `"abcabcbb"` → `3` (`"abc"`), `"bbbb"` → `1`, `"pwwkew"` → `3` (`"wke"`).

Здесь длина окна **не задана**. Правило:
- **правая** граница всегда идёт вперёд и добавляет символ в окно;
- если новый символ уже есть в окне — окно «плохое», и мы сдвигаем **левую** границу, выбрасывая символы, пока повтор не исчезнет;
- после каждого шага окно «хорошее» — запоминаем его длину, если она рекордная.

Какие символы сейчас в окне — храним в **множестве** (соответствии) — проверка за `O(1)` ([[05. Соответствие как хеш-таблица]]).

```text
Строка: a b c a b c b b

[a]                  окно "a"     длина 1
[a b]                окно "ab"    длина 2
[a b c]              окно "abc"   длина 3  ← рекорд
 a[b c a]            пришла "a", уже есть → выкинули левую "a" → "bca", длина 3
 a b[c a b]          пришла "b" → выкинули "b" → "cab", длина 3
 a b c[a b c]        пришла "c" → выкинули "c" → "abc", длина 3
 a b c a b[c b]      пришла "b" → выкидываем "a", "b" → "cb", длина 2
 a b c a b c b[b]    пришла "b" → выкидываем "c", "b" → "b", длина 1
Ответ: 3
```

```1C
&НаКлиенте
Функция ДлинаБезПовторов(Текст)
	ВОкне = Новый Соответствие;   // символы, которые сейчас в окне
	Левый = 1;
	Лучшая = 0;

	Для Правый = 1 По СтрДлина(Текст) Цикл
		Символ = Сред(Текст, Правый, 1);

		// Пока новый символ уже в окне — сужаем окно слева
		Пока ВОкне.Получить(Символ) <> Неопределено Цикл
			ВОкне.Удалить(Сред(Текст, Левый, 1));
			Левый = Левый + 1;
		КонецЦикла;

		ВОкне.Вставить(Символ, Истина);   // расширяем окно справа
		Лучшая = Макс(Лучшая, Правый - Левый + 1);
	КонецЦикла;

	Возврат Лучшая;
КонецФункции
```

| Код | Смысл |
| --- | --- |
| `ВОкне` | Множество символов окна — чтобы за `O(1)` узнать, есть ли повтор |
| `Для Правый = …` | Правая граница проходит по всем символам |
| `Пока ВОкне.Получить(Символ) <> Неопределено` | Пока повтор есть — выкидываем символ на левой границе |
| `Правый - Левый + 1` | Длина окна: границы включительно |
| `Макс(…)` | Запоминаем рекорд |

Время `O(n)`, хотя внутри цикла есть цикл: каждый символ **один раз** добавляется правой границей и **не больше одного раза** удаляется левой. Всего не больше `2n` действий.

```1C
Проверить("abcabcbb", ДлинаБезПовторов("abcabcbb"), 3);
Проверить("bbbb", ДлинаБезПовторов("bbbb"), 1);
Проверить("pwwkew", ДлинаБезПовторов("pwwkew"), 3);
Проверить("Пустая", ДлинаБезПовторов(""), 0);
```

> [!tip] Цикл в цикле — не всегда `O(n²)`
> В переменном окне внутренний `Пока` не начинает каждый раз сначала: левая граница только движется вперёд и за всю работу пройдёт строку один раз. Это частый вопрос на собеседовании: «Почему тут `O(n)`, если циклы вложенные?».

## Шаблон переменного окна

Большинство задач на переменное окно решаются по одному шаблону:

```text
Левый = начало
Для Правый = начало По конец:
    добавить элемент Правый в состояние окна
    Пока окно нарушает условие:
        убрать элемент Левый из состояния
        Левый = Левый + 1
    окно корректно → обновить ответ
```

| Задача | Состояние окна | Условие нарушено, когда |
| --- | --- | --- |
| Подстрока без повторов | Множество символов | Новый символ уже в окне |
| Кратчайший подмассив с суммой ≥ S (положительные числа) | Сумма окна | — (сужаем, **пока** сумма ≥ S, и запоминаем минимум) |
| Самая длинная подстрока, где не больше K разных символов | Частоты символов | Разных символов больше K |

## Задача для закрепления: кратчайший подмассив с суммой не меньше S

**Условие.** Даны положительные числа и число `S`. Найти длину самого короткого непрерывного подмассива с суммой `≥ S`. Если такого нет — вернуть 0. `[2, 3, 1, 2, 4, 3]`, `S = 7` → `2` (`[4, 3]`).

> [!example]- Подсказка
> Расширяйте окно вправо, прибавляя элемент к сумме. Как только сумма `≥ S` — окно подходит: запомните длину и сужайте слева, вычитая элементы, **пока** сумма остаётся `≥ S` — так найдёте самое короткое подходящее окно с этой правой границей.

> [!example]- Решение
> ```1C
> &НаКлиенте
> Функция КратчайшийПодмассив(Числа, S)
> 	Левый = 0;
> 	СуммаОкна = 0;
> 	Лучшая = 0;   // 0 — «не найдено»
> 	Для Правый = 0 По Числа.ВГраница() Цикл
> 		СуммаОкна = СуммаОкна + Числа[Правый];
> 		Пока СуммаОкна >= S Цикл
> 			Длина = Правый - Левый + 1;
> 			Если Лучшая = 0 Или Длина < Лучшая Тогда
> 				Лучшая = Длина;
> 			КонецЕсли;
> 			СуммаОкна = СуммаОкна - Числа[Левый];
> 			Левый = Левый + 1;
> 		КонецЦикла;
> 	КонецЦикла;
> 	Возврат Лучшая;
> КонецФункции
> ```
> Время `O(n)`. Работает только для **положительных** чисел: с отрицательными сужение окна может увеличить сумму, и правило ломается.

> [!question]- Проверь себя
> 1. Как получить сумму следующего окна длины `k` из суммы текущего?
> 2. Почему решение «подстрока без повторов» работает за `O(n)`, хотя содержит цикл внутри цикла?
> 3. Где хранить символы текущего окна, чтобы быстро проверять повторы?
> 4. Почему приём «сужать, пока сумма ≥ S» не работает для отрицательных чисел?
>
> > [!success]- Ответы
> > 1. Прибавить вошедший справа элемент и вычесть ушедший слева: `Сумма + Числа[i] − Числа[i − k]`.
> > 2. Левая граница только движется вперёд: каждый символ добавляется один раз и удаляется не больше одного раза — всего до `2n` операций.
> > 3. В соответствии-множестве (символ → Истина).
> > 4. Удаление отрицательного элемента слева **увеличивает** сумму — сужение больше не означает уменьшение суммы, и логика «сужаем, пока подходит» перестаёт быть верной.
